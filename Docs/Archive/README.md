# 문서 보관소

최종 갱신: **2026-10-14**

이곳의 문서는 과거 기획·초안·검토 기록의 보관본이다. 현행 게임 규칙의 근거로 사용하지 않는다.
[현행 기획서](../../Assets/Docs/Design/README.md)가 유일한 설계 입구다.

| 보관본 | 범위 |
| --- | --- |
| [2026-10-14 정리 전 문서](2026-10-14/Assets/Docs/Design/README.md) | 현행 사양과 작업 보고서가 섞여 있던 Rework 문서의 원문. 미채택 대안·이전 수치·검토 이력도 보존한다. |
| [legacy 브랜치](https://github.com/siholee/NeverTheLast/tree/legacy) | 개편 전 main의 코드·데이터·문서. 보관용이며 새 개발은 main에서 진행한다. |

검증 촬영본·실행 로그·인계 보고서는 로컬 `Logs/`와 해당 보고서의 증거 경로에 둔다. 저장소 기획서에 반복해서 붙이지 않는다.
이 보관소와 legacy는 읽기 위한 이력이며, 현행 수치 변경을 동기화하는 대상이 아니다.
