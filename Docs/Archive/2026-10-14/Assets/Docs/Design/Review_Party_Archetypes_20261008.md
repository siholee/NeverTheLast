# 기믹 파티 전체 검토 · Rework

최종 갱신: 2026-10-10 (아군 전용 재보·쿠베라 소환 이탈·DEF 만사·풀 이슈타르 수정). 기획 원본: Detail_02/08/15/16/17, 실제 코드·10_units/30_synergies.yaml 대조.

현행 파티 동작 설명과 🔸 신규 설계를 구분한다. 아래 5인 편성은 **구조 검토 예시**이며 승률 검증으로 확정된 최적 덱이 아니다. 훈련/장비/중량을 전제로 하지 않는다. 필드 5인의 슬롯 비용, 보상 코드 7활성/보관/교환, 원소 부착·디버프의 특공 기반 효과 명중과 특방 기반 저항을 함께 고려한다. 소환수는 영웅 슬롯과 다르며 행동 분류도 따로 유지한다.

## 1. 기믹의 경계

- 일반/초월/특수/추가/우선 추가/소환을 분리한다. 지휘 사격의 타격은 참여자의 일반 공격이지만 행동 완료는 나폴레옹 특수1회다. 일반 공격 피해 증가와 일반행동 턴이 같다고 해석하면 안 된다.
- 고유 자원은 캐릭터별. 재보만 아군 파티 공용(적 저장소 없음). 아누비스·축전기는 저장 성장, 프레이아 온기는 실제 자기 치유량, 쿠베라 초월기는 마나120이며 이자로 공용 재보를 충전한다. 서로 대체하거나 복제하지 않는다.
- 효과 명중을 필요한 만큼 확보하고 남은 투자를 주 피해/생존/속도에 배분한다. 아군 버프·치유·보호막에는 저항을 붙이지 않는다.
- 원소를 타고난 것과 부착하는 것은 다르다. 프레이아의 풀 속성, 츠쿠요미의 번개 속성을 화상/감전 재료로 세지 않는다.

## 3. 지속피해 파티의 확장성

감전은 적 일반행동, 화상은 적 모든 행동, 맹독은 적 일반행동, 저주는 생성자 일반행동에 발동한다. 저주 기간은 대상 일반2회이고 재부여는 갱신만 한다. 야마 즉시 발동은 존재하는 모든 지속피해를 활용하고 삭제하지 않는다. 지속피해를 지우고 다른 이득으로 바꾸는 별도 캐릭터는 여기 구현/필수 파츠가 아니다.

속도는 저주의 생성자 발동을 늘리지만 적의 지속시간 소모와 같지 않다. 화상은 추가행동이 많은 적에게 상대적으로 유리하다. 맹독은 최대 HP 기반이지만 무조건 보스 처형으로 쓰지 않도록 보스 규칙·상한을 실제 구현과 대조한다. 특공은 부착/디버프 명중과 계수 양쪽에 영향을 주므로 한 번 투자로 발생하는 이중 이득을 같은 코드 가격으로 비교해야 한다.

현재 구현 파티 예시는 풀 부착자를 가정하지 않아 화상을 억지로 넣지 않는다. 풀 이슈타르의 일반/초월 첫 탄 부착은 현재 화상 재료지만 매 탄 부착이나 범용 풀 공급기로 계산하지 않는다. 프레이아를 화상 공급자로 수정해서 자해/치유 특성을 흐리지 않는다.

## 4. 반격과 브라다만테의 설계 자리

🔸브라다만테는 이미 요청된 피해 이전·유지력 담당 기초안이며 현재 로스터에 구현되었다고 취급하지 않는다. 반격 딜러가 피해 이전 후 실제 피격 트리거를 잃지 않도록 **원래 대상의 공격 대상 지정/접촉과 최종 HP 손실을 구분**해야 한다. 전체 아군 피해 이전과 피격 치유가 자기 이전 피해를 다시 이전/치유하는 고리가 되면 안 된다. 직접 받는 타격과 분담 피해의 반격 허용 여부, 보호막 선후, 사망 동시 판정은 구현 전 별도 확정한다. 만사 무사의 신규 기획과 섞어 출시 범위를 확대하지 않는다. 아스톨포 보류 유지.

## 5. 코드·보상과 공통 밸런스 예산

| 투자축 | 가치가 커지는 파티 | 판단할 비용 |
| --- | --- | --- |
| 공격/치명 | 지휘·추격·야마 캐리·수르트·쿠베라 치피/이슈타르 | 버퍼에 같은 공격 코드를 줄지 딜러에 줄지, 7슬롯 기회비용 |
| 특공/속도 | 지속피해·부착·츠쿠요미·이슈타르 풀 부착 | 명중과 피해/버프의 이중 가치, 고속만으로 상한/기간을 무시하는지 |
| HP | 프레이아·수르트 | HP 성장 넥타르가 치유량과 자해 계수 양쪽에 미치는 영향 |
| DEF | 바루나·수르트 보호막·만사 | HP가 보호막 계수로 바뀌지 않음. 만사DEF는 재보 공급/버프/보호막의 세 가지 가치. 수르트 보호막은 딜러 최소 안전망 |
| 특방/저항 | 모든 생존 담당 | 높은 저항 적에서도 디버퍼 선택이 무효가 되지 않는지 |
| 저장 성장/축전기 | 아누비스·소모 소환 | 코드 이동·판매 저장치 유지, 상한, 전투 재시작 중복 충전 |

재보와 소환 고리는 분리한다. 재보 전용 보상 코드나 생산량 배수 코드는 첫 구현에 추가하지 않는다. 재보는 기존 속도·생존·DEF·공격·치명 코드로 운영하고 소환 파티는 소환 코드로 투자한다. 편성 정의는 추천이지 자동 세트 수치 보너스가 아니다.

## 6. 후속 비교 실험

동일 레벨/스테이지/보상 가치에서 각 예시와 필수 파츠를 하나 뺀 변형을 비교한다. 일반 적 다수·단독 보스·다타수 보호막·높은 효과 저항·고특방·고속 적/추가행동 적 등에서 승률, 전투 AV, 생존, 실제 치유·과잉 치유, 첫 자원 발동, 낭비 충전, 기믹별 피해 기여를 기록한다. 특정 파티에 불리한 적이 존재하는 것은 결함이 아니다. 모든 적/보상 조건에서 같은5명이 이기는 것이 문제다.

실제 신규 재보 파티 구현은 [Draft_Treasure_Party.md](Draft_Treasure_Party.md)의 수치/원자 소비/시드 검수안을 따른다. 이 문서의 구조 검토만으로 신규 파티 승률이나 장기 경제 검수를 통과했다고 보고하지 않는다.
