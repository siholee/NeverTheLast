# 상세 기획서 10 — 보스 카탈로그

> **3계층 문서.** 중간 보스(엘리트 단독)와 최종 보스의 사양 · 공략 축.

최종 갱신: **2026-10-12** — 범용 공허·오리지널18개 테마 복구 및24층 고정 보스.

> 2026-09 개편 때 제외한 원본 보스들을 2026-10-12에 현행8스탯과 전투 규칙으로 다시 등록했다. §4의 ID·역할 사양이 현행 기준이며, 옛 사양은 커밋 `a6194c9`에서 확인한다.

## 1. 공허 분쇄자 (2001) — 비활성 시험장 6라운드

| 항목 | 내용 |
| --- | --- |
| 일반행동 | 돌격 — 짧은 후퇴→부분 전진으로 시전하고 대상 초상화 중심에 굵은 충격 별·짧은 충격파 고리·카드 반동을 한 중타격 단계로 재생 |
| 궁극기 | **대지 분쇄** — 같은 카드 움직임과 더 큰 중타격으로 공격력 180% + **고정 기절 1턴**. 기절 성공 때만 단순한 상태 부여광 한 번 |
| 검증 목적 | 기절이 집중 시전자에게 들어가면 집중 효과(버프 · 덧붙는 피해)가 풀리고 보호막은 남는가 |
| 공략 축 | 세이가 우선도 대상이 되면 창세의 노래가 끊긴다. 노래를 켠 직후 분쇄자의 마나를 본다 |

## 2. 공허룡 (3001) — 비활성 시험장 8라운드

| 항목 | 내용 |
| --- | --- |
| 일반행동 | 사격 — 후열 용 카드 중앙과 아군 방향 끝의 보스 배율 `Fire3` 작은 불꽃 한 번 → `Explosion1`의 충돌 끝을 대상 초상화 중심에 맞추고 암자주 몸체를 카드 오른쪽에 남기는 카드 폭 안팎 피격 한 번. 투사체·원형 집속 없음 |

## 3. 고정 보스 스테이지

24층(3스테이지 마지막 라운드)에 **공허의 파수거신(3201)**이 테마와 무관하게 단독 등장한다. 일반전 내용 슬롯2를 생략하여 기존 엘리트는21층, 테마 보스는23층으로 앞당긴다. 서사 테마 사건은20층으로 당겨지며 보스 승리 사건과 다음 테마 연작을 보존한다.

특수 기믹 없이 내구력·유지력·딜링을 확인하는 보스다. 일반행동은 공격력100% 단일 돌격, 초월기는 공격력110% 전체 피해(마나160). 원소 부착·기절·소환·격노·무적·회복 차단은 없다. 별도 제한은 추가하지 않으며 공통 전역80턴 규칙만 적용한다. 초기 원화는 기존 공허 분쇄자 원화를 재사용한다. T4/T5 코드를 클리어 전제로 삼지 않는다. 정확한 스탯 원본은 Detail_09 §6을 따른다.

## 2026-10-12 활성 범용 보스

6라운드에 테마별 엘리트(2101 우두머리·2102 날개사슴·2103 결정사슴·2104 암반사슴), 8라운드에 테마별 보스(3101 초원룡·3102 둥지룡·3103 결정룡·3104 암반룡)가 등장한다.

엘리트는 단일 강타, 보스는 후열 일반 공격과 광역 초월기를 사용한다. 첫 두 스테이지에는 강제 제어·가속 페이즈·별도 서사 기믹을 넣지 않는다. 일반전의 누적 체력 손실과 보스의 광역 피해에 치유/보호막/휴식으로 대비하는 것이 공략 축이다.

수치 원본과 테마별 속도/내구력 보정은 [Detail_09의 범용 공허 표](Detail_09_Enemy_Catalog.md)를 따른다. 초원은 기준형, 둥지는 빠르고 가벼운 형, 결정원은 방어형, 암반지는 느리고 묵직한 형이다. 색 결정 원화 변형은 실제 원소 부착을 의미하지 않는다.
