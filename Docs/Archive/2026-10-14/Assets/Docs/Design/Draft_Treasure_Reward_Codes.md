## 판정과 지급

- 개인 코드는 보유자만 강화한다. 재보는 아군 전용 공용 잔고이며 상한12를 유지한다. 보관/벤치/사망의 개인 효과는 꺼진다. 보상 후보는 파티에 Treasury 태그 유닛이 있을 때만 생성하며 활성7칸/보관/교환/저장 v14 규칙을 공유한다.
- 부유한 시작은 파티 중복 가능하다. 코드5개가 서로 다른 필드 아군에게 있으면 합10을 공급하고 상한 초과는 버린다. 같은 전투에서 재시전/재장착으로 시작 충전을 복제하지 않는다.
- 거래 성공 여부를 실제 공격에 고정한다. 예약/미발사 반환/골드 지출/추가 생산은 공격이나 소비 횟수가 아니다. 상한으로 충전 실패한 쿠베라 일반과 재보 부족 미강화 특수에는 거래 화력 보너스가 없다.
- 확실한 거래와 천공의 황소는 같은 피해 증가에 가산한다. 초월기 피해 증가 분류와도 가산하며 1.10×1.80으로 별도 증폭하지 않는다. 황금 탄환은 쿠베라 후원의 원본 치피를 올리지 않아 오라 재귀가 없다. 금권은 기존 일반 방어 경감 입구에만 적용한다.
- 유전무죄는 소비를 결제한 지원 행동이 직접 생성하는 보호막/치유에만 적용한다. 만사 일반행동의 전원 보호막에는 적용되며 동반된 다른 캐릭터의 패시브 치유/일반 보호막에는 적용되지 않는다. 보호막 원시 계수 DEF·치유 원시 계수 규칙을 바꾸지 않는다.
- 장기 적금은 보유자의 일반행동 완료 사건으로 센다. 지휘사격/추가/특수/초월기에는 일반행동 완료를 복제하지 않는다.3회 지급 기회에서 상한 초과분은 이월하지 않는다.
- 풍요의 산물은 스케줄러의 실제 행동ID/행동자별 소비 합계를 종료 시 걷은 뒤 충전한다. 연사 도중에는 환급하지 않는다. 원인을 다시 소비로 세지 않으며 중복 종료/미발사 반환에 환급하지 않는다. 다른 보유자의 코드가 함께 환급하지 않는다.
- 천공의 황소는 이슈타르의 실제 소비 탄 번호를 사용한다. 한 번에 재보3을 쓰는 쿠베라 광역 특수나 광역 적6명 피격으로 발동하지 않는다.

## 경제와 경쟁

티어는 사용자가 지정한 T2×2/T3×3/T4×2/T5×2 그대로다. 고정 상점 필수품으로 추가하지 않으며 기존 보상 추첨·재보 태그 가중·왕실 추가 구매의 상점 티어 가격을 공유한다. 장기 적금/풍요에 초안의 임의 전투당 횟수 상한을 다시 넣지 않았다. 만사에게 풍요를 장착하면 소비1이 행동 종료에 돌아와 방호를 유지하기 쉬워진다. T5 획득·활성1칸·DEF 투자라는 비용은 남는다. 이슈타르 환급은 현재 탄창을 늘리지 않고 다음 행동의 가용 재보가 된다. 장기 승률/경제30시드 검수나 상용 미술 승인을 의미하지 않는다.
