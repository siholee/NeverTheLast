# 재보 파티 — 쿠베라 리워크 · 만사 무사 · 이슈타르

최종 갱신: **2026-10-11** (사용자 확정 재보 보상9종·만사 무사/이슈타르 제공 원화 반영)

**구현 상태:** 2026-10-10 공용 재보·쿠베라 리워크·만사 무사(ID200)·이슈타르(ID220)·왕실 추가 구매를 Rework 런타임에 반영했다. 아래 수치가 현재 구현 기준이다. 실제 Unity의 기능 검증과 자연 자동전투 순환은 별도 보고서로 기록하며 장기 승률/경제 및 신규 조합의 상용 미술 검수는 아직 완료하지 않았다. 신규 재보 보상9종도 [사용자 확정 사양](Draft_Treasure_Reward_Codes.md)으로 구현했다.

**이번 변경:** 재보는 아군 전용. 쿠베라의 소환 시너지 전부 폐기, 초월기는 재보 이자 충전·특수행동은 재보 소비 증폭·특성은 재보 공격 치피 지원. 만사 일반행동은 소비형 전체 보호막, 초월기는 DEF 기반 공급/버프, 추가 구매는 상점 가격과 동일. 이슈타르는 풀 원소의 순수 소비자이며 자기 소비마다 1턴 버프를 중첩한다. 이전 초안의 적 재보·소환 생성 재보·만사 일반 충전·이슈타르 일반 충전·번개·두 번째 구매 할증은 폐기한다.

## 1. 공용 재보 규칙

재보는 **아군 파티 하나가 공유하는 전투 자원 중첩**이다. 적 저장소/적 재보 HUD/적 생산·소비 코드는 만들지 않는다. 골드는 런의 구매력, 재보는 한 전투의 탄약과 지원 비용이며 직접 환전하지 않는다. 재보 캐릭터는 개인 성능의 일부를 자원/경제에 배분하고, 풍부한 골드로 코드·넥타르를 구매해 보완한다.

| 항목 | 기준안 |
| --- | --- |
| 저장소 | 아군 파티당 하나. 모든 카드에 개인 상태로 복제하지 않음 |
| 초기/상한 | 전투 시작 0, 상한 **12**, 정수 |
| 생산/소비 | 살아 있는 필드 아군만. 벤치는 생산/소비하지 않음 |
| 공급자 사망 | 남아 있는 잔고 유지. 죽은 공급자의 추가 생산/오라는 중단 |
| 전투 종료 | 잔고·예약 폐기. 다음 전투 0, 런 저장/영구 성장 이월 없음 |
| 부여/저항 | 아군 자원·버프·보호막은 효과 명중/저항 판정 없음 |
| 결제 | 실행 직전 원자적으로 검사·정산. 예약만으로 소비 패시브를 발동하지 않음 |
| 중첩 성장 | 아누비스·축전기·영구 중첩 보상 코드와 연결하지 않음 |

쿠베라는 일반행동과 마나 초월기로 벌고, 로카팔라 특수행동으로 쓸 수도 있다. 만사 무사는 초월기로 벌고 일반행동의 보호막에 쓴다. 이슈타르는 생산 없이 초월기에 소비한다. 공급과 소비를 담당하는 캐릭터가 달라도 같은 잔고를 두 번 사용할 수 없다.

### 재보 공격 판정

쿠베라의 지원 대상은 **해당 공격이 직접 재보를 충전하거나 소비하는 것으로 등록된 공격**이다. 재보가 변하는 순간 주변에서 우연히 발생한 공격/소환 공격까지 강화하지 않는다. 첫 타격 직전 유효 대상/시전/재보 거래를 확정한 뒤 해당 공격의 치명타 판정에 지원을 적용한다.

- 쿠베라 일반: 유효 공격 확정 시 재보+1을 정산하고 그 공격에 적용. 상한 때문에 실제 증가가 0이면 미적용.
- 쿠베라 특수: 재보3을 실제 소비해 강화한 공격에 적용. 소비 없는 기본 특수에는 미적용.
- 이슈타르: 탄마다 재보1을 실제 소비한 해당 탄에 적용.
- 만사 일반/초월·쿠베라 초월: 자원 거래지만 공격이 아니므로 치피 지원 대상 아님.
- 후속/반격/소환/지휘 사격: 별도의 재보 거래가 없는 한 미적용. 지휘 사격이 일반공격을 복사했다고 고유 일반행동의 재보 생산을 복사하지 않음.

치피 지원과 이슈타르 중첩은 하나의 재보 거래를 읽는 독립 효과이며 서로 자원을 새로 생산하지 않는다. 거래 실패/미발사 예약 반환에는 발동하지 않는다.

## 2. 쿠베라 — 재보를 운용하는 후원자

**역할:** 재보 생산·재보 공격 치피 지원. 로카팔라에서는 소비형 광역 서브딜러. 원소 바위, 로카팔라 소속과 기존 기본/성장 스탯 유지: HP1150(+100), ATK90(+5.8), SP65(+4), DEF75(+5.5), SDEF75(+5.5), SPD100, 치확5%, 치피50%.

| 코드 | 사용자 방향 / 현행 수치 |
| --- | --- |
| 특성 **재보천의 후원** | 필드 오라. 아군의 재보 증감 공격에 **쿠베라 치피의30%만큼 치피 가산**. 자신의 재보 공격도 수혜. 소환수 피해 오라·소환 생성 재보/골드 보너스·외부 증원 전부 삭제 |
| 일반 **금화 투척** | 단일 ATK90% 비접촉 사격. 유효 공격 확정 시 재보+1. 공격 취소에는 미지급, 실제 공격이 회피/무효/타수 보호막으로 막혀도 지급은 유지 |
| 초월 **복리의 보고** | **마나120**. 현재 사용 가능한 재보를 R로 읽고 **1+floor(R×25%)** 충전, 상한12 적용. 공격/소환/원소 부착 없음 |
| 로카팔라 특수 **골드 러쉬** | 현행 ATK100%×금력 전체 사격. 재보3 이상이면 **3 소비하여 ATK180%×금력**으로 강화. 부족하면 재보를 부분 소비하지 않고 기본 공격 실행. 인드라만 묶음 개방, OpenOrder=0 유지 |

치피는 기본 치명 배율150%의 **추가분50%**를 뜻한다. 쿠베라 치피50%면 +15%p, 치피150%면 +45%p. 자신이 「재보천의 후원」으로 받는 치피는 공급자가 누구든 계수 원본에서 제외해 자기/상호 증폭 재귀를 막는다. 다른 정상 치피 버프/보상 투자는 반영하되 하나의 공격 해결 도중 값이 다시 증폭되지 않게 읽는다. 중복 쿠베라 오라는 최댓값 하나, 쿠베라 사망/벤치에서는 즉시 해제한다.

이자는 정산 전 R을 한 번 읽는다. R=0/4/8이면 각각1/2/3 충전. 기본1은 잔고0에서 공급이 멈추지 않게 하는 최소 원금이고 나머지가 비례 이자다. 초월기는 마나로 예약하며 이자 충전이 다음 초월기를 재귀 호출하지 않는다. 이슈타르가 이미 예약한 탄창은 사용 가능 R에서 제외한다.

기존 금력 `보유골드/(스테이지×100)`, 배율 `min(4,1+금력×0.15)`와 골드 러쉬의 승리 골드+5%(최대25%)는 유지한다. 소환 횟수에 연동되던 골드 보너스는 삭제한다. 구매에 쓴 골드는 현재 금력을 낮추므로 덱 투자와 즉시 광역 화력 사이에 선택이 남는다.

인드라 없이도 생산/치피 지원이 작동한다. 로카팔라에서만 재보3을 써 강화 특수를 사용할 수 있다. `SUMMON_CYCLE`의 후원자 자리는 리워크 후 피그말리온 등에게 넘어가며 쿠베라를 소환 코어로 계속 추천하지 않는다.

## 3. 만사 무사 — 재산을 방호와 전력으로 바꾸는 여왕

**역할:** 경제·재보·보호막의 퓨어 서포터. 비로카팔라. 원소 바위 제안, 공격/원소 부착 없음. **DEF/속도**가 주 투자축이며 높은 DEF로 서브탱커 배치가 가능한 쉴더 모델을 따른다. 치유를 겸하거나 HP를 보호막 계수로 사용하지 않는다.

근거 있는 오만함을 가진 매우 부유한 성인 여성. 재산과 조달 능력을 성과로 보여 주고 후원을 정당한 통치 행위로 생각한다. 확신에 찬 짧은 선언, 장부 인장과 금고로 연출한다. 동료를 가격으로 평가하다가 의지/명예는 돈만으로 해결되지 않는 상황과 마주한다.

**스프라이트: 사용자 제공 만사 무사 원화(`MANSAMUSA_PORTRAIT` / `MANSAMUSA_STANDING`). 임시 보이스: 제이드.** 2026-10-11 기존 야마 별칭을 교체했다. 전신 원본 픽셀/투명도는 보존하고, 초상화만 Unity 스프라이트 영역으로 상반신을 지정한다. 기존 야마 원본/GUID와 음성은 보존한다.

| 초월 **황금의 행렬** | **마나100**. 시전 직전 만사 DEF를 D로 읽고 재보 **min(10,6+floor(D/100))** 충전. 필드 아군 전체 ATK/SP **min(24%,8%+D×0.04%p)** 증가, 만사 일반행동2회 지속·갱신 |
| 특수 | 없음 |

초월기의 공급량/버프는 DEF, 보호막은 DEF와 보호막 보너스만 사용한다. 보호막 보너스는 재보 생산/ATK·SP 버프까지 증폭하지 않는다. D는 음수 없이 시전 직전 정상 파생 방어력을 읽고 공급/버프에 동일 스냅샷을 쓴다. 예: DEF100이면 재보7, 버프12%, 일반 보호막80. DEF300이면 재보9, 버프20%, 보호막240(모두 보호막 보너스 적용 전).

잔고0이면 일반행동에서 보호막을 생성하지 않지만 **일반행동 완료/통상 마나+20은 정상 처리**한다. 자원 부족을 이유로 일반행동/마나를 영원히 멈추지 않는다. 초기 마나를 임의 지급하는 별도 특성은 추가하지 않는다. 초월기100은 일반행동 마나만 계산하면5회 후 공급이며 실제 시간 충전/피격 마나는 현행 공식을 따른다. 이 최초 공급까지의 낮은 방호력이 초반 기회비용이다.

공급6~10과 일반 소비1로 단독 운영에도 장기 잉여가 생긴다. 일반행동 마나만 기준으로 DEF100에서 5회당 순공급2, DEF300이면4다. 이슈타르가 잔고를 비우면 만사의 다음 보호막도 못 쓰므로 공격 탄약/유지력 경쟁이 실제로 남는다. 보호막은 누적되지만 유한 자원·행동 수를 지불하고, 공격/원소 슬롯1개를 포기한다.

경제 자격은 전투 시작의 실제 필드 편성으로 고정한다. 벤치 경제 토템은 작동하지 않음. 자격 획득 후 사망해도 이번 승리의 보너스/구매권은 유지한다. 기존 골드 비율 보너스와 합산해 한 번만 정산하고 패배/판매/사건 고정 골드/이미 계산한 보너스에 다시 붙이지 않는다.

## 4. 이슈타르 — 모은 재보를 화력으로 바꾸는 풀 원소 헤비슈터

**역할:** 풀 원소 단일 초월기 딜러/순수 재보 소비자. 메소포타미아 소속, 비로카팔라. 일반행동/특성에서 재보를 생산하지 않는다. 자체 부착은 통상 효과 명중을 요구하며 탄약 소비·자기 버프에는 저항을 붙이지 않는다. 수리야의 일반공격/표식/방어 무시와 구분한다.

**스프라이트: 사용자 제공 이슈타르 원화(`ISHTAR_PORTRAIT` / `ISHTAR_STANDING`). 임시 보이스: 토파즈.** 2026-10-11 기존 아마테라스 별칭을 교체했다. 전신 원본 픽셀/투명도는 보존하고 초상화는 Unity 스프라이트 영역으로 상반신을 지정한다. 풀 원소는 사용자 지정으로 확정하며 원화가 바뀌어도 임의로 번개로 되돌리지 않는다.

특성 수치는 현재 최초 구현값이며 실전 장기 밸런스는 별도 검증한다. 다른 아군의 소비/예약/충전에는 중첩하지 않는다. 중첩마다 별도의 긴 만료 시간을 부여해 영구히 남기지 않고 전체가 같은 1턴 갱신 시점을 가진다. 같은 1턴 안 두 번째 초월기가 가능하다면 잔여 중첩을 이용하지만12층 상한은 유지한다. 초월 피해 보너스는 동일 범주의 피해 증가와 합산하며 탄마다 별도 곱연산으로 누적하지 않는다.

마나가 가득 차도 재보0이면 준비 상태로 기다린다. 반복 예약/마나 차감/헛발사 없이 새 충전에 재검사한다. 첫 유효 발사 직전에 마나를 한 번만 지불한다. 첫 탄 전 취소에는 마나/재보/특성 중첩을 차감·추가하지 않는다. 연사 전체는 **초월기 행동1회**이며 탄마다 행동 완료·아군 초월 트리거·프레이아 짤힐·일반 마나를 새로 발생시키지 않는다. 실제 타수는 발수대로다.

첫 탄 직전 사용 가능한 잔고를 최대12발로 예약한다. 예약은 소비가 아니며 **각 탄 직전 1씩 실제 소비**한다. 진행 중 새 생산은 다음 행동의 잔고로 남고 현재 발수를 늘리지 않는다. 표적 사망 시 살아 있는 다음 적으로 이어 쏘며 새 표적마다 경호/타겟 라우팅을 재검사한다. 전멸/자기 사망/제어/취소에는 미발사 예약을 반환하고 이미 쏜 탄/지불한 마나/획득한 특성 중첩은 되돌리지 않는다. 회피/무효/타수 보호막에 막힌 실제 발사도 소비와 중첩은 유지한다.

예약 재보와 신규 잔고를 합쳐 상한12를 지킨다. 예약을 잠글 때 잔고 상한 공간이 새로 생긴 것으로 취급하지 않으므로 예약 중 생산/반환으로 상한을 우회하지 않는다.

## 5. 추가 보상 구매 — 상점과 같은 시세

무료1개 선택은 유지하고 만사 구매권으로 같은 묶음의 남은 선택지 최대2개를 구매한다. **첫/두 번째 구매 가격 동일**, 별도 보상 희귀도 프리미엄·두 번째 할증 없음. 같은 상품의 가격은 다음 순서로 결정한다.

1. 해당 상품에 현행 상점 기본가가 있으면 그 가격을 그대로 사용: `기본가×현재스테이지`.
2. 가격이 없는 보상은 아래 **공통 티어 상점 기본가** 사용. 상점/추가 보상 구매가 같은 표를 참조하고 보상 전용 고가 표를 두지 않는다.

| 티어 | 공통 기본가 | 스테이지6 예시 |
| --- | ---: | ---: |
| T1 | 75G | 450G |
| T2 | 150G | 900G |
| T3 | 300G | 1800G |

**현행 가격 API:** `RewardManager.ShopPrice`가 개별 `goldCost`, 해당 아이템/코드의 상점 기본가, 공통 `TierBasePrice` 순으로 가격을 결정하고 현재 스테이지를 곱한다. 코드 매대의 고정 재고 자격(`shopFixed`)은 그대로이며 왕실 구매만으로 일반 상점의 품목이 늘어나지는 않는다. 회복/부활/보급 등 기존 상품은 티어 기준으로 재가격하지 않는다. `goldCost=0`은 왕실 추가 구매에서 무료가 아니라 공통 가격 또는 상품 가격을 사용한다.

- 무료 획득 후 받은 카드에 완료 표시, 나머지 수평 카드와 가격 유지. 클릭은 선택만 하고 대상 선택 뒤 최종 확정에서 골드·자격·수령 가능·미획득을 재검사한다. 실패/취소에는 차감 없음, 성공한 수령/결제는 함께 정산한다.
- 7활성 가득 차면 개인 보관함으로 수령. 중복/상위 보유로 수령 불가하면 구매도 차단. 동일 카드1회만 획득한다.
- 무료/유료 획득 후 리롤 차단. 무획득 상태에서만 기존 티켓 리롤. 구입하지 않고 즉시 다음으로 진행 가능.
- 준비 상점 구매2회와 별도 기회. 상점 가격 할인/변동 규칙이 생기면 동일 상품 구매에 같은 기준을 사용하며 이번에 추가 할인을 신설하지 않는다.
- 구매/무료 선택 중 기존 저장 금지 유지, 마지막에 스테이지 전진1회. 추후 중간 저장 허용 시 카드/무료권/유료 횟수/결제 결과의 저장 버전·이관 별도 검토.
- 판매가는 구입가보다 낮게 유지하고 현재 코드 취득 시세/축전기 저장치 규칙을 보존한다. 취득 시세를 판매 직전 스테이지로 바꿔 차익을 만들지 않는다.

스테이지6 적5명 기준 기본 수입950, 만사25% 추가 수입은 반올림238골드. T1추가450은 약1.9전투, T3추가1800은 약7.6전투치 추가 수입이다(스테이지6 고정 비교). 두 번째 구매에도 할증은 없지만 기본 수입/저축까지 쓰면 기존 상점과 쿠베라 금력 화력을 포기한다. 경제 조정은25% 골드/기회 횟수/공통 시세로 검토하고 사용자 폐기한 두 번째 할증을 임의 복구하지 않는다.

이슈타르 중첩0에서 시작하면 n발의 원시 초월 피해는 `120%×[n+0.04×n(n+1)/2]`(n≤12). 3발388.8%, 7발974.4%, 12발1814.4% ATK이며 기존 피해 증가/치명/방어/원소 반응 전이다. 같은12재보를3발씩 네 번 쓰면1555.2%로, 한 번 모아12발 쓸 때 약16.7% 강하다. 같은1턴 안 이미 남은 중첩이 있으면 이 비교와 달라진다. 마나140을 매 행동 지불하므로 소분 발사도 무료가 아니다.

쿠베라 특수는 재보3으로 ATK80% 전체를 추가한다. 적1명에는80%, 적4명에는320% 추가로 광역에서 효율이 좋다. 금력/치명 적용 전이며 소모한3은 이슈타르388.8% 단일이나 만사 전체 방호3회를 포기한 비용이다. 이자로 늘어난재보/부족시기본특수는 별도 기록한다.

만사 DEF100은 일반 보호막80/인, DEF300은240/인. 최대 HP1500 수준의 아군 기준 약5.3%/16% 안전망이며 보호막 누적 횟수와 자원 지출까지 함께 평가한다. DEF는 초월 공급량과 버프에도 영향을 주므로 방어 코드 하나의 세 가지 이득을 고려한다. 공급 상한10/버프상한24%는 경제 성장으로 무한 생산·전원 고배율이 되지 않게 하는 최초 제안이다.

이슈타르는 자체 재보 생산이 없고 낮은 일반80%/속도90으로 공급 없는 파티의 저점이 뚜렷하다. 쿠베라 치피 투자와 만사 DEF 투자가 지원 슬롯을 차지하므로 딜러 공/치명에만 골드를 집중하는 구성과 비교한다. 소환 파티의 코어/추천에서 쿠베라를 제외하고 찬드라 등 유지력 담당으로 교체했다. 쿠베라에게 소환 생성·소환 피해·추가 소환 기능은 없다.

## 7. HUD · 연출 · 구현/검수 기준

**HUD (2026-10-12):** 화면 우하단에 SP형 재보 슬롯12개를 표시한다. 채운 군청 별은 가용량, 금색 빈 별+중앙 점은 사격 예약분, 청회 빈 별은 미충전분이다. 오른쪽 숫자는 사용 가능한 양이며 예약량은 하단에 별도 명시한다. 실제 충전은 짧은 확대·정착, 실제 소비는 작은 잔상 소멸로 표현하며 예약/미발사 반환은 소비 연출 없이 모양만 전환한다. 배속에 맞춰 짧아지고 일시정지 시 멈춘다. 출전 중인 아군 재보 캐릭터가 없거나 전투 자원이 종료됐으면 전체 표시·툴팁을 숨긴다. 적 재보 표시와 개인 카드 복제는 없다. 상한12/예약/전투 종료 규칙은 바꾸지 않는다. 좌측 세로 장식선은 추가하지 않는다.

**만사:** 장부/금고는 자원 공급, 얇은 밝은 보호막은 방호로 읽히게 구분. 야마 원화를 전체 금색화하거나 방호에 공격/피격 불꽃을 재사용하지 않음.

**쿠베라:** 이자 충전은 작은 금고/재보 숫자 증가. 골드 러쉬는 소비3과 강화 사격을 표시하고 미강화와 시각 강도를 구분. 소환수 생성 연출 없음.

**이슈타르:** 제자리 조준→짧은 총구 발광→가슴 국소 피격→재장전. 풀 원소는 밝은 옥색/연두 몸체와 크림 코어로, 매 탄 똑같은 대형 잎/광역 섬광은 금지. 탄마다 점차 강해지는 작은 코어/황금탄창 숫자로 중첩 의미를 전달한다. 얼굴/HUD/행동서열 가림·연결선·매 탄 화면 흔들림 없음. 기존 Maple투명도80%의 실제 보이는 정도와 맞춘다. 보이스는 초월기1회, 타격음은 배속/중첩 믹싱 규칙 적용.

발사마다 기존 사격 조합의 조준·실제 피격·정리 코루틴을 완료하고 추가 간격0.12초를 둔다. 아래 연출 방향은 목표이며 신규 조합은 아직 독립 미술 합격이 아니다. 2배속은 타격 순서가 읽히고 4배속은 표시를 병합해 빠르게 처리한다. 판정에는 벽시계를 사용하지 않으며 전체 연사 종료까지 행동서열 확장을 유지한다.

공용 서비스는 아군 잔고·예약·실제 증감 이벤트·원자 결제·상한·종료를 한곳에 관리한다. 현재 증감 이벤트는 거래 주체·실제 증감을 제공하며 공격 귀속은 `DamageContext.IsTreasuryAttack`으로 고정한다. 재보 보상 코드의 환급은 실제 행동ID/행동자별 소비 종료 사건으로 처리하며 예약/반환/추가 생산을 소비로 세지 않는다. 적 진영용 일반화를 미리 구현하지 않는다. 기존 ID를 보존하고 말리200~219(만사200/P400/N200/U200), 메소포타미아220~239(이슈타르220/P420/N220/U220)를 추가했다. 슬롯별 팩토리 등록과 표시 데이터가 일치하며 저장 v14 구조는 바꾸지 않는다. 재보는 전투 자원으로 저장하지 않는다.

실 Unity에서는 다음 항목을 확인한다.

- 공용 자원: 적 접근 차단, 공급자 사망/벤치, 초기0·종료 폐기·상한12, 이자 잔고0·3·4·8·12의 경계값과 예약 재보 제외.
- 쿠베라: 오라 자기/상호 재귀 방지·중복 제한, 미소비 기본 특수, 기존 소환 훅 전부 제거.
- 만사: 잔고0 일반행동 완료, DEF 공급/버프 상한, 누적 보호막, 보호막 보너스 중복 적용 금지.

## 8. 구현 경로와 검증 범위

공용 자원 `Combat/PartyTreasury.cs`, 캐릭터 `TreasuryPassives/TreasuryNormals/TreasuryUltimates.cs` 및 쿠베라 네 코드, `CodeFactory`, `10_units/20_codes/30_synergies`, 보상 거래 `RewardManager`/`RewardScreen`, 재보 HUD·자료실/용어를 연결했다. 임시 원화/음성은 기존 리소스를 참조하며 야마·아마테라스와 제이드·토파즈 원본/GUID를 보존했다.

실 Unity 검증 시나리오는 `treasury_core`(예약·소비·취소·가격·실제 구매 버튼·단일 스테이지 전진), `treasury_natural`(일반 전투 충전·소비·초월 순환)이다. 연출 회귀는 `battle_pacing`으로 배속·정지·행동 종료까지 확장을 확인한다. 상세 실행 근거는 `Logs/TreasuryRework20261010/`에 남긴다. 옛 소환 쿠베라 검증/촬영은 새 사양의 합격 근거로 재사용하지 않는다.
