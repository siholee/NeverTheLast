## N 게임 표시: 캐릭터 간 같은 SD 비율

원인: `SdFrameRig`가 `feetY − topY`(모자·귀·치켜든 무기·후드를 포함한 실루엣 맨 위)를 같은 높이로 맞춘다. 그래서 머리 위 장식이 높은 캐릭터(아누비스·바스테트·찬드라·우치·아스톨포·야마·나폴레옹·사바흐·마리 등)는 몸과 머리가 작아지고, 장식이 없는 캐릭터(세이·쿠베라·츠쿠요미·히미코 등)는 커진다. Root 측정: 현재 표시 기준 머리 앵커 높이 비율 0.59~0.81(약 37% 차).

1. 측정(아군 42명, 호루스 제외, IDLE): `crownY` = 두개부 맨 위(정수리 머리카락 윗선. 귀·뿔·모자·관·후드 여분·바람에 뜬 머리·아호게·무기 제외), `chinY` = 턱 끝. 머리 높이 = chinY − crownY, 등신 = (1220 − crownY) / 머리 높이. 5명 이상은 System.Drawing 확대 크롭에 선을 그어 육안 대조 시트로 남긴다.
2. `97_stage_figures.yaml` sd 블록에 선택 필드 `crownY`를 추가하고, `SdFrameRig`는 있으면 `_pixelWorld = height × K / (feetY − crownY)`로 크기를 정한다(없으면 기존 topY). K는 정규화 전후 아군 표시 높이 중앙값이 같도록 한 번 정한 전역 상수. topY는 HeadBounds·HP바·가림 판정에 그대로 쓴다(모자가 HUD에 닿지 않는지 확인).
3. 같은 비율 확인: 정규화 후 아군 등신 중앙값 대비 ±6% 밖인 캐릭터를 목록으로 남긴다(그림 재생성 후보, 이번 회차에 그리지 않음). 남녀 구분 없이 같은 기준.
4. 로키 펜리르(사용자 정정): 11차 G 이전의 게임 실제 위치·크기로 되돌린다(G 변경 기록·백업 값 우선. 못 찾으면 검토판 이전 값: 주인 뒤쪽 −170, 화면 위 −20, ×0.62). 다만 **그리기 순서는 로키보다 앞**(펜리르가 로키를 가림). 오리온·토트는 11차 앞 배치(150, −10) 유지.
5. 증거: 정규화 전/후 아군 42명 같은 기준선 나란히 시트, 실제 Play 1920×1080 편성 촬영(장식 큰 캐릭터와 없는 캐릭터 섞어서), 로키 펜리르 촬영.
