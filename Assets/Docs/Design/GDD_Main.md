# NeverTheLast — 게임 방향

최종 갱신: **2026-10-14**

신화 속 인물의 파티와 보상 코드 조합을 설계하고, 자동 전투로 그 선택을 확인하는 서브컬처 로그라이트 RPG다.
전투의 조작 숙련보다 편성·배치·코드 선택·골드와 회복 운영이 결과를 만든다.

## 핵심 경험

캐릭터의 고유한 행동과 자원을 이해하고, 서로 다른 투자 요구를 가진 동료를 연결한다.
일반 라운드는 팀의 컨디션을 소모시키고 엘리트·보스는 딜링·탱킹·유지력의 균형을 시험한다.
같은 캐릭터도 얻은 보상과 편성에 따라 역할이 달라지며, 자동 전투의 순서와 효과는 화면에서 읽을 수 있어야 한다.

## 게임 루프

해금한 캐릭터 1~5명 편성 → 준비(배치·활성 코드·상점·휴식) → 자동 전투 → 정산 → 보상 또는 사건 → 다음 라운드.
무한 모드 하나이며 메인/서포터 구분, 훈련, 장비 중량, 서포트 카드 계승은 사용하지 않는다.
영구 계정 해금과 한 런의 레벨·코드·아이템·중첩은 구분한다.

테마 하나는 8라운드다. 첫 두 표시 스테이지는 서사가 없는 범용 공허 테마를 사용하고 이후 문명별 테마가 섞인다.
24층은 특별한 퍼즐보다 유효한 편성과 보상을 골랐는지 확인하는 저속·고내구·고화력 시험이다.
진행의 상세 수치와 실제 콘텐츠 목록은 [01 진행](Detail_01_Progression.md)·[09 적](Detail_09_Enemy_Catalog.md)·[10 보스](Detail_10_Boss_Catalog.md)에 둔다.

## 설계 원칙

- 캐릭터의 특성·일반행동·초월기와 선택적 특수행동이 편성의 연결점을 만든다. 이름 조건만으로 전용 파티를 강제하지 않는다.
- 공격력·특수공격력·방어력·체력·속도·치명타의 투자 대가가 역할을 가른다. 효과 명중과 지속피해의 위력도 이 선택에 포함한다.
- 보상 활성 칸의 한도와 개인 보관함·무료 교환이 현재 전력과 미래 빌드의 선택을 만든다.
- 체력·생사·마나가 전투 사이에 이어져 회복과 골드 운영이 의미를 가진다. 테마 전환의 자원 초기화는 진행 사양을 따른다.
- 일반·추가·특수·초월기·소환·지속피해·반격의 판정을 구분하고 같은 논리 효과를 연출 횟수만큼 중복 발동하지 않는다.
- 정보 계층·정렬·여백·아이콘·행동 읽기를 상용 게임 기준으로 검수한다. 미술 승인과 기능 검증은 별개의 판정이다.

## 남은 과제

장기 런 밸런스, 게임 전체 기술·성능 검수, 최종 상용 미술 판정, 미리워크 인물과 신규 도입부는
[백로그](Design_Backlog.md)에서 상태를 관리한다. 개발 브랜치의 main 승격은 이 검수의 합격을 의미하지 않는다.
