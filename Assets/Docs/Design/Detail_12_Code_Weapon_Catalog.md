# 상세 기획서 12 — 스킬·무기 관리 목록

최종 갱신: 2026-09-03

이 문서는 플레이어 캐릭터 코드와 장비 숙련을 한곳에서 찾기 위한 색인이다. 실제 런타임 원본은 `20_codes.yaml`, `40_items.yaml`, `CodeFactory.cs`이며 캐릭터별 상세 수치는 [Detail_08](Detail_08_Confirmed_Characters.md)를 따른다.

## 1. 공통 슬롯 규칙

| 슬롯 | 런타임 타입 | 규칙 |
| --- | --- | --- |
| 고유 패시브 P | `UniquePassiveCode` | 캐릭터당 1개. 코드 용량 미점유. **전수 불가** |
| 일반행동 N/N+ | `BaseNormalCode` | 고유 이름 없음. N+도 UI에는 일반행동으로 표시 |
| 고유 궁극기 U | `UltimateCode` | 캐릭터당 1개. 일부 캐릭터는 마나를 쓰지 않는 상시형 궁극기를 가짐 |
| 해금 패시브 | `PassiveCode` | `levelPassives`의 **레벨 조건만** 만족하면 활성. 코드 용량 한도는 폐지됐다 |

**모든 고유 패시브는 전수되지 않는다.** 열화 전수본 제도는 폐지했고, 그 흔적이던 `TransferVersionCodeId` 필드도 삭제했다.
서포터 카드가 넘겨줄 수 있는 코드는 해금 패시브뿐이다.

**숙련을 주는 코드도 전부 없앴다.** 모션 문제로 캐릭터는 시작 숙련 이외의 무기·방어구를 익히지 못한다.
`만류귀종`(55)은 완전 삭제했고, `궁수`(140)와 `민첩함`(141)에서는 숙련 부여 부분만 뺐다.

> **적 코드는 이 문서에 없다.** 아군·적을 통틀어 ID로 찾으려면
> [Detail_11 — 코드 ID 카탈로그](Detail_11_Code_Catalog.md)를 본다.

### 3.3 코드 등급 — 일반(은색) / 강화(금색)

등급은 셋이다.

| 등급 | 색 | 성격 |
| --- | --- | --- |
| **일반** `Normal` | 은색 | 해금 패시브의 기본. 같은 계열의 강화 등급이 있으면 그쪽에 눌린다 |
| **강화** `Enhanced` | 금색 | 같은 계열의 일반 등급을 대체한다 |
| **고유** `Unique` | 보라색 | **P 슬롯 전용.** 은·금 사다리 밖에 있어 대체하지도, 대체당하지도 않는다 |

**고유 패시브는 등급 사다리에 끼지 않는다.** `PassiveCode.IsUniquePassive`를 켜면
등급이 자동으로 `Unique`가 되고 `SupersededByCodeId`가 지워진다. 그래서 고유 패시브를
어떤 코드의 상위로 지정할 수 없고, 고유 패시브에 상위 코드를 달 수도 없다.

같은 효과 계열에 은·금 두 등급이 있으면 **강화 등급이 일반 등급을 대체한다.** 스킬 Pt 습득으로
두 등급을 함께 들 수 있으므로, 일반 등급 코드는 `PassiveCode.SupersededByCodeId`에
자신을 덮는 강화 코드 ID를 적어 두고 `Unit`이 발동 단계에서 걸러 낸다.

**이 한 줄이 습득 순서도 정한다.** `PassiveCatalog`가 공용 구간(ID 1~179)을 훑어
`금 → 선행 은` 역색인을 만들고, 스킬 화면은 **선행 은 코드를 배운 뒤에만 금을 팔게** 한다 —
[Detail_04 §6.4](Detail_04_Training.md). 사다리를 새로 이어도 색인에 손댈 것이 없다.

| 계열 | 일반(은색) | 강화(금색) | 대체 방식 |
| --- | --- | --- | --- |
| 처형 기준 | 11 천살성(8%) | 13 당연한 운명(12%) | 한 유닛이 둘을 들면 11이 발동하지 않는다 |
| 부여 치유·보호막 | 70 의술(+25%) | 32 의신의 가호(+50%) | 한 유닛이 둘을 들면 70이 발동하지 않는다 |
| 가한 피해 회복 | 41 투사(8%) | 1524 하루종일도 할 수 있어(12%) | 한 유닛이 둘을 들면 41이 발동하지 않는다. 금색은 현재 공허의 멧돼지 전용. 41은 테세우스·수르트·세트가 함께 쓰는 범용 코드다 |
| 위기 회복 | 2 기사회생(60%) | 103 완벽한 재기(100%) | 한 유닛이 둘을 들면 2가 발동하지 않는다. 🔸 금색은 아직 보유자가 없다 |
| 흡혈 증폭 | 1531 흡혈귀(+25%) | 1532 어둠의 군주(+50%) | 한 유닛이 둘을 들면 1531이 발동하지 않는다. 공허의 늑대 전용 |
| 체력 분할 | 1541 알파 개체(×2) | 1546 완전함(×3) | 한 유닛이 둘을 들면 1541이 발동하지 않는다. 공허 계열 전용 |
| 최대 체력 추가타 | 1581 궁극의 신체(2.5%) | 1582 천무지체(5%) | 한 유닛이 둘을 들면 1581이 발동하지 않는다. 공허의 분쇄자 전용 |
| 원소 반응 피해 | 76 원소술사(+25%) | 1591 에테르(+40%) | 한 유닛이 둘을 들면 76이 발동하지 않는다. 금색은 공허의 용 전용 |
| 치명 피해 부활 | 1403 명계의 재림(다음 턴) | 1592 완전한 부활(즉시) | 한 유닛이 둘을 들면 1403이 발동하지 않는다. 둘 다 적 전용 |
| 원소 숙련 | 58·186·187·57·188·74·189(+10%) | 1593 원소 정통(+25%) | 금색은 보유자 자신의 원소를 읽어 일곱 개를 하나로 덮는다. 공허의 용 전용 |

**등급 쌍이 아니라 상태 키로 겹침을 막는 계열**도 있다. 아래는 전부 한쪽이 고유 패시브라
등급 사다리를 쓸 수 없고, 같은 공용 상태 키를 써서 **높은 쪽만 남긴다.**

| 계열 | 약한 쪽 | 강한 쪽(고유) | 처리 |
| --- | --- | --- | --- |
| 원소 반응 피해 | 76 원소술사 · 1591 에테르 | 266 대해의 판결(+40%) | 공용 상태 키, 높은 쪽만 |
| 지속피해 부여량 | 1016 저주(+20%) | 261 죽음의 계약(+30%) | 공용 상태 키, 높은 쪽만 |
| 불 원소 아군 피해 | — | 262 영원히 타오르는 불꽃(+20%) | 공용 상태 키, 중복 없음 |
| 보주 치명타 피해 | — | 62 대마법사(+25%) | 공용 상태 키, 중복 없음 |

등급은 도감의 코드 목록에서 색으로 보인다 — 일반은 은색, 강화는 금색, 고유는 보라색이며,
대체되어 발동하지 않는 코드는 흐리게 깔리고 이름 뒤에 `(대체됨)`이 붙는다.

## 6. 신규 코드 등록 체크리스트

1. `20_codes.yaml`의 올바른 분류(passive/normal/ultimate)에 고유 ID와 표시 설명을 등록한다.
2. 코드 클래스를 만들고 `CodeFactory`의 같은 분류에 연결한다.
3. 캐릭터 코드면 `10_units.yaml`의 `codes` 또는 `levelPassives`에 연결한다.
4. 일반/대체행동의 `CodeName`은 `일반행동`으로 통일한다.
5. 영구 이벤트 리스너는 사망·라운드 종료 시 반드시 해제한다.
6. 새 숙련이면 `EquipmentProficiency`, `IsWeapon`, 이 문서의 숙련 표를 함께 갱신한다. **코드로 숙련을 부여하지는 않는다.**
7. 현재 전용 그래픽 제작 전이므로 신규 공격은 공용 투사체를 사용하고, 아래 아이디어만 기록한다.
