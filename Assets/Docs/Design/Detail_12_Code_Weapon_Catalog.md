# 상세 기획서 12 — 스킬·무기 관리 목록

최종 갱신: 2026-09-03

이 문서는 플레이어 캐릭터 코드와 장비 숙련을 한곳에서 찾기 위한 색인이다. 실제 런타임 원본은 `20_codes.yaml`, `40_items.yaml`, `CodeFactory.cs`이며 캐릭터별 상세 수치는 [Detail_08](Detail_08_Confirmed_Characters.md)를 따른다.

## 1. 공통 슬롯 규칙

| 슬롯 | 런타임 타입 | 규칙 |
| --- | --- | --- |
| 고유 패시브 P | `UniquePassiveCode` | 캐릭터당 1개. 코드 용량 미점유. **전수 불가** |
| 일반공격 N/N+ | `BaseNormalCode` | 고유 이름 없음. N+도 UI에는 일반공격으로 표시 |
| 고유 궁극기 U | `UltimateCode` | 캐릭터당 1개. 일부 캐릭터는 마나를 쓰지 않는 상시형 궁극기를 가짐 |
| 해금 패시브 | `PassiveCode` | `levelPassives`의 **레벨 조건만** 만족하면 활성. 코드 용량 한도는 폐지됐다 |

**모든 고유 패시브는 전수되지 않는다.** 열화 전수본 제도는 폐지했고, 그 흔적이던 `TransferVersionCodeId` 필드도 삭제했다.
서포터 카드가 넘겨줄 수 있는 코드는 해금 패시브뿐이다.

**숙련을 주는 코드도 전부 없앴다.** 모션 문제로 캐릭터는 시작 숙련 이외의 무기·방어구를 익히지 못한다.
`만류귀종`(55)은 완전 삭제했고, `궁수`(140)와 `민첩함`(141)에서는 숙련 부여 부분만 뺐다.

> **적 코드는 이 문서에 없다.** 아군·적을 통틀어 ID로 찾으려면
> [Detail_11 — 코드 ID 카탈로그](Detail_11_Code_Catalog.md)를 본다.

### 3.2 코드 등급 — 일반(은색) / 강화(금색)

같은 효과 계열에 두 등급이 있으면 **강화 등급이 일반 등급을 대체한다.** 서포터 전수로
두 등급을 함께 들 수 있으므로, 일반 등급 코드는 `PassiveCode.SupersededByCodeId`에
자신을 덮는 강화 코드 ID를 적어 두고 `Unit`이 발동 단계에서 걸러 낸다.
효과 안에서 상대 상태를 조회해 스스로 눌리던 방식을 한 줄 선언으로 바꾼 것이다.

| 계열 | 일반(은색) | 강화(금색) | 대체 방식 |
| --- | --- | --- | --- |
| 처형 기준 | 11 천살성(8%) | 13 당연한 운명(12%) | 한 유닛이 둘을 들면 58이 발동하지 않는다 |
| 부여 치유·보호막 | 70 의술(+25%) | 32 의신의 가호(+50%) | 한 유닛이 둘을 들면 261이 발동하지 않는다 |
| 원소 반응 피해 | 76 원소술사(+25%) | 266 대해의 판결(+40%) | 필드 오라라 서로 다른 유닛이 들며, 높은 쪽만 적용된다 |
| 지속피해 부여량 | 1016 저주(+20%) | 261 죽음의 계약(+30%) | 한 유닛이 둘을 들면 123이 발동하지 않고, 서로 다른 유닛이 들면 공용 상태 키로 높은 쪽만 남는다 |
| 불 원소 아군 피해 | — | 262 영원히 타오르는 불꽃(+20%) | 같은 공용 상태 키를 써 중복되지 않는다 |
| 보주 치명타 피해 | — | 62 대마법사(+25%) | 같은 공용 상태 키를 써 중복되지 않는다 |

**한 유닛이 함께 들 수 있는 계열**만 `SupersededByCodeId`로 막는다. 필드 오라 계열은
서로 다른 유닛이 들고 있어 매 순간 높은 쪽을 골라야 하므로, 기존대로 최댓값 판정이나
공용 상태 키로 처리하고 등급은 표시로만 쓴다.

등급은 도감의 코드 목록에서 색으로 보인다 — 일반은 은색, 강화는 금색이며,
대체되어 발동하지 않는 코드는 흐리게 깔리고 이름 뒤에 `(대체됨)`이 붙는다.

## 6. 신규 코드 등록 체크리스트

1. `20_codes.yaml`의 올바른 분류(passive/normal/ultimate)에 고유 ID와 표시 설명을 등록한다.
2. 코드 클래스를 만들고 `CodeFactory`의 같은 분류에 연결한다.
3. 캐릭터 코드면 `10_units.yaml`의 `codes` 또는 `levelPassives`에 연결한다.
4. 일반/강화 일반공격의 `CodeName`은 `일반공격`으로 통일한다.
5. 영구 이벤트 리스너는 사망·라운드 종료 시 반드시 해제한다.
6. 새 숙련이면 `EquipmentProficiency`, `IsWeapon`, 이 문서의 숙련 표를 함께 갱신한다. **코드로 숙련을 부여하지는 않는다.**
7. 현재 전용 그래픽 제작 전이므로 신규 공격은 공용 투사체를 사용하고, 아래 아이디어만 기록한다.
