# 상세 기획서 12 — 플레이어 코드 슬롯

> **3계층 문서.** 플레이어 캐릭터의 코드 슬롯 규칙. 장비·무기 숙련은 폐지됐다.

최종 갱신: **2026-10-12**

## 1. 슬롯 규칙

| 슬롯 | 개수 | 비고 |
| --- | ---: | --- |
| 고유 특성 | 1 | `UniquePassiveCode`. 옮겨지지 않는다 |
| 일반행동 | 1 | 행동 순서의 기본 슬롯 |
| 초월기 | 1 | 기본은 자원이 차면 자동 발동. `Passive` 자원은 라운드 동안 상시 활성화되고 직접 시전하지 않는다 |
| 특수행동 (선택) | 0~1 | 특정 트리거가 연 묶음에서만 나선다(로카팔라: 바유 · 바루나 · 쿠베라 · 아그니 · 인드라 · 야마 · 찬드라). 추가행동으로 세지 않는다 |
| **보상 코드** | **7** | 보상 · 상점에서 얻는 패시브 500~999. 위 슬롯과 **칸이 따로**다. 활성은 7개, 초과분은 개인 보관함으로 들어간다. 활성 중복·상하위 동시 활성은 금지한다. 상위를 받으면 활성 하위는 보관하고 같은 칸에서 교체된다. 쓰러져도 남고 런 내내 저장된다 — [Detail_17 §2](Detail_17_Reward_Codes.md) |

해금 패시브, 코드 용량, 스킬 포인트, 장비 부여 코드는 없다. 보상 코드는 **준비 중 무료 드래그**로 활성/보관,
아군 간 이동과 점유 칸 교환을 한다. 고유 특성 · 일반행동 · 초월기는 옮겨지지 않는다.
소환수가 쓰는 일반행동 코드(우치 분신의 일격, 일반행동 500)는 유닛 슬롯이 아니라 소환자 코드가 소환수에게 붙인다 — [Detail_03 §4.7](Detail_03_Character.md).

## 3. 폐지 이력

옛 숙련 목록은 커밋 `a6194c9`에서 확인한다.
