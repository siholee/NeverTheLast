# 상세 기획서 12 — 스킬·무기 관리 목록

최종 갱신: 2026-08-30

이 문서는 플레이어 캐릭터 코드와 장비 숙련을 한곳에서 찾기 위한 색인이다. 실제 런타임 원본은 `20_codes.yaml`, `40_items.yaml`, `CodeFactory.cs`이며 캐릭터별 상세 수치는 [Detail_08](Detail_08_Confirmed_Characters.md)를 따른다.

## 1. 공통 슬롯 규칙

| 슬롯 | 런타임 타입 | 규칙 |
| --- | --- | --- |
| 고유 패시브 P | `UniquePassiveCode` | 캐릭터당 1개. 코드 용량 미점유. **전수 불가** |
| 일반공격 N/N+ | `BaseNormalCode` | 고유 이름 없음. N+도 UI에는 일반공격으로 표시 |
| 고유 궁극기 U | `UltimateCode` | 캐릭터당 1개. 상시형 수르트 궁극기도 이 슬롯에 속함 |
| 해금 패시브 | `PassiveCode` | `levelPassives`의 레벨 조건과 코드 용량을 만족하면 활성 |

**모든 고유 패시브는 전수되지 않는다.** 열화 전수본 제도는 폐지했고, 그 흔적이던 `TransferVersionCodeId` 필드도 삭제했다.
서포터 카드가 넘겨줄 수 있는 코드는 해금 패시브뿐이다.

**숙련을 주는 코드도 전부 없앴다.** 모션 문제로 캐릭터는 시작 숙련 이외의 무기·방어구를 익히지 못한다.
`만류귀종`(55)은 완전 삭제했고, `궁수`(140)와 `민첩함`(141)에서는 숙련 부여 부분만 뺐다.

> **적 코드는 이 문서에 없다.** 아군·적을 통틀어 ID로 찾으려면
> [Detail_11 — 코드 ID 카탈로그](Detail_11_Code_Catalog.md)를 본다.

## 6. 신규 코드 등록 체크리스트

1. `20_codes.yaml`의 올바른 분류(passive/normal/ultimate)에 고유 ID와 표시 설명을 등록한다.
2. 코드 클래스를 만들고 `CodeFactory`의 같은 분류에 연결한다.
3. 캐릭터 코드면 `10_units.yaml`의 `codes` 또는 `levelPassives`에 연결한다.
4. 일반/강화 일반공격의 `CodeName`은 `일반공격`으로 통일한다.
5. 영구 이벤트 리스너는 사망·라운드 종료 시 반드시 해제한다.
6. 새 숙련이면 `EquipmentProficiency`, `IsWeapon`, 이 문서의 숙련 표를 함께 갱신한다. **코드로 숙련을 부여하지는 않는다.**
7. 현재 전용 그래픽 제작 전이므로 신규 공격은 공용 투사체를 사용하고, 아래 아이디어만 기록한다.
