# 상세 기획서 12 — 코드 슬롯

최종 갱신: **2026-10-14**

## 1. 고유 슬롯

유닛은 고유 특성·일반행동·초월기를 기본으로 가진다. 특정 트리거를 사용하는 유닛만 특수행동 슬롯을 추가한다.
레벨 패시브 해금·INT 기반 코드 용량·무기/장비 숙련은 없다. 고유 슬롯은 보상 코드 칸을 사용하지 않는다.
현재 각 유닛의 슬롯 ID와 이름은 [11 고유 코드 색인](Detail_11_Code_Catalog.md)에 둔다.

## 2. 보상 활성·보관

유닛당 보상 **활성 7칸**과 개수 제한 없는 개인 보관함을 사용한다. 초과 획득은 보관하며 활성 코드만 효과를 낸다.
빈 슬롯 위치와 보관 순서, 코드 한 장의 인스턴스 식별자·축전량·취득 스테이지를 보존한다.
동일 코드·상하위 동시 활성은 제한하며 상위 수령은 활성 하위를 보관하고 같은 칸을 사용한다.

준비 중 TAB에서 Drag & Drop으로 활성/보관 이동·점유 칸 교환·아군 간 이전을 무료로 한다.
준비 밖에는 읽기만 가능하다. 대상/중복/사다리/출발 위치를 검증한 뒤 양쪽 상태를 함께 변경한다.
규칙과 저장/승급/판매의 세부 판정은 [17 보상 코드](Detail_17_Reward_Codes.md)가 원본이다.

## 3. 공용 보급과의 구분

아이템은 파티 공용 인벤토리에 있다. 코드 보관함과 공용 아이템을 같은 장비/중량 시스템으로 취급하지 않는다.
폐지된 무기·장비·훈련 슬롯 이력은 [보관소](../../../Docs/Archive/README.md)에 둔다.
