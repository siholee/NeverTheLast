최종 갱신: 2026-10-03 (잔 P207/N7/U7 슬롯 추가)

## 1. 슬롯 규칙

| 슬롯 | 개수 | 비고 |
| --- | ---: | --- |
| 고유 특성 | 1 | `UniquePassiveCode`. 옮겨지지 않는다 |
| 일반행동 | 1 | 행동 순서의 기본 슬롯 |
| 초월기 | 1 | 기본은 자원이 차면 자동 발동. `Passive` 자원은 라운드 동안 상시 활성화되고 직접 시전하지 않는다 |

해금 패시브, 코드 용량, 스킬 포인트, 전수, 장비 부여 코드는 없다.
