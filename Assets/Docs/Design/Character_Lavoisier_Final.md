# 라부아지에 — 캐릭터 최종 기획서

작성: 2026-09-15  
상태: **2026-09-16 구현 완료. Unity 6000.4.9f1 전투·해금·UI 검증 76개 통과. 장기 런 밸런스 검증은 별도다.**  
범위: 캐릭터 사양. 고유 보상·장치 개조·전용 재화는 사용하지 않는다.

## 1. 정체성과 해금

**다른 아군에게 받은 치유·보호막·버프를 세 종류의 시약으로 저장하고, 궁극기로 배합·소비하는 고급 광역 딜러.** 편성이 공급을, CON이 수용량을, DEX가 실험 주기를, INT·LUK가 결과의 위력을 결정한다.

| 항목 | 확정안 |
| --- | --- |
| 이름 | 라부아지에 |
| 인물 | 역사 속 라부아지에. 아카샤에서 상점을 운영하는 화학자 |
| 원소 | 불 — `Pyro` |
| 속성 | 아카샤 · 갈리아 · 인간 — `[Akasha, Gaul, Human]` |
| 분류 | `Locked` → 계정 최초 육성 모드 완주로 영구 해금 |
| 해금 후 | 다음 런부터 메인·서포트 선택 가능. 본인의 육성 완주 후 무한 모드와 서포트 카드에 사용 |
| 전투 위치 | 기본 후열. 특정 보호막 공급원을 쓰려면 전열 배치를 선택할 수 있다 |
| 시작 숙련 | 보주(`Orb`). 방어구 숙련 없음 — 의복 사용 |
| 시작 장비 | 유리 구슬(4109). 보주를 시약병·실험 장치로 표현 |
| 고유 궁극기 자원 | 반응 준비도 — 스택형, 최대 3. 마나 자동 충전 없음 |

상점 NPC로서의 역할은 해금·출전 여부와 무관하게 유지한다. 이번 캐릭터에 상점 할인·연구 보상·개조 기능을 붙이지 않는다.

완주 실패·중도 포기·무한 모드 종료는 해금 조건이 아니다. 기존 세이브에 유효한 육성 완주 기록이 있으면 업데이트 후 해금을 소급 적용한다. 해금은 한 번만 저장한다.

### 성격

관심이 없으면 자신이 필요 없는 것인지 걱정하며 투덜거린다. 지원과 칭찬을 받으면 금방 자신감을 되찾으며, 전문 분야에서는 계산과 기록이 정확한 인물이다. 지즈 모티브는 사용자가 지정한 소심함·인정 욕구·금방 풀리는 성격에 적용한다.

별도 기분 게이지·확률적 실험 실패·행동 거부는 없다. 성격은 지원 수신과 실험 성공 시의 대사·표정으로 드러낸다.

## 2. 스탯과 성장

| 구분 | STR | DEX | CON | INT | LUK |
| --- | ---: | ---: | ---: | ---: | ---: |
| 기초 스탯 | 9 | 16 | 18 | 22 | 15 |
| 레벨당 성장 | +1 | +1 | +1 | +2 | +1 |
| 트레이닝 보너스 | 0% | +5% | +5% | +20% | 0% |

데이터상 주스탯 INT, 부스탯 DEX·CON. 일반 캐릭터의 부스탯 2개 규격을 사용하며 별도 성장 규격을 신설하지 않는다. 기초 합계는 80, 레벨당 합계는 6이다. 위 표는 데이터 원값으로, 캐릭터 보정·장비·상태가 적용된 최종 능력치와 구분한다.

LUK도 핵심 전투 스탯이지만 별도 성장 보너스를 주지는 않는다. LUK 서포터·훈련·전수가 필요한 이유를 남긴다. 네 능력치는 수치 자체를 소비하지 않으며, 소모 자원은 시약과 준비도뿐이다.

| 능력치 | 고유 기능 | 부족할 때 |
| --- | --- | --- |
| INT | 일반행동·궁극기 피해의 배율 | 충분히 배합해도 피해가 낮다 |
| CON | 세 용기의 저장 한도와 시약 1회 획득량 | 같은 지원 횟수로도 소량만 배합한다 |
| DEX | 행동치에 따른 일반행동 주기 → 준비도와 자체 합성 속도 | 공급은 충분한데 발사가 늦다 |
| LUK | 궁극기 촉매 배율 + 기존 치명타 확률 | 배합당 피해와 치명타 기대값이 낮다 |
| STR | 기존 방어력·장비 중량 | 고유 공격의 직접 계수는 아니다 |

균형 육성은 네 수치를 똑같이 맞추는 뜻이 아니다. INT·CON의 배합 규모를 확보하고, 공급 속도에 맞는 DEX와 충분한 LUK를 갖추는 것이다. 과도한 DEX는 시약을 생성해 주지 않으므로 공급이 느린 파티에서는 효율이 낮아진다.

## 3. 고유 패시브 — 질량 보존

**전수 불가. 전투 중 다른 아군이 자신에게 제공한 지원을 시약으로 수집한다.**

| 지원 | 시약 | 식별 |
| --- | --- | --- |
| 치유 | 연료 | 적색 액체·물방울 아이콘 |
| 보호막 | 안정제 | 청색 결정·결정 아이콘 |
| 버프 | 촉매 | 황색 분말·별 아이콘 |

세 시약은 독립적으로 저장한다. 원래 받은 지원은 정상 적용되며, 시약을 얻거나 소비한다고 치유량·보호막·버프를 빼앗지 않는다.

### 3.1 수치

`C`는 획득 시점의 최종 CON이다.

```
종류별 저장 한도 K = 20 + max(0, C)
유효한 외부 지원 1회 = 해당 시약 +K × 50%
일반행동 2회마다 자체 합성 = 가장 부족한 시약 +K × 25%
```

| 최종 CON | 종류별 한도 | 외부 지원 1회 | 자체 합성 1회 |
| ---: | ---: | ---: | ---: |
| 20 | 40 | 20 | 10 |
| 60 | 80 | 40 | 20 |
| 100 | 120 | 60 | 30 |
| 200 | 220 | 110 | 55 |

시약량은 0.25 단위까지 보존한다. 세 종류를 합쳐 하나의 저장 한도를 공유하지 않는다.

획득량은 지원자의 회복량·보호막량·버프 수치가 아니라 라부아지에의 수용량으로 정한다. 그래야 지원 종류와 빈도가 중요하고, 거대한 치유 1회가 다른 두 공급원을 대신하지 않는다. CON은 빈 공간만 늘리는 스탯이 아니라 실제 배합량을 늘리는 스탯이 된다.

### 3.2 지원 인정 규칙

| 사례 | 판정 |
| --- | --- |
| 다른 아군의 직접 치유 | 보정 후 치유 시도량이 양수이면 연료. 과잉 치유도 인정 |
| 다른 아군이 건 지속치유의 회복 틱 | 연료. 아래 수신 제한 적용 |
| 실제로 보호막을 추가·보충하는 외부 효과 | 안정제. 보호막이 이미 있어도 순증분이 있으면 인정 |
| 보호막 설정값이 이전 현재값 이하 | 안정제 없음 |
| 다른 아군이 주는 능력치·피해·치명타·행동 속도·받는 피해 감소·면역 버프 | 촉매. 효과 적용 또는 유효한 지속시간/중첩 갱신 시 인정 |
| 한 효과가 올스탯을 올리거나 여러 버프를 함께 부여 | 촉매 1회 |
| 한 행동이 직접 치유와 직접 보호막을 각각 부여 | 연료와 안정제를 각각 1회 |
| 지속치유 상태를 최초로 부착 | 부착 자체는 촉매 없음. 실제 회복 틱에서 연료 |
| 마나·궁극기 자원·행동 게이지를 즉시 충전 | 시약 없음. 지속적인 행동 속도 버프와 구분 |
| 원소 부착·정화·부활 | 그 자체로는 시약 없음 |
| 전투 시작 시 아군의 상시 오라 부여 | 능력치 등 대상 버프가 실제 적용되면 최초 1회 촉매. 유지·재계산은 없음 |
| 자기 치유·흡혈·자기 보호막·자기 버프 | 시약 없음 |
| 과다치유 등 치유에서 파생된 보호막 | 안정제 없음. 외부 치유가 한 번에 두 공급원을 대신하지 않음 |
| 장비 장착·레벨업·훈련·전투 밖 회복·보상·상점 | 시약 없음 |
| 적·사망한 대상·대기석 대상에게 들어간 지원 | 라부아지에의 시약과 무관 |

**수신 제한:** 같은 부여자에게서 같은 종류의 시약은 라부아지에의 자기 턴 구간마다 1회만 얻는다. 턴 구간은 전투 시작~첫 `BeginTurn`, 이후 각 `BeginTurn` 사이이며 사망·라운드 종료에 정리한다. 같은 원인 행동에서 파생된 같은 종류 효과도 한 번만 센다. 소환수의 부여자는 그 소유자로 묶는다.

서로 다른 두 아군의 지원은 각각 인정한다. 같은 아군도 치유·직접 보호막·버프를 서로 다른 종류로 줄 수 있다. 실제 시약을 받지 못할 만큼 용기가 가득 찼어도 해당 유효 지원의 수신 기회는 소비한다.

### 3.3 한도 변경과 정리

- CON 상승은 한도와 이후 획득량만 늘리고, 기존 시약을 비례 증식시키지 않는다.
- CON 하락으로 새 한도를 넘으면 초과분만 폐기한다.
- 지원 효과가 끝나거나 부여자가 사망해도 이미 저장된 시약은 남는다.
- 라부아지에의 사망·전투 이탈·라운드 종료에는 모든 시약·준비도·일반행동 누적·수신 기록을 초기화한다. 부활하면 0부터 시작한다.
- 새 전투에는 시약 0 / 준비도 0으로 시작한다. 다른 아군의 개전 버프보다 수신기 초기화가 먼저다.

## 4. 일반행동

UI 명칭은 **일반행동**이다. 단일 적에게 시약병을 던져 공격하면서 실험을 준비한다.

| 항목 | 수치 |
| --- | --- |
| 위력 | 고정 **30**, INT 참조 |
| 방어·치명타 전 피해 | **INT × 6** (`30 × INT × 0.2`) |
| 판정 | 단일 · 특수 · 비접촉 · 일반행동 |
| 대상 | 기존 단일 일반행동 우선도 규칙 |
| 준비도 | 정상 해결 시 +1, 최대 3 |
| 자체 합성 | 일반행동을 2회 해결할 때마다 가장 적은 시약 +K/4 |
| 원소 부착 | 없음 |

자체 합성의 동률 우선순위는 **연료 → 안정제 → 촉매**다. 일반행동 누적은 궁극기를 써도 유지되므로 전투 내 2·4·6·8…번째 일반행동에 합성한다. 준비도가 가득 차도 일반행동과 합성은 계속한다.

회피·보호막에 막혀도 일반행동을 정상 해결했다면 실험 준비는 진행한다. 시전 중단·대상 소실로 해결하지 못한 행동은 진행하지 않는다. 추가행동·반격·다타수는 준비도나 합성 횟수를 늘리지 않는다. 일반행동 자리를 소비한 대체행동은 1회로 취급한다.

## 5. 궁극기 — 실험 결과를 발표하겠습니다!

### 5.1 발동과 소비

**준비도 3이며, 세 시약이 모두 양수이고, 공격 가능한 적이 있으면 자동 예약한다.** 준비도만 가득 차고 시약이 없으면 기다린다. 부족한 시약이 들어온 순간에도 조건을 다시 검사한다.

```
Q = min(연료, 안정제, 촉매)
각 시약에서 Q씩 소비
준비도 = 0
```

Q는 세 종류 각각에서 꺼낸 양이다. 총 소비량 `3Q`를 피해 공식에 넣지 않는다.

예: `연료 120 / 안정제 60 / 촉매 90` → `Q=60`, 소비 후 `60 / 0 / 30`.

시전이 정상 해결되는 순간 시약·INT·LUK·치명타 관련 수치를 확정하고 자원을 먼저 소비한다. 그 다음 피해와 발동 후 효과를 해결한다. 시전 전에 제어·대상 소실로 취소되면 소비하지 않는다. 예약 중복은 한 개로 제한한다.

### 5.2 피해 수식

`I`, `L`은 궁극기 해결 시점의 최종 INT·LUK다.

```
촉매 배율 R = 1 + max(0, L) / (100 + max(0, L))
적 1명당 기본 피해 = I × (8 + 0.3 × Q) × R
                  = (40 + 1.5 × Q) × I × 0.2 × R
```

치명타·가하는 피해·받는 피해·방어력 등은 이후 기존 파이프라인에서 적용한다. 중간 위력을 정수화하지 않고 최종 피해를 기존 반올림 규칙으로 정수화하며, INT를 다시 곱하지 않는다.

| 항목 | 확정안 |
| --- | --- |
| 대상 | 공격 가능한 적 전체 |
| 타수 | 적마다 **1회**. Q가 많아도 타수가 증가하지 않음 |
| 태그 | 전체 · 특수 · 비접촉 · 궁극기 |
| 치명타 | 시전 1회에 한 번 판정, 모든 대상에게 공유. 기존 치명타 배율 적용 |
| 원소 | 피해 해결 후 살아 있는 명중 대상마다 **불 5턴** 부착. 대상 자신의 턴 기준 |
| 화상 | 직접 부여하지 않는다. 원소 반응으로 생기는 화상은 기존 규칙 |
| 준비도 이월 | 없음. 매 시전 후 0 |
| 전용 쿨다운 | 없음 |

고정 부분 `8 × INT`는 적은 시약을 합성하는 초반의 피해 바닥이다. 나머지는 실제 배합량으로 결정한다. 촉매 배율은 LUK 0/50/100/200에서 각각 1.000/1.333/1.500/1.667이며 2 미만으로 수렴한다. 실험 실패 확률은 없다.

### 5.3 자원 지원 호환

- 마나 자동 회복·마나 호흡법·코드 가속·일반 마나 주유·사전준비는 준비도를 채우지 않는다.
- 현재 아그리파 궁극기의 자원 주유는 코드상 마나형만 대상으로 하므로 라부아지에에게 적용되지 않는다. 아그리파의 일반행동과 화합은 유효한 버프 공급이다.
- 창세의 노래처럼 **스택형도 명시적으로 충전하는 효과**는 준비도만 채운다. 시약을 만들지는 않는다.
- 라부아지에의 궁극기는 발동형 궁극기다. 라이트의 궁극기 발동 횟수 등에는 정상 집계하며, 여러 적을 때려도 한 번이다.

## 6. 레벨 해금 패시브

기존 공용 코드로 구성한다. 고유 전투 체계는 처음부터 완성되어 있고, 레벨 패시브로 공급 제약을 없애지 않는다.

| 해금 Lv | 코드 ID | 이름 | 효과·역할 |
| ---: | ---: | --- | --- |
| 4 | 15 | 학식 | 서포트로 INT 훈련에 배치되면 효율 +10%. 본인의 메인 훈련에 자동 적용되는 효과가 아님 |
| 9 | 16 | 행운아 | LUK +4. 초반 촉매 효율·치명타 보완 |
| 22 | 18 | 명상 | 자기 턴마다 이번 전투 INT +1. 자기 버프라 촉매를 생성하지 않음 |
| 30 | 40 | 천상의 신체 | 받는 치유·보호막 +25%. 생존 보강이며 시약 획득량은 변하지 않음 |

## 7. 편성 검토

### 7.1 처음 해금했을 때

**라부아지에 / 프레이아 / 아그리파 / 찬드라 / 잔**

- 프레이아의 일반행동은 아군 전체 치유라 연료를 공급한다.
- 아그리파의 일반행동은 INT가 가장 높은 아군을 강화한다. 라부아지에의 INT가 선택 대상이 되도록 맞춘다. 치명타 피해와 화합을 함께 받아도 같은 행동의 촉매는 한 번이다.
- 찬드라는 개전 CON 강화와 궁극기 버프를 제공한다. 궁극기 버프 대상은 누적 피해 기여도에 따라 달라지므로 매번 라부아지에에게 들어온다고 가정하지 않는다.
- 잔은 전열을 담당한다. 찬드라·잔의 CON/STR 등 훈련 배치가 모두 라부아지에에게 최적이라는 뜻은 아니다.
- **이 편성에는 안정제의 상시 외부 공급이 없다.** 라부아지에의 자체 합성으로 낮은 출력의 궁극기를 유지하는 입문 편성이다.

첫 클리어만으로 해금된다는 조건 때문에 특정 미해금 동료가 없으면 궁극기가 영구 봉쇄되는 설계는 피한다. 대신 외부 보호막 공급을 갖췄을 때 출력이 분명하게 상승한다.

### 7.2 보호막까지 갖춘 편성

**라부아지에 / 프레이아 / 아그리파 / 아누비스 / 아스클레피아**

아누비스의 서포트 선택이 가능하고 아스클레피아를 확보한 이후의 편성이다.

- 아누비스가 전열에서 궁극기를 쓰면 아군 전열에 보호막을 준다. 라부아지에도 전열에 두어야 한다.
- 아스클레피아는 체력이 부족한 아군의 행동에 반응해 치유하고, 궁극기로 전장을 가르며 아군 전체를 회복한다.
- 프레이아는 연료, 아그리파는 촉매를 공급한다.
- 두 보호막 궁극기의 실제 주기는 지원자의 INT·행동 상황에 달려 있다. 이 편성이 언제나 최대 배합을 달성한다고 보장하지 않는다.

후열 안정성을 유지할지, 보호막을 직접 받기 위해 전열로 나갈지도 판단이 된다. 전열을 선택하면 CON의 체력과 외부 보호막이 낮은 STR을 보완한다.

### 7.3 혼동하기 쉬운 기존 캐릭터

| 캐릭터/효과 | 실제 관계 |
| --- | --- |
| 찬드라 | 기본 궁극기의 보호막은 자기 자신에게만 적용. 인드라가 여는 특수행동은 아군 전체 보호막 |
| 스카디 | 기본 보호막은 자기 자신에게 적용. 일반적인 안정제 공급원으로 계산하지 않음 |
| 니콜 | 궁극기의 치명타 피해 버프는 촉매 공급. 번개 부착 자체는 촉매 아님 |
| 프레이아 | 과잉 치유도 연료가 되지만 프레이아 자신의 순수치유 기록에는 과잉분이 들어가지 않음 |
| 아누비스 | 전열 보호막. 후열 라부아지에에게는 공급되지 않음 |
| 아스클레피아 | 반응 치유는 체력이 부족한 아군의 행동 시 발동. 궁극기 치유는 아군 전체 |

## 8. 수치 검토

이 절은 방어력·원소 반응·피해 버프·레벨 패시브를 제외한 계산이다. 표의 스탯은 장비·상태를 반영한 최종값이며 특정 레벨의 보장값이 아니다. 전투 시계는 AV 환산값이고 벽시계 시간·연출 시간이 아니다.

### 8.1 성장 구간별 최대 배합

| INT / CON / DEX / LUK | 한도 K | 일반행동 피해 | 최대 배합 U, 적 1명 | 기본 치명타 기대 U | 공급이 충분할 때 준비 주기 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 30 / 25 / 20 / 20 | 45 | 180 | 752.5 | 827.75 | 자기 일반행동 3회 / 250 AV |
| 60 / 60 / 60 / 60 | 80 | 360 | 2,640 | 3,432 | 3회 / 187.5 AV |
| 100 / 100 / 100 / 100 | 120 | 600 | 6,600 | 9,900 | 3회 / 150 AV |
| 200 / 200 / 150 / 100 | 220 | 1,200 | 22,200 | 33,300 | 3회 / 120 AV |

위 표의 소수는 반올림 전의 비교값이다.

### 8.2 공급 부족 시 순환 — 24회 일반행동 계산

최종 INT·CON·DEX·LUK 모두 100, 용기 한도 120. 공급이 있는 종류는 매 자기 일반행동 전에 외부 지원을 1회 받는다는 이상화 조건이다. 공급량은 60, 자체 합성은 30이다.

| 공급 | U 시점 | 회당 Q | 회당 U 기본 피해, 적 1명 |
| --- | --- | --- | --- |
| 세 종류 모두 | 3·6·9·12…번째 일반행동 | 항상 120 | 6,600 |
| 연료·촉매만 | 3·6·9·12…번째 일반행동 | 30·60 반복 | 2,550·3,900 반복, 평균 3,225 |
| 외부 지원 없음 | 6·12·18·24번째 일반행동 | 항상 30 | 2,550 |

자체 합성은 지원 공백을 메우지만, 모든 공급을 갖춘 화력과 같지 않다. 실제 지원 주기·제어·전투 종료 시점에 따라 결과는 달라진다.

### 8.3 기존 궁극기와 동일 기준 비교

참조 능력치 100, 비치명타·방어 전. 각 캐릭터의 고유 패시브 중 아래 명시한 보정만 포함한다.

| 캐릭터 | 적 1명당 기본 피해 | 조건 |
| --- | ---: | --- |
| 사바흐 | 2,000 | 위력 100. 대상 디버프별 추가 증폭 제외 |
| 수르트 | 광역 2,240 / 주 대상 합계 5,600 | 광역 80·단일 120, 황혼 1.4배 |
| 이카리아 | 3,920 | 위력 140, 실제 체력 비용 40%에 의한 1.4배. 다른 패시브 제외 |
| 옥타비아 | 3,750 | 현재 코드의 가변 위력 150에 INT·0.2를 곱하고 고유 궁극기 1.25배 |
| 라부아지에, 배합 50% | 3,900 | INT·CON·LUK 각각 100, Q=60 |
| 라부아지에, 최대 배합 | 6,600 | INT·CON·LUK 각각 100, Q=120 |

라부아지에의 고점은 의도적으로 높다. 세 지원 종류와 네 스탯을 요구하고 일반행동 위력을 30으로 낮춘 대가다. 비교표는 동등한 총 투자량이나 파티 전체 DPS를 보장하는 순위표가 아니다.

문서의 `INT×1.5` 같은 표기를 그대로 최종 피해로 읽으면 안 된다. 옥타비아는 현재 `PowerStatCoefficient`로 위력을 만들고 다시 `SkillDamage`를 거친다. 반면 수르트·사바흐·이카리아는 현재 코드에 고정 위력 120/80·100·140 등이 명시되어 있다. 이번 제안은 각 구현을 직접 확인해 위 표로 환산했다. 기존 캐릭터 공식은 변경하지 않는다.

### 8.4 같은 네 스탯 합계의 편중 검토

공급이 충분하고 적이 4명 계속 살아 있으며, 일반행동 3회와 최대 배합 U를 반복한다고 가정한다. 기존 기본 치명타 배율 1.5만 적용하고 소수 반올림은 생략했다. 전투 시계 1초당 총 피해는 비교용이며 기술 주기를 초 단위로 정의하지 않는다.

| 분배 | INT / CON / DEX / LUK | 합계 | U 비치명타, 적 1명 | 전투 시계 1초당 기대 총 피해 |
| --- | --- | ---: | ---: | ---: |
| 네 축 확보 | 100 / 100 / 100 / 100 | 400 | 6,600 | 11,280 |
| INT 편중 | 280 / 40 / 40 / 40 | 400 | 9,360 | 9,515.52 |

INT 편중은 한 발이 세지만, 저장·회전·치명타를 함께 확보한 쪽이 이 조건에서 약 18.5% 높다. 적이 한 명이면 약 4.2% 차이로 줄어든다. 이는 한 조건의 비교이며 균등 분배가 모든 구간·편성에서 최적이라는 증명은 아니다. 훈련의 실제 체력 비용·보너스까지 같은 비교도 아니다.

### 8.5 수치 선택의 이유와 검증 범위

- 일반행동 위력 30: 자립 공격을 남기되 지원 없이도 전용 딜러급이 되지 않게 한다.
- 준비도 3: DEX가 회전을 결정하고, 받는 지원만으로 무한 연속 궁극기가 생기지 않게 한다.
- 지원 50% / 자체 합성 25%: 종류별 외부 지원 두 번이면 용기를 채우며, 공급 누락은 낮은 출력으로 보완한다.
- 저장량 `20+CON`: 초반 바닥을 확보하고, CON에 실제 배합량 증가를 부여한다.
- 궁극기 고정 위력 40: 소량 합성 상태의 초반 피해를 보장한다.
- 배합 계수 1.5·촉매 배율 최대 2 미만: 완전한 공급에 보상을 주되 LUK 촉매가 무한 선형 증폭하지 않게 한다.
- INT와 CON을 함께 올리면 배합 피해가 곱으로 성장한다. 후반의 일격 처치 가능성이 주요 실전 검증 항목이다.

계산 검토 완료: 위 수식, 24회 행동 순환, 동일 스탯 합계 비교, 현행 궁극기 피해 환산. 구현 후 검증: Unity 실제 일반행동·궁극기·자동 예약·취소·지원 수신·라운드/사망 초기화와 해금 UI. 미실시: 장기 육성 런에서의 지원자 AI·전수/장비 조합별 승률과 후반 밸런스 검증. 기능 검증 통과를 밸런스 확정으로 해석하지 않는다.

실전 조정은 배합 계수 1.5를 첫 손잡이로 사용한다. 너무 강하면 1.3, 약하면 1.7을 비교한다. 첫 런의 문제가 보호막 접근성이라면 전체 고점을 올리기 전에 자체 합성 주기와 초반 방어를 점검한다. 수치는 이 문서의 1.5를 구현 기준으로 한다.

## 9. UI와 연출

- 캐릭터 카드에 세 시약의 현재량/한도와 준비도 0~3을 표시한다. 색 외에 모양·이름도 구분한다.
- 궁극기 설명에 현재 Q, 예상 비치명타 기본 피해, 대기 원인(준비 중/연료 부족/안정제 부족/촉매 부족)을 표시한다. 방어력 적용 후 확정 피해처럼 표시하지 않는다.
- 육성 미리보기는 해당 스탯 증가에 따른 배합 피해·수용량·행동 속도·촉매 배율 변화를 보여 준다.
- 일반행동은 시약병 투척, 궁극기는 세 병을 연결해 계량한 후 한 번의 큰 화염을 방출한다. 발사 횟수·피격 이벤트를 연출상의 작은 불꽃 수와 연결하지 않는다.
- 처음으로 세 종류를 모두 갖췄을 때 표정이 밝아지고, 최대 배합 시 자신감 있는 짧은 대사를 사용한다.

대사 예시:

> 지원 없이 자기 일반행동 3회 경과: “저기…… 저도 여기 있는데요.”  
> 외부 지원 수신: “제 연구가 필요하신 거죠? 그렇죠?”  
> 최대 배합 발사: “보셨죠? 제 계산이 맞았죠!”

징징거림 대사는 조건 발생 시 전투당 최초 한 번, 지원 수신 음성은 자기 일반행동 2회당 최대 한 번으로 제한한다. 지원 판정·성능에는 영향을 주지 않는다.

## 10. 구현 시 확인할 연결부

기획서만으로 기존 코드가 이 동작을 지원한다고 가정하지 않는다.

1. `ModifyHp`·`AddShield`·`SetShield`는 현재 치유/보호막 공용 통지를 부여자의 효과에 전달한다. 받는 라부아지에가 종류·원인 행동·실제 공급량·파생 변환 여부를 구분할 수 있는 수신 이벤트가 필요하다.
2. 이로운 상태 통지는 현재 부여자 중심의 일반 이벤트이며 일부 갱신 경로는 신규 적용과 다르다. 직접 버프·갱신·지속치유 부착·오라 유지의 분류와 동일 원인 행동 묶음을 명시해야 한다.
3. 일반행동의 준비·합성은 실제 해결 지점에서 1회 실행한다. 궁극기의 표준 자원 선소비 경로는 이 캐릭터의 시약 동시 소비·시전 취소 규칙에 맞게 처리해야 한다.
4. 특수 궁극기 충전 효과는 준비도만 변경하며 시약은 건드리지 않는다. UI는 세 용기와 준비도를 함께 보여 준다.
5. 레벨·훈련·CON 버프 갱신 시 용기 한도만 재계산한다. 지원 이벤트를 새로 발행하지 않는다.
6. 계정 완주 저장 이후 영구 해금을 적용하고, 기존 완주 기록을 소급 처리한다. 새 런 선택 제한·무한 모드 조건은 기존 정책을 따른다.
7. 전투를 중간 저장하는 경로가 추가되거나 사용되는 경우 세 시약·준비도·일반행동 누적·현재 턴 수신 기록을 함께 보존한다. 라운드 밖 세이브에는 전투 자원을 넘기지 않는다.
