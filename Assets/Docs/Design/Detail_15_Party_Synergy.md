## 1. 편성이란 무엇을 고르는 일인가

파티는 **메인 1 + 서포트 4**이고, **다섯 명 전원이 필드에 선다.** 서포트라는 이름은
'전투에 안 나온다'는 뜻이 아니라 **육성 대상이 아니다**는 뜻이다.

| 슬롯 | 조건 (`CharacterSelectionManager.CanSelectForRole`) | 하는 일 |
| --- | --- | --- |
| 메인 1 | `characterType != Support` 이고 해금 또는 육성 완료 | 필드 전투 + **집중 훈련·패시브 전수를 받는 유일한 대상** |
| 서포트 4 | `canStartAsSupport` 또는 해금·육성 완료 | 필드 전투 + 훈련 참여(강화량·특기 보너스·패시브 전수) |

그래서 서포트 한 자리는 **전투 기여**와 **육성 기여** 두 축을 동시에 고른다.
`30_synergies.yaml`의 `supportValue: { combat, training }`가 그 두 축이다.

### 1.1 런 1회차에 실제로 고를 수 있는 것

| 분류 | 인원 | 메인 | 서포트 |
| --- | ---: | --- | --- |
| Starter | 7 | O | ✕ (육성 완료 전까지) |
| Support | 15 | ✕ | O |
| Locked | 17 | ✕ (해금 후 O) | ✕ (해금 후 O) |

**최초 편성은 Starter 1명 + Support 4명으로 고정된다.** 그래서 이 문서의 추천은 두 벌이다.

| 이름 | 가정 | 서포트 후보 |
| --- | --- | --- |
| **고점(best)** | 전 캐릭터 해금 + 코드 전수 완료 | 38명 전원 |
| **대체(basic)** | 최초 로스터, 전수 코드 없음 | Support 유형 15명 |

### 1.2 서포트는 생각만큼 자라지 않는다

EXP는 처치·스테이지 클리어·육성 페이즈 세 곳에서 나오는데 **육성 페이즈 EXP는 메인만 받는다.**

| 진행 | 메인 | 서포트 |
| ---: | ---: | ---: |
| 10스테이지 | Lv.10 | Lv.9 |
| 30스테이지 | Lv.28 | Lv.24 |
| 50스테이지 | Lv.46 | Lv.39 |
| 60스테이지 | Lv.54 | Lv.47 |

(스테이지당 처치 3기 가정. `Unit.RequiredExpForLevel = 100 + 28 × (Lv−1)`)

**따라서 서포트의 실전 기여는 사실상 `고유 패시브 + 일반행동 + 궁극기`다.**
Lv.50 이상에서 열리는 팀 버프 코드 — 스카디 `원소술사`(60), 프레이아 `전사장`(61),
바루나 `수천`(50), 케찰코아틀 `날개 달린 뱀`(90), 로카팔라 `전부 아니면 전무`(80) — 는
서포트 슬롯에서 열리지 않는다고 보고 배점했다.

> 🔸 해금 패시브 190개 중 **39개(21%)가 Lv.51 이상**, 그중 17개가 Lv.71 이상이다.
> 메인은 전수로 우회할 수 있지만 서포트는 우회로가 없다.

### 5.2 단일 실패점 — 대체 불가능한 유일 코드

아래는 **보유자가 한 명뿐**이라, 그 한 명이 빠지면 축이 통째로 사라진다.

| 효과 | 유일 보유자 | 대체재 |
| --- | --- | --- |
| 원소 반응 증폭 | 바루나 `대해의 판결` (+40%) | 스카디 `원소술사`(+25%)가 하위 코드지만 **Lv60**이라 서포트로는 안 열린다 |
| 소환수 증폭 | 로키 `소환사` (+25%) | 없음 |
| 강인도 부여 | 오르페우스 `비탄의 연주` | 없음 (토트는 증폭 전용) |
| 강인도 증폭 | 토트 | 없음 |
| 아군 전체 행동 게이지 | 카이사르 `주사위는 던져졌다` | 없음 |
| 아군 전체 궁극기 자원 | 아그리파 `제 2의 건국자` | 세이 `창세의 노래`가 있으나 **Lv92** |
| 부활 | 아누비스 `죽은 자의 소생` | 없음 |
| 아군 대상 원소 부착 | 세이(바위) · 라이트(바람) · 니콜(번개) | 니콜이 셋째로 들어오면서 **축전(전기+전기)** 하나가 아군에게 실제로 만들어진다 |

> §6.3의 "버프 반응은 자기 자신에게 원소를 둘러 만드는 것이 정규 운용"이라는 설계 의도와
> 실제 로스터가 여전히 어긋나 있다. 다섯 버프 반응 중 아군에게 만들 수 있는 것은
> **축전(전기+전기, 니콜)** 하나뿐이고, 성장(풀+바위) · 단조(불+바위) · 개화(물+풀) ·
> 정수(물+물)는 여전히 만들 수단이 없다. 아군에게 **불·물·풀**을 걸 수 있는 서포터가 있어야 열린다.

### 5.3 이미 있으나 값을 못 하는 것

| 항목 | 문제 |
| --- | --- |
| 스카디 | 주스탯 STR인데 **최고 스탯이 CON**(Lv60 기준 128 vs 142)이다. 카드 특기가 CON으로 굴러 자기 화력(STR 계수)과 훈련 기여가 서로 다른 곳을 본다 |
| 가우디 | 해금 패시브가 **0개**. 레벨을 올려도 아무것도 열리지 않는다 |
| 오르페우스 · 토트 | 둘이 함께 서야만 성립한다. 서포트 4칸 중 2칸을 쓰는데 강인도는 골드·EXP·킬 카운트를 주지 않는다 |
| 천재(64) · 직감(84) | 훈련 효율 코드로 선언만 되어 있고 `TrainingManager`가 읽지 않는다 |

### 5.4 확인이 필요한 상호작용

| 항목 | 내용 |
| --- | --- |
| 세이 `창세` 중복 | 부착 지속이 5턴, 궁극기 쿨다운이 4턴이다. 두 번째 시전이 **아군 전체에 바위+바위 = 진동(기절)** 을 만든다. 제어 분쇄가 있어도 1회차 1턴 기절은 그대로 들어간다 |
| 세이 `창세` 만료 | 상태는 4**턴**인데 추가 피해 훅 회수는 `WaitForSeconds(4)`, 즉 4**초**다. 턴 축과 어긋나 있다 (`SeiSanctuary.ExpireAfter`) |
| 라이트 `하늘을 나는 꿈` | 아군의 **모든 원소를 먼저 제거**한다. 세이의 창세 바위, 테세우스의 `원소 친화 - 물`을 함께 지운다 |
