> **3계층 문서.** 기획이 끝난 모든 캐릭터의 사양. **획득처가 아직 없어도 여기에 적는다.**

## 0. 공통 규칙

```
피해     = 스킬 위력 × 주스탯 × 0.2        (위력은 스킬마다 고정)
최대체력 = CON × 100
방어력   = STR × 1  →  받는 피해 배율 = 기준값 / (기준값 + 방어력)
기준값   = 100 + 10 × (레벨 − 1)
고정 피해 = 방어력 감쇠를 받지 않는 피해 (DamageTag.TrueDamage)
```

| 규칙 | 내용 |
| --- | --- |
| **고유 P·고유 U** | 모든 유닛은 해금 패시브와 별개인 **고유 패시브 1개와 고유 궁극기 1개**를 가진다. 고유 패시브 원본은 코드 용량을 차지하지 않는다 |
| **열화 전수본** | `<전수 불가>`가 없는 고유 P는 원본 대신 별도 일반 `PassiveCode`인 열화 전수본을 후보로 기록한다. 시·수르트·츠쿠요미·케찰코아틀·테세우스·세이·찬드라·피그말리온의 고유 P는 전수 불가다 |
| **해금 패시브는 별개** | `levelPassives`는 고유 패시브와 별개이며 INT가 만드는 코드 용량 안에서 습득한다 |
| **일반공격 무명** | 일반공격과 강화 일반공격에는 고유 기술명을 붙이지 않고 UI에서 모두 `일반공격`으로 표기한다 |
| **일반공격 쿨타임 없음** | 발동 주기는 DEX가 만드는 행동치가 전담한다 |
| **장비 스킬 제외** | 장비가 부여하는 코드는 캐릭터 사양이 아니므로 여기에 적지 않는다 |
| **시작 숙련** | 모든 영웅은 최소 무기 1종을 가진다. 방어구 숙련은 캐릭터별 사양이며, 숙련이 없는 캐릭터는 숙련이 필요 없는 의복을 사용한다. 추가 숙련은 패시브로 얻으며 중복은 무효다 |

## 4. 수르트 (ID 24) — Starter

> 스스로 타들어 가며 세계를 끝내는 전열 화력.

| 항목 | 값 |
| --- | --- |
| 원소 | Pyro |
| 주/부 스탯 | **STR** / CON |
| 시작 숙련 | 장검 · 둔기 · 중갑 |
| 속성 | Nord |
| 초상화 `SURTR_PORTRAIT` | 스탠딩 `SURTR_STANDING` |
| 초기 사용 | 메인으로 즉시 선택 가능 |

### 4.1 스탯

기초/성장/트레이닝 보너스는 [공통 스탯 표](#스탯-표기-규칙)를 따른다.

**포지션** — STR이 방어력이 되면서 **파티 최고 화력이자 최고 실효 체력**.
STR 주력은 공격과 방어를 동시에 얻는다 — 의도된 이중 이득이다.
대신 DEX 12로 느리고 INT 8로 궁극기가 늦게 찬다.

### 4.2 코드

| 슬롯 | ID | 이름 | 내용 |

| **P** | 130 | **황혼** | 치명 피해를 전투당 1회 막고 **2초 경직** 후 최대 체력까지 회복, 해제 불가 황혼 상태 진입  · 🟡 단계 강화 미정 |

**황혼** — 라그나로크를 항상 6스택으로 유지한다. 매초 최대 체력의 2%부터 시작해
틱마다 1%p씩 증가하는 체력을 잃고, 체력이 소진되면 전투 불능이 된다. 라운드 종료 외에는 제거되지 않는다.
