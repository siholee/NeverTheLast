## 0. 공통 규칙

```
피해     = 스킬 위력 × 주스탯 × 0.2        (위력은 스킬마다 고정)
최대체력 = CON × 100
방어력   = STR × 1  →  받는 피해 배율 = 기준값 / (기준값 + 방어력)
기준값   = 100 + 10 × (레벨 − 1)
고정 피해 = 방어력 감쇠를 받지 않는 피해 (DamageTag.TrueDamage)
```

| 규칙 | 내용 |
| --- | --- |
| **고유 P·고유 U** | 모든 유닛은 해금 패시브와 별개인 **고유 패시브 1개와 고유 궁극기 1개**를 가진다. 고유 패시브 원본은 코드 용량을 차지하지 않는다 |
| **고유 P는 전수 불가** | **모든 고유 패시브는 전수되지 않는다.** 열화 전수본 제도는 폐지했다. 서포터 카드가 넘겨줄 수 있는 것은 해금 패시브뿐이다 |
| **추가 숙련 없음** | 모션 문제로 **숙련을 부여하는 코드는 전부 삭제**했다. 각 캐릭터는 시작 숙련으로 고정되며, 숙련 없는 장비는 장착은 되지만 중량만 적용되고 효과는 비활성이다 |
| **해금 패시브는 별개** | `levelPassives`는 고유 패시브와 별개이며 INT가 만드는 코드 용량 안에서 습득한다 |
| **일반공격 무명** | 일반공격과 강화 일반공격에는 고유 기술명을 붙이지 않고 UI에서 모두 `일반공격`으로 표기한다 |
| **일반공격 쿨타임 없음** | 발동 주기는 DEX가 만드는 행동치가 전담한다 |
| **장비 스킬 제외** | 장비가 부여하는 코드는 캐릭터 사양이 아니므로 여기에 적지 않는다 |
| **시작 숙련** | 모든 영웅은 최소 무기 1종을 가진다. 방어구 숙련은 캐릭터별 사양이며, 숙련이 없는 캐릭터는 숙련이 필요 없는 의복을 사용한다. **시작 숙련은 이후 어떤 코드로도 늘어나지 않는다** |

### 화상

화상은 불+풀 원소 반응 또는 코드의 직접 부여로 생기는 지속피해다. 보유자의 턴이 시작되면
**최대 체력의 5%** 피해를 입고 남은 턴을 1 감소시킨다. 지속시간이 따로 적혀 있지 않거나
원소 반응으로 발생하면 **2턴**, 세트의 궁극기로 직접 부여하면 **3턴**이다.
명중 확률은 `50% + (부여자 CON - 대상 CON) × 1%p`이며 10~90%로 제한한다.
