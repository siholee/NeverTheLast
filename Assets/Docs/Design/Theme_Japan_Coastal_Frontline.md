## 1. 핵심 방향

**행동불능으로 공허의 갑주를 벗기는 것이 첫 번째 해법이다.** 제어가 닿지 않는 동안에는 보호막을 두드리거나
지속피해로 우회하고, 남아 있는 STR 강화와 준비 공격을 견딘다.

해안은 공허 괴수의 상륙을 막는 동부 최전선이다. 초반에는 익숙한 공허의 기사·사수·프리즘이 **물·얼음 변형**으로 서서
아군을 먼저 얼린다. 그 경험이 3슬롯부터 나오는 갑주의 해법 — "멈춰 세우면 벗겨진다" — 의 힌트가 된다.

- 새 동물군의 방어 기믹은 **공허의 갑주** 하나로 통일한다. 병종별 갑각 파괴 규칙을 따로 외우게 하지 않는다.
- 문어 모티브는 엘리트 **심연의 공포**, 고래는 최종 보스 **심연의 집정관**에 집중한다.
- 스사노오는 집정관 격파 뒤 등장·합류·해금한다.
- 5슬롯은 공용 사건 목록을 쓴다. 테마 고정 사건을 넣지 않는다.

## 2. 공통 고유 코드 — 공허의 갑주 (1800)

### 2.1 효과

돌격대장·선봉대장·사냥꾼·공포가 고유 패시브로 갖고, 집정관은 자기 고유 패시브(1850)가 같은 갑주를 구간마다 두른다.
수치는 [Detail_09 §7-E.1](Detail_09_Enemy_Catalog.md)이 원본이다.

| 효과 | 내용 |
| --- | --- |
| 장착 | STR 강화 + 보호막(기존 누적형). 체력 배율 패시브가 붙은 뒤 재도록 한 프레임 뒤에 건다 |
| 해제 조건 | 실제 행동불능 진입(`OnControlStarts`) — 빙결·기절·에어본 등 |
| 해제 결과 | STR 강화 제거 + **갑주가 준 남은 보호막만** 제거 |
| 일반·엘리트 재생 | 없음 |
| 집정관 재생 | 구간 브레이크마다 재장착 |

STR 강화는 방어력과 STR 기반 공격을 함께 올린다. DEX·INT로 치는 사냥꾼·공포는 갑주를 벗겨도 화력이 크게 줄지 않는다 —
방어가 약해질 뿐이다. 이 차이가 "약화했다"와 "준비 공격을 끊었다"를 다른 가치로 만든다.

### 2.2 갑주를 벗겼다는 의미

- 해당 전투의 갑주 활성 상태가 사라진다. 패시브 정의는 남아 다음 전투에 다시 두른다.
- 이미 피해로 소진된 갑주 보호막은 다시 빼지 않는다. 다른 출처의 보호막·장비·원소·성장치는 남는다.
- 제어 없이 보호막을 때려 없애도 STR 강화는 남는다.
- STR만 바꾸므로 장착·해제가 최대 체력이나 현재 체력을 바꾸지 않는다.

### 2.3 인정하는 행동불능

- 면역이거나 제어 분쇄로 0턴이 되면 행동불능에 들어가지 않으므로 해제도 없다.
- 둔화·침묵·행동 게이지 감소는 해제하지 않는다. 대상 지정 불가와 행동불능을 혼동하지 않는다.
- 같은 제어 구간에서 상태가 겹쳐도 해제는 한 번이다(이미 벗겨진 갑주는 무시).
- **재장착 순간 이미 행동불능이면 새 갑주는 즉시 해제된다.** 제어 회차는 늘지 않는다.

### 2.4 두 가지 공략법

| 상태 | 해결법 | 남는 부담 |
| --- | --- | --- |
| 제어 가능 | 행동불능 → STR·갑주 보호막 제거 → 집중 공격 | 기본 방어력과 본래 공격 |
| 제어 면역·분쇄·공급 부족 | 지속피해로 보호막 우회, 또는 보호막을 두드려 소진 | STR 강화에 따른 방어력·STR 공격 |
| 방어막 관통 | 세이메이 결계 해독 — 필드에 서 있으면 아군 전체 | STR 강화에 따른 방어력·STR 공격 |

방어막 관통은 **방어력 관통이 아니다.** 지속피해의 보호막 우회는 기존 규칙 그대로이며, 집정관의 구간 경계까지 우회하지는 않는다.

## 3. 세이메이 — 관통 서포터

**해안 1슬롯을 이기면 합류를 제안한다.** 츠쿠요미처럼 해금 뒤에도 이번 런에 없으면 다시 제안한다 —
어떤 메인으로 들어왔든 제어 없이 갑주를 넘길 수단을 한 명은 확보하게 하는 안전장치다.
수치·코드는 [Detail_08 §23-A](Detail_08_Confirmed_Characters.md)가 원본이다.

| 코드 | 설계 의도 |
| --- | --- |
| P 결계 해독 | 필드에 **서 있기만 하면** 아군 전체가 보호막을 건너뛴다. 판정은 피해가 들어가는 순간이라 세이메이가 쓰러진 뒤 도착한 공격은 관통하지 않는다. 방어력 관통이 아니다 |
| N 봉인부 | 3회마다 기절 1턴. 준비 공격 중인 적 → 갑주를 두른 적 → 제어가 통하는 적 순으로 노린다. 원소를 붙이지 않아 반응 기절과 겹치지 않는다 |
| U 천지반전 | 아군 보호막을 **먼저** 준 뒤 적 전체 에어본. 에어본이 분쇄·면역에 막혀 준비 공격을 못 끊어도 받아낼 몫이 남는다. 스사노오의 천총운검을 연다 |

해금 패시브는 낮은 레벨부터 관통을 완성된 채로 주고, 성장은 보호·제어 보상에 나눈다. Lv10·20은 기존 공용 코드
(의술 70, 지혜 56)를 재사용해 2차안의 `두터운 부적 +15%`·`INT +5%`를 대체했다.

## 3-A. 극초반 무뎌진 무기 — 반응은 보여 주되 무너뜨리지 않는다

**원소를 붙이는 해안의 적은 Lv40까지 적 전용 T1 무기를 들고, Lv41부터 같은 분류의 범용 T2로 갈아 든다.**
적의 Level은 스테이지와 같으므로 해안이 첫 네 라운드(1~40스테이지) 안에 뽑히면 무뎌진 무기를 만난다.

| 무뎌진 결정 (432) | 내용 |
| --- | --- |
| 해로운 반응 위력 | ×0.5 — 증폭·즉발·지속피해·디버프·착근 지연 |
| 턴 상한 | 빙결 · 진동 기절 · 화상 **1턴** |
| 건드리지 않는 것 | 버프 반응(받는 쪽이 이득), 반응 성립 자체, 제어 분쇄 회차 |

- 반응을 없애지 않는다. 1·2슬롯의 "적이 나를 얼린다"는 경험과 행동제어의 힌트는 그대로 남고, 얼음이 3턴씩 연쇄하는 일만 막는다.
- **대상:** 공허의 기사·사수·프리즘의 원소 변형 21기(공허 원소 테마에도 같이 적용된다), 돌격대장·선봉대장·사냥꾼·공포. 집정관은 원소를 붙이지 않아 들지 않는다.
- Lv41부터의 범용 T2는 반응 약화가 없을 뿐 특별한 효과가 없다 — "제대로 된 성능"은 원래 반응 규칙 그대로라는 뜻이다. 스탯 +3이 함께 붙는다.
- 무기 규격·목록은 [Detail_14 §6.E](Detail_14_Equipment_Catalog.md). T1이 코드를 주는 유일한 예외이며 보상·상점에 나오지 않는다(`enemyOnly`).

## 4. 병종 설계 의도

수치는 [Detail_09 §7-E](Detail_09_Enemy_Catalog.md)와 [Detail_11 §2.15](Detail_11_Code_Catalog.md)를 본다.

### 4.1 초반 재사용 병력 — 물·얼음 공허

**기사(물) 1096 하나**와 기사·사수·프리즘의 **얼음 변형(1100·1108·1068)**을 그대로 편성한다. 사본을 만들지 않고 갑주도 붙이지 않는다.
각자 궁극기가 자기 원소를 붙이므로, 한 아군에게 물과 얼음이 겹치면 **빙결**, 얼음끼리는 **둔화**가 터진다.

**버프 반응은 원소가 붙은 쪽이 가져간다**([Detail_16 §8](Detail_16_Elements.md)). 물 공급원이 둘이면 물+물 **정수(INT 버프)**가
아군에게 가므로 슬롯마다 물은 한 곳에서만 붙인다. 같은 이유로 바위(선봉대장)는 불·얼음과 **열을 나눈다**(단조·경화).

- 1·2슬롯은 적이 아군을 얼리는 경험 자체가 목적이다. "행동불능은 이런 것이다"를 먼저 몸으로 보여 준다.
- 2슬롯을 이기면 서리 앉은 곳부터 갈라진 껍질을 보는 예고 사건이 뜬다 — 3슬롯의 갑주를 얼려서 벗긴다는 힌트.
- 3슬롯의 돌격대장은 물을 붙이는 전열이라 얼음 기사·프리즘과 같은 조합을 이어 간다.
- 적의 빙결은 유발자 CON에 비례해 1~3턴이다. 고레벨에서 3턴 빙결이 연달아 걸리면 체감이 가혹할 수 있어 검증 항목에 둔다.

### 4.2 공허의 돌격대장 — STR 강화를 체감하는 전열 (게, 물)

갑주가 있으면 단단하고 아프다. 벗기면 공격과 방어가 함께 약해진다. 궁극기가 물을 붙여 빙결 조합의 한 축이 된다.

### 4.3 공허의 선봉대장 — 느리고 두꺼운 벽 (거북, 바위)

CON이 높아 체력과 갑주 보호막이 크지만 느리다. 궁극기가 아군 **전열에만** 바위를 붙인다.
둘이 서면 바위+바위 **진동(기절)** — 적이 아군을 멈춰 세우는 두 번째 힌트다. 돌격대장의 물과는 **풍화**(지속피해)가 된다.
불(단조)·얼음(경화)과 만나면 아군 버프가 되므로, 사냥꾼·얼음 사수처럼 **후열에 붙이는 적**하고만 같은 슬롯에 둔다.

### 4.4 심연의 사냥꾼 — 갑주를 두른 후열 사냥꾼 (상어, 불, 일반)

2차안 갈매기의 자리다. 아군 후열을 먼저 물고, 궁극기로 후열 전체에 불을 붙인다.
주공격이 DEX라 갑주를 벗겨도 화력은 남는다 — 대신 방어가 약해져 빠르게 정리된다.
불은 후열에 남은 얼음·물과 융해·증발을 만든다. 바위와 만나면 단조(아군 DEX 버프)라 선봉대장과는 열이 겹치지 않게 둔다.

### 4.5 심연의 공포 — 준비 공격을 끊는 법 (문어, 바람, 엘리트)

- 갑주를 벗겨도 INT 화력은 남는다. 제어를 **앞의 갑주**에 쓸지 **촉수 폭풍 준비**에 쓸지 고르게 한다.
- 촉수 폭풍의 바람 부착은 확산 반응으로 아군에 남은 원소를 퍼뜨린다.
- 촉수는 본체 스킬 연출이며 소환체를 늘리지 않는다.
- 8슬롯을 이기면 물이 빠져나가는 바다를 보는 예고 사건이 뜬다 — 대호흡도 같은 방법으로 끊는다는 힌트.

## 5. 최종 보스 — 심연의 집정관

### 5.1 목표 경험

**갑주 제거에 쓸 제어와 해일을 끊을 제어가 모두 필요하다.** 체력 구간을 넘길 때마다 갑주가 다시 생겨,
첫 제어 한 번으로 전투 끝까지 방어 기믹을 없앨 수 없다. 6개 갑주와 모든 해일을 전부 제어로 처리하라고 요구하지 않는다 —
**제어를 쓸 구간과 두드려 넘길 구간을 나누는 것이 보스의 중심**이다.

### 5.2 체력 6구간 — 판정 계약

| 페이즈 | 체력 범위 | 갑주 |
| --- | --- | --- |
| 1 | 100% → 83.3% | 입장 시 장착 |
| 2~5 | 경계마다 | 브레이크 후 재장착 |
| 6 | 16.7% → 0% | 마지막 장착, 다음은 실제 사망 |

- 6구간은 체력 표시와 브레이크 단위다. 최대 체력 배수는 알파 개체·완전함에서만 온다.
- 브레이크 때 체력을 회복하지 않는다. 갑주 STR 강화는 갱신이며 겹치지 않는다.
- 옛 갑주 보호막이 남아 있으면 걷고 새 구간 기준 보호막을 한 번 준다. 다른 출처 보호막은 지우지 않는다.

**처리 순서: 기존 피해 계산 → 보호막 흡수(또는 관통·지속피해 우회) → 체력 손실을 현재 구간 하한으로 제한 → 브레이크 → 재장착.**

보호막보다 먼저 구간 잔량으로 피해를 자르면, 경계까지 1 남았을 때 큰 공격도 보호막에 1밖에 못 넣는다.
그래서 `IncomingDamageCapRatio`(보호막 전 상한)가 아니라 **체력 손실에만 적용되는 `BaseEffect.HpLossFloor`** 훅을 새로 두었다.

- 한 번의 피해는 한 구간만 넘긴다. 다단 공격은 타격마다 새 갑주를 만난다.
- 경계는 매번 최대 체력에서 다시 잰다. 최대 체력이 바뀌어도 현재 구간 번호는 그대로다.
- 재장착은 피해 처리(`OnAfterDamageTaken`) 안에서 일어나므로, 같은 공격의 뒤따르는 제어가 새 갑주를 벗길 수 있다.
- 처형은 일반 등급만 대상이라 구간을 건너뛰지 못한다.

### 5.3 해연의 대호흡 → 해일

1. 입장 후 일반행동 2회를 마쳤고 자원이 찼으면 대호흡을 준비한다. 자원은 준비에 쓰이고 피해는 없다.
2. 다음 자기 일반행동이 해일로 바뀐다. 피해는 **해일이 나가는 순간의 STR**로 계산한다. **원소를 붙이지 않는다** —
   물을 연달아 붙이면 정수(INT 버프)가 아군에게 가므로, 대신 위력을 올렸다([Detail_10 §4-E.2](Detail_10_Boss_Catalog.md)).
3. 준비 중 실제 행동불능이면 예약이 사라지고 자원은 돌아오지 않는다.
4. **브레이크는 준비를 취소하거나 미루지 않는다.**
5. 매 3번째 일반행동은 꼬리 휩쓸기다. 해일로 바뀐 회차도 순번 하나로 세지만 꼬리 휩쓸기를 겹쳐 쓰지 않는다.

갑주와 준비가 동시에 켜져 있으면 **한 번의 제어가 둘 다 해결**한다. 따로 때려야 하는 인위적 제한을 두지 않는다.

### 5.4 수치 기준

집정관 체력은 오딘 기준 보스 목표(100스테이지 250,000)의 약 85%로 잡았다 — 반복 갑주와 구간 경계의 초과 피해 손실 몫이다.
2차안의 비교표(종말의 거인 21,200 · 공허의 용 49,000 등)는 적 체력 정규화 이전 값이라 지웠다.
현재 실효 체력·갑주 보호막 표는 [Detail_09 §7-E.2](Detail_09_Enemy_Catalog.md)에 있다.

Lv50 기준 갑주 활성 여부에 따른 같은 공격의 방어 배율(기준값 590):

- 갑주 없음: `590 / (590 + 283) ≈ 0.676`
- 갑주 있음: `590 / (590 + 396) ≈ 0.598`

관통·지속피해는 보호막만 건너뛰므로 두 번째 감쇠를 그대로 받는다. 이 차이가 "갑주를 벗기는 1차 해법"의 가치다.

## 7. 검증과 조정 기준

### 핵심 비교 파티

1. 충분한 제어 + 직접 공격.
2. 세이메이 관통 + 제한된 제어 + 치유/보호막.
3. 지속피해 중심 + 생존 지원.
4. 제어·관통이 모두 부족한 고화력 파티.

같은 투자에서 1·2가 자연스러운 해법이 되는 것이 목표다. 제어가 분쇄되는 구간에도 2는 계속 진행할 수 있어야 한다.
4는 충분한 성장으로 정면 돌파할 수 있지만, 같은 투자에서는 보호막과 강한 공격을 오래 상대해야 한다.

### 필수 확인

- 갑주 장착 · 제어 해제 · 제어 실패(분쇄·면역) · 보호막만 소진의 네 상태가 다르게 처리되는가.
- 갑주와 외부 보호막이 함께 있을 때 자기 몫만 지워지는가.
- Lv40 이하에서 무뎌진 무기가 빙결을 1턴으로 묶는가, Lv41부터 원래 턴 수로 돌아오는가.
- Lv41 이상 1·2슬롯의 아군 빙결이 과하지 않은가(3턴 빙결 연쇄).
- 세이메이가 벤치·사망·퇴장하면 관통이 즉시 끊기는가. 관통 피해가 갑주 장부를 줄이지 않는가.
- 해일(고정 120 + STR 125)이 갑주 유지 상태에서 즉사 수준이 아닌가.
- 한 열이 비어 선봉대장·사냥꾼의 열 공격이 전원으로 퍼질 때 단조가 얼마나 나는가.
- 집정관 구간 경계 바로 앞에서도 비관통 공격이 보호막에 큰 피해를 넣는가.
- 큰 단발·다단·지속피해·제어 중 브레이크에서 구간이 한 번씩만 진행되는가.
- 준비 중 브레이크가 나도 해일이 남고, 실제 행동불능에는 취소되는가.
- 스사노오 합류가 실제 최종 사망 뒤 한 번만 뜨는가.

과하게 길면 **집정관 체력 → 갑주 보호막 기준량 → 구간 수 6→5** 순으로, 해일이 즉사 수준이면
**해일 위력 → 갑주 STR 보너스** 순으로 조정한다. 제어가 부족하다는 이유로 면역을 무시하는 전용 제어를 주지 않는다.
