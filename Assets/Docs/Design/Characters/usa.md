# 우치 · ID 180

최종 갱신: **2026-10-14**

[아군 목록·성장값](../Detail_08_Confirmed_Characters.md) · [고유 코드 색인](../Detail_11_Code_Catalog.md)

분신을 찍어 내 대신 싸우게 하는 도사. 빠를수록 많이 만들지만, 너무 빠르면 분신이 넘쳐 흩어진다.

원화 키: `USA_PORTRAIT` / `USA_STANDING`. 현재 데이터가 아트 연결의 원본이다.

## 현재 코드

- **P380 도사란 무엇인가**: <고유 특성> 분신을 최대 3기 거느린다. 분신은 고정 속도 70으로 제 차례에 우치 공격력 120%로 한 번 치고 사라진다. 상한에서 새 분신이 생기면 가장 오래된 분신이 즉시 60%로 치고 사라진다. 우치가 최대 체력 15% 이상인 한 방을 맞으면 분신 1기가 대신 맞고 사라진다(한 적 행동당 1기).
- **N180 분신술**: 분신 1기를 만든다. 피해를 주지 않는다.
- **U180 만천화우**: <마나 100> 분신을 모두 소모해 각각 우선도 적에게 우치 공격력 300% 피해. 분신이 없으면 분신 2기를 만든다. #다중 #궁극기 #접촉 #타격

## 세부 판정과 투자

> **분신을 찍어 내는 소환 딜러.** 우치 자신은 때리지 않는다. 일반행동은 분신을 하나 만들 뿐이고, 분신이 **제 속도로**
> 움직여 한 번 공격하고 사라진다. 초월기는 분신이 스스로 움직이기 전에 한꺼번에 세게 터뜨린다.
> 분신의 이득은 **우치 혼자** 본다(공격 · 대신 맞기). 다른 캐릭터는 소환수 규칙(생성 · 소멸 판정)을 통해서만 엮인다.

| 분류 / 원소 | Unlocked (해금 조건은 아직 없다) / 바람 (`Anemo`) |
| 소속 | 화령 · 짐승 (`Hwaryeong` · `Beast`, 개편 전 데이터) |

### 분신

| 항목 | 값 |
| --- | --- |
| 상한 | **3기**. 칸을 차지하지 않고 우치 카드 뒤에 겹쳐 서며, 적의 대상이 되지 않는다 |
| 속도 | **고정 70** (AV 약 143). 우치의 스탯 · 버프를 물려받지 않는다 |
| 행동 | 생성된 뒤 제 차례가 오면 우선도 적에게 우치 공격력 **120%** `#단일 #일반 #접촉 #타격`을 한 번 주고 **사라진다** |
| 넘침 | 상한에서 분신이 새로 생기면, 넘친 수만큼 **가장 오래된 분신부터 즉시 공격하고 사라진다.** 이 공격은 **60%(절반)** 만 준다. 그 뒤 새 분신이 들어온다 |
| 넘침의 출처 | 일반행동 · 초월기 · 외부 생성 API 모두 같다 |
| 우치 사망 / 라운드 종료 | 사망: 남은 분신이 모두 흩어진다(소멸 판정, 피해 없음). 라운드 종료: 사라질 뿐 소멸 판정 없음 |

분신이 사라지는 모든 경우(제 공격 · 넘침 · 대신 맞기 · 초월기)는 **소멸(사망) 판정**이다.

### 특성 — 도사란 무엇인가 (P 380)

- 분신을 거느린다(§10.1).
- **대신 맞기:** 우치가 **최대 체력 15% 이상**인 한 방을 맞으면 분신 1기가 사라지고 그 피해를 무효화한다. 한 적 행동당 1기. 우치 자신만 보호한다.

대신 맞기로 사라진 분신은 공격하지 않는다 — 생존과 화력이 같은 분신을 두고 다툰다.

### 일반행동 — 분신술 (N 180)

분신 **1기 생성**. 피해를 주지 않는다. 일반행동이므로 마나 +20을 받고 `NotifyActionResolved()`를 부른다.

### 초월기 — 만천화우 (U 180)

마나 100. 보유한 분신을 **모두** 소모해 각각 우선도 · 무작위 적에게 우치 공격력 **300%** `#궁극기 #접촉 #타격`(`20_codes.yaml` 표기는 `#다중`; 타격 하나하나는 단일 대상 판정이다).
분신이 하나도 없으면 대신 분신 2기를 생성한다. 마나는 일반행동 +20이 주 충전원이라 **약 5행동마다** 돈다.

분신이 제 차례에 120%를 주는 대신 초월기로 300%를 주므로, **분신이 움직이기 전에 초월기를 많이 겹칠수록 이득**이다.

### 속도의 양날

분신 속도가 고정이므로, 우치의 속도만 분신의 **평균 보유 수**(= 분신 AV ÷ 우치 AV)를 정한다.

| 우치 속도 | 우치 AV | 평균 보유 | 상태 |
| ---: | ---: | ---: | --- |
| 118 (기본) | 85 | 약 1.7 | 여유. 초월기가 분신 약 2기를 잡는다 |
| 150 | 67 | 약 2.1 | 초월기 효율이 오르고 주기도 빨라진다 |
| 170 | 59 | 약 2.4 | **상한 3에 자주 닿는다** — 행동 직후 넘침이 섞이기 시작 |
| 200 | 50 | 약 2.9 | 거의 매 행동이 넘침. 분신 하나가 120% 대신 60%로 흩어진다 |

속도는 초월기를 자주, 크게 돌리게 해 주지만 **어느 선을 넘으면 일반행동이 넘침으로 날아간다.**
속도 코드(바람의 발걸음 · 질풍신뢰 · 주문 가속)와 신속의 비약을 얼마나 줄지가 우치 빌드의 결정이다.

### 화력 위치
