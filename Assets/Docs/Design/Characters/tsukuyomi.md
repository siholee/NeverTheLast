# 츠쿠요미 · ID 45

최종 갱신: **2026-10-21**

[아군 목록·성장값](../Detail_08_Confirmed_Characters.md) · [고유 코드 색인](../Detail_11_Code_Catalog.md)

높은 기본·성장 체력과 방어로 전열을 지키며, 전체 보호막·달의 저주·모든 지속피해 증폭을 제공하는 서브탱커 겸 서포터.

원화 키: `TSUKUYOMI_PORTRAIT` / `TSUKUYOMI_STANDING`. 현재 데이터가 아트 연결의 원본이다.

## 현재 코드

- **P245 달이 보지 않는 밤**: 필드에 있는 동안 아군 전원의 지속피해를 독립적으로 증폭한다. 증가량은 자신의 특수공격력 / (100 + 레벨당 6) × 20%. 모든 지속피해와 야마의 즉시 발동에 적용. 전투 시작 시 생존 필드 아군 전체에 자신의 현재 방어력 300% 보호막(전투당 1회).
- **N45 말없는 저주**: 공격력 70% 단일 주문 피해 후 저주 부여. 원소는 부착하지 않는다. 저주는 생성자의 일반행동 시작에 특수공격력 50% 피해, 대상 일반행동 2회 유지. #일반 #주문 #비접촉
- **U45 달 아래의 계약**: 아군 전체 특수공격력 +자신 특수공격력의 20%(시전 시점, 자신의 기존 계약 제외). 자신의 일반행동 2회 유지. 생존 필드 아군 전체에 자신의 현재 방어력 550% 보호막. 적 전체에 저주를 부여한다. 마나 140.

- P245 **달이 보지 않는 밤**: 필드에서 아군 모든 지속피해에 독립 배율 `1 + 0.20 × 츠쿠요미 현재 특공 / (100 + 6 × (레벨-1))`. 기존 지속피해 보상 배율 뒤 한 번 적용하며 야마의 즉시 발동도 포함한다. 같은 오라의 가장 큰 하나. 즉발 원소 반응·일반 추가 피해는 제외.
- N45 **말없는 저주**: 공격력 70% 비접촉 단일 주문 뒤 저주 직접 부여(통상 효과 명중). 원소 부착 없음.
- U45 **달 아래의 계약**: 아군 전체 특공에 자기 시전 시 특공 20%를 고정 가산. 자신의 기존 계약 값은 산정에서 제외하고 재시전은 갱신한다. 츠쿠요미 일반행동 2회, 사망·라운드 종료 시 해제. 생존 필드 아군 전체에 현재 방어력 550% 보호막. 적 전체 저주 직접 부여. 마나 140.

저주: 생성자의 일반행동 시작에 생성자 현재 특공 50%를 기반으로 발동. 기간은 대상의 일반행동 2회이며 생성자 행동으로 기간이 줄지 않는다. 같은 종류 1개, 성공한 재부여는 남은 기간만 갱신한다. 감전·화상·맹독도 함께 지원한다. 원소 재료는 동료가 제공해야 한다.

보호막은 자신·독립 소환수를 포함한 생존 필드 아군에게 공통 `AddShield`로 부여한다. 각 대상의 기존 보호막에 누적하며 공통 보호막 보정을 한 번 적용한다. 전투 종료 시 공통 정리하고 지속피해·반응의 보호막 우회 규칙은 유지한다. 개전 알림과 중복 활성은 개전 보호막을 중복 부여하지 않는다. 개전은 방어력300%, 초월기는 방어력550%로 정규 방어 서포터 수준의 전체 방호를 제공한다. 초월 마나140이며 바루나의 특수행동·자기 제방 같은 반복 방호는 없다. 우수한 방어를 활성화하면 초월기의 기본 보호막을 개전 시 한 번 더 부여한다.

투자는 특공(지딜 증폭·특공 공유), 방어력(보호막), 속도·마나 수급(초월 주기), 체력·특방(전열 생존)으로 나뉜다. 방어력만으로 지딜 증폭이 커지지는 않는다.

기본 추천 위치는 전열이다. 지딜 편성에서는 에레쉬키갈과 전열을 나누고, 감전은 바루나·혼합은 세트도 전열에 둔다. 특공 오라를 유지할 생존과 피격 마나를 확보하지만 별도 도발·피해 분담은 없다.
