바람 속성 후열 반격·치유 서포터. 적의 차례를 당겨 반격을 유도하고 추가행동·반격의 치명타 피해를 키우며, 초월기로 공격력 기반 전원 치유를 제공한다. 유효 스탯은 공격력·특공·치피·속도다. 체력·방어 투자가 치유량으로 전환되지 않으며 단독 전열용 내구를 제공하지 않는다. 배치 자체를 금지하지는 않는다.

## 코드와 판정

- **P362 아직 남아 있어!**: 타겟 우선도 -1. 전투 비약이 실제 적용될 때 25% 확률로 소모한 비약 1개를 돌려준다. 준비 중 비약을 예약하는 순간에는 판정하지 않는다. 적용 전 취소·중복 사용·미보유에는 발동하지 않는다. 심장 제세동기(보상638)가 치명상을 막을 때도25% 확률로 코드 한 장의 소비를 막는다. 보존되면 이후 치명상에도 재사용할 수 있다. 같은 특성이 여러 개여도 한 비약/제세동기 발동에 한 번만 판정한다. 식량·넥타르·승급 도구·판매·보상 즉시 효과는 제외한다.
- **N162 이쪽이야, 따라와!**: 피해 없는 일반행동. 적 전체에 가하는 피해 -25%를 다음 일반행동 완료까지 부여하고, 성공한 적의 다음 행동을 전체 AV의20%만큼 앞당긴다. 특공/특방 효과 명중과 상태 저항을 한 번 통과한 상태가 두 효과를 함께 연다. 제어 디버프가 아니다. 정상 완료 시 일반행동 해결과 마나20을 한 번 발행한다. 공격이 아니므로 나폴레옹의 일제사격에 참여하지 않는다.
- **U162 되돌려줄 시간이야!**: 마나120. 시전 시 자신의 치피30%를 스냅샷해 아군 전원의 **추가행동 치명타 피해**에 가산하고, 반격이면 자신의 치피30%를 추가 가산한다. 각 수혜자의 일반행동2회 완료까지 유지하며 같은 키는 갱신한다. 치피70%면 일반 추가행동에 +21%p, 반격에는 총+42%p. 바스테트 후속도 기본 보너스를 받는다. 일반행동·특수·초월기·지속피해에는 적용하지 않는다. 살아 있는 아군 전원을 **자신의 현재 공격력600%**만큼 치유한다. 공통 치유 보너스·치유 보상 코드를 적용한다. 적 방어력 감소·강화 해제는 제거했다. 피해·원소 부착·부활·정화는 없다.

적 가속은 반격 횟수와 마나 피격 충전을 늘릴 수 있지만 반격 기회를 소진한 뒤에는 위험하다. 잔의 선제 얼음 반격이 공격자를 처치·빙결하면 원 공격은 취소되므로 가속이 항상 피격 횟수를 늘리지는 않는다. 특공은 일반행동 피해 감소·가속의 명중, 공격력은 치유, 치피는 반격 지원, 속도·마나 효율은 초월기 회전을 담당한다.

## 스탯·편성

HP820(+72) · 공격92(+6.4) · 특공108(+7) · 방어48(+3.8) · 특방74(+5.4) · 속도110 · 치확5% · 치피70%. 속도·치명 스탯은 레벨 성장 없음.

초월기의 자동 시전은 살아 있는 아군 중 체력90% 이하인 대상이 있을 때 허용한다. 만피에서 치피 버프만을 위해 마나를 소모해 치유를 전부 과회복시키지 않으며, 부상 시 마나가 충족되어 있으면 공통 스케줄러가 시전한다. 예약 자원이나 별도 행동 게이지를 도입하지 않는다.

추천: **오리온 / 바스테트 / 아스톨포 / 세이 / 마리 테레즈**. 아스톨포·세이·마리를 공통 코어로 두고 메인 딜러를 잔·세트 등으로 교체한다. 바스테트는 기본 추가행동 보너스를, 반격 딜러는 추가 반격 보너스까지 받는다. 정확한 전후열은 `30_synergies.yaml`에 둔다. 아마테라스를 사용하는 종전 반격 조합과 별도로 비교한다.

**잔 반격**은 **전열 잔 / 후열 세이·바스테트·아스톨포·니콜**이다. 아스톨포가 마리의 치유 자리를 맡고 니콜이 번개 부착과 방깎·공방 중첩을 제공한다. 잔에게 피격을 집중하며 세이는 후열에서 보호막·집중 경감을 제공한다. 에비스와 잔·세이 2인 전열 변형은 반격 대표 비교에서 제외한다. 기존 오리온 편성의 마리는 얼음 부착과 상시 치유를 남기는 선택지다.
