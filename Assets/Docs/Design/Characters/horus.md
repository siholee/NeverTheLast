- 지휘 사격은 기본 파성의 화살을 빌리며 해방 기간·일반행동 마나를 발생시키지 않는다.
- 기본 강인도 삭감은 파성30, 소사 주대상30/기타15. 두 소사 경로 모두 같은 고유 삭감량이며 별도 삭감 증가 버프는 없다. 오르페우스·보상 코드의 공통 효율을 곱한다.

- 예약 대상이 사망하면 살아 있는 우선도 적으로 교체한다. 직접 공격 공통 대상 교체·선제 개입을 거친다. 사망·정지·라운드 종료는 이전 세대 예약을 무효화한다.
