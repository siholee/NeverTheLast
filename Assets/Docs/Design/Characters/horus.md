# 호루스 · ID 120

최종 갱신: **2026-10-14**

[아군 목록·성장값](../Detail_08_Confirmed_Characters.md) · [고유 코드 색인](../Detail_11_Code_Catalog.md)

마나형 초월기 딜러 하나에게 왕권과 에너지를 집중하는 태양의 후견인.

원화 키: `HORUS_PORTRAIT` / `HORUS_STANDING`. 현재 데이터가 아트 연결의 원본이다.

## 현재 코드

- **P320 태양의 후계자**: 편성상 앞선 마나형 공격 초월기 아군1명 지정(자신 제외, 사망/이탈 시 교체). 필드에 있는 동안 대상 초월기 피해+(25%+특공/K×15%p), 최대55%. 일반/지속/특수 피해에는 적용하지 않음.
- **N120 태양의 화살**: 공격력80% 단일 비접촉 사격. 일반 마나20. 원소 부착 및 아군 에너지 충전 없음.
- **U120 지평선의 왕관**: 마나120. 지정한 후계자의 초월기 피해+30%(대상 일반행동2회), 이후 최대 마나30% 충전. 버프를 먼저 부여. 자신/고유중첩/상시 초월기 충전 불가. 대상이 없으면 자원 소비 없음.

불 속성, 부착 없음. P320/N120/U120, 마나120. 특공·속도 중심 후열 지원. 일반공격의 화력은 낮으며 서브딜러/일반공격 버프 특성안은 폐기했다.

- **태양의 후계자:** 본인 제외, 편성 순서상 앞선 **마나형 초월기 피해 딜러** 아군1명을 고정 지정. 살아 있고 필드에 있는 동안 유지, 사망/이탈/자격 상실 시 다음 적격자로 교체. 특성은 지정 대상의 초월기 피해만 `min(55%,25%+특공/K×15%p)` 증가(K=100+6×(Lv-1)). 일반/지속/특수 피해 증폭 없음. 고유중첩/상시/초월기 피해를 제공하지 않는 지원 초월기는 대상이 아니다. 아그니처럼 초월기로 추가공격에 초월기 피해 판정을 주는 딜러도 포함한다.
- **태양의 화살:** 공80% 단일 비접촉 사격. 원소 부착·동료 충전 없음. 일반행동 기본 마나20만 본인이 받음.
- **지평선의 왕관:** 후계자에게 초월기 피해+30%(대상 일반행동2회)를 먼저 부여한 뒤 최대 마나30% 충전. 특성과 같은 초월기 피해 분류로 가산. 자신이나 고유자원을 충전하지 않음. 적격자가 없으면 시전/자원 소모 없음. 특성 오라는 호루스 사망/정지 시 제거, 이미 준 유한 왕관 버프는 대상의 기간 동안 유지.
- 원화 HORUS 재사용. 신규 임시 보이스 없음. 서포터 슬롯을 치유/보호막 대신 단일 초월기 화력과 회전율에 투자하는 구조.
