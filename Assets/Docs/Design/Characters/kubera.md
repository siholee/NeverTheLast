# 쿠베라 · ID 65

최종 갱신: **2026-10-14**

[아군 목록·성장값](../Detail_08_Confirmed_Characters.md) · [고유 코드 색인](../Detail_11_Code_Catalog.md)

재보를 불리고 거래 공격의 치명타를 후원한다. 로카팔라에서는 재보와 금력으로 골드 러쉬를 강화한다.

원화 키: `KUBERA_PORTRAIT` / `KUBERA_STANDING`. 현재 데이터가 아트 연결의 원본이다.

## 현재 코드

- **P265 재보천의 후원**: 아군 필드 오라. 재보를 실제 충전·소비한 공격에 쿠베라 자신의 치명타 피해 30%만큼 치피 가산. 중복은 높은 하나. 소환 시너지 없음.
- **N65 금화 투척**: 단일 공격력90% 사격. 유효 공격 시 공용 재보+1(상한12). 지휘 사격은 생산하지 않음. 실제 증가가 있는 공격만 후원 치피 적용.
- **U65 복리의 보고**: 마나120. 사용 가능한 재보 R을 읽고 1+floor(R×25%) 충전. 예약 제외·공용 상한12. 피해·소환·원소 부착 없음.
- **SP65 골드 러쉬**: 금력×공격력100% 전체 사격. 재보3 이상이면3 소비하여180%로 강화하고 후원 치피 적용. 부족하면 소비 없이100%. 사용당 전투 골드+5%(최대25%).

## 세부 판정과 투자

2026-10-10 리워크. P265/N65/SP65/U65 ID와 바위 원소·기존 성장 스탯은 유지한다. 개인 보물8·소환수 피해 오라·소환 생성 보너스·추가 소환은 삭제했다. 초월 자원은 **마나120**이다.
