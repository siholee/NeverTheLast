# 이슈타르 · ID 220

최종 갱신: **2026-10-15**

[아군 목록·성장값](../Detail_08_Confirmed_Characters.md) · [고유 코드 색인](../Detail_11_Code_Catalog.md)

모은 재보를 황금 탄창에 채워 풀 원소 단일 포격으로 소진하는 헤비 슈터.

원화 키: `ISHTAR_PORTRAIT` / `ISHTAR_STANDING`. 현재 데이터가 아트 연결의 원본이다.

## 현재 코드

- **P420 황금 탄창**: 자신이 재보1을 실제 소비할 때마다 초월기 피해+4%p. 최대12중첩, 현재 탄부터 적용. 재소비로 갱신하고 다음 자기 일반행동 종료 시 모두 만료. 예약·반환·다른 아군 소비는 제외.
- **N220 금성 사격**: 단일 공격력80% 사격, 풀1회 부착(효과 명중). 재보 생산 없음.
- **U220 왕권의 일제 포격**: 마나140·재보1 이상 필요. 사용 가능 재보를 탄창에 예약해 탄마다1 소비하여 공격력120% 단일 연사. 독립 치명·처치 시 표적 재선정. 첫 유효 탄만 풀 부착. 전체 초월기1회. 취소 시 미발사 재보 반환.

## 세부 판정과 투자

메소포타미아·풀·재보/방출. P420/N220/U220, 마나140. 2026-10-11 사용자 제공 이슈타르 원화(`ISHTAR_PORTRAIT` / `ISHTAR_STANDING`)·임시 토파즈 보이스. 성장 및 산술 원본은 [재보 사양 §4·6](../Detail_18_Treasury.md).

- P420 황금 탄창: 자신의 재보 실제 소비1마다 초월기 피해+4%p(최대12층), 다음 자신의 일반행동 종료까지. 해당 탄부터 적용, 예약/반환/다른 아군 소비에는 발동하지 않는다.
- N220 금성 사격: ATK80% 단일 사격·풀 부착, 재보 생산 없음.
- U220: 시전 시 가용 재보를 탄창 예약, 탄마다1실소비·ATK120% 단일 사격. 첫 유효 탄에서만 풀 부착/마나 지불/초월 발동 알림. 표적 사망이면 다음 우선도 적으로 이어 쏘고 경호/타겟 라우팅을 다시 검사한다.
- 유한 탄창의 실제 탄 소비·타격마다 정지 감시 시간을 갱신한다. 정상 연사를 총8초라는 이유만으로 자르지 않으며, 다음 유효 탄 진행이8초 이상 멈추면 강제 중단·미발사 반환한다.
- 연사 전체는 초월 행동1회, 탄수만 실제 타수. 중단/제어/전멸 시 미발사 반환. 예약 중 신규 충전은 다음 행동으로 보존, 상한12 유지. 자체 재보 생산 없음.
