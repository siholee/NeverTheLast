# 바루나 · ID 66

최종 갱신: **2026-10-14**

[아군 목록·성장값](../Detail_08_Confirmed_Characters.md) · [고유 코드 색인](../Detail_11_Code_Catalog.md)

법으로 혼돈을 다스리는 물의 판결관. 물을 붙일수록 제방이 쌓이고, 같은 법 아래 모두에게 같은 보호를 내린다.

원화 키: `VARUNA_PORTRAIT` / `VARUNA_STANDING`. 현재 데이터가 아트 연결의 원본이다.

## 현재 코드

- **P266 법이 만든 제방**: <고유 특성> 자신의 행동으로 적에게 물을 부착하면 현재 방어력 35%의 보호막을 자신에게 얻는다. 광역 · 확산으로 여러 명에게 붙어도 행동당 한 번이며, 기존 보호막에 누적된다. 물 부착이 없는 특수행동에서는 발동하지 않는다.
- **N66 금줄**: 단일 적에게 공격력 90% 피해를 주고 물을 부착한다. 부착하면 현재 방어력 35%의 보호막을 얻는다(제방). #단일 #일반 #비접촉 #주문
- **U66 동일한 법 아래**: <마나 100> 적 전체에 공격력 120% 피해를 주고 물을 부착하며, 생존한 필드 아군 전원(자신 포함)에게 바루나 현재 방어력 100%의 보호막을 준다. 물 부착으로 제방 보호막(자신 35%)도 따로 얻는다. #전체 #궁극기 #비접촉 #주문
- **SP66 넘치는 판결**: <로카팔라> 적 전체에 공격력 70% 피해를 주고 생존한 필드 아군 전원(자신 포함)에게 바루나 현재 방어력 100%의 보호막을 준다. 바유 뒤 · 쿠베라 앞(-50)에 행동한다. 물 부착이 없어 제방 보호막도 없다. #전체 #특수행동 #비접촉 #주문

## 세부 판정과 투자

> 세부 기획 확정(2026-10-05) · 코드 구현 · Unity 전투 검증 · 전용 연출 및 SFX 검수 완료(§16.5). 인간의 혼돈을 법으로 조율하려는 진중한 판결관.
> 물 부착·보조 공격·방어력 기반 누적 보호막을 담당한다. 전열 배치로 버티지만 공격 방향을 강제로 통제하지 않는다.

### 특성 — 법이 만든 제방 (P 266)

자신의 행동으로 적에게 물을 부착하면 자신에게 **현재 방어력 35%** 보호막. 광역도 행동당 한 번.
물 부착 직후 반응으로 물이 소비되어도 발동한다. 자기 출처의 물 부착만 인정하며, 자기 행동에 딸린 확산으로 여러 명에게 붙어도 한 번.
N/U의 실제 물 부착 시점과 행동 예약/종료 구간을 사용하고 턴 수만으로 제한하지 않는다. SP에는 물 부착이 없으므로 특성 보호막도 없다.
보호막은 `AddShield`로 기존 보호막에 **누적**. 생성량에 최대 체력/공격력/특공/피해 보너스를 사용하지 않는다.
보호막 보너스·받는 보호막 보너스는 공용 경로에서 한 번만 적용한다. 상한·턴 만료·덮어쓰기를 두지 않는다.

직접 공격은 각각 NormalAttack/UltAttack/SpecialAttack 및 단일/전체·비접촉·주문 태그. 아군 보호막은 피해/치명타와 무관하게 한 번씩 부여하며 아군 전원에 자신 포함.
U의 특성 보호막(자신 35%)과 파티 보호막(각자 100%)은 독립된 실제 부여이므로 의신의 가호(810) 같은 기존 보상도 각 부여에 정상 반응한다.
모두에게 같은 양의 법적 보호를 제공하지만 각자가 처한 위험까지 같게 만들지는 못한다.

### 보상·밸런스 검토

- 방어력·보호막 보너스는 전열 유지/보호막, 공격력은 직접 보조 피해, 특공은 자신이 나중에 부착해서 만든 반응 위력에 투자된다. 보호막에 치명타·피해 증가를 적용하지 않는다.
- 624 수호의 결계(+20%), 810 의신의 가호(+40%, 623의 상위), 625 받는 보호막(+20%)의 기존 곱연산은 허용한다. 새 규칙으로 전체 보상 카탈로그를 임의 변경하지 않는다.
- Lv.20 방어력 219.2, HP 3020. U/SP 1회의 보호막은 기본 약 **219/인**. 방어 603(+15%), 503(+12), 906(+12%)와 624/810/625의 6칸 조합은 해당 보유자에게 약 **585/인**(받는 625를 들지 않은 아군은 약488).
- 5N+1U+1SP의 소비 전 자기 누적 공급량은 기본 약 **899**. 방어/지원 보상 투자 위 가정에서는 약2400. 이는 여러 행동을 거쳐 발생하는 공급량이지 단발 보호막이나 무적이 아니다.
- 누적 상한 대신 35% 자기/100% 파티 계수와 100 마나 주기로 조절한다. 인드라의 특수행동 피해 버프는 보호막 생성량을 올리지 않는다.
- 현행 DoT/반응 Effect 피해는 보호막을 우회하므로 누적 보호막만으로 모든 공격을 버틸 수 없다. 기존 전투 규칙을 변경하지 않는다.
- 구현 검증은 기존 보호막 유지, HP/특공 변화의 보호막 불변, 방어·보너스 변화, 광역 특성 1회, SP 물 없음 및 로카팔라 순서를 포함한다.
