# 야마 · ID 61

[아군 목록·성장값](../Detail_08_Confirmed_Characters.md) · [고유 코드 색인](../Detail_11_Code_Catalog.md)

죽음의 시점을 정하는 번개의 판관. 감전된 적에게 선고를 내리고, 쌓인 지속피해를 지금 이 자리에서 치르게 한다.

원화 키: `YAMA_PORTRAIT` / `YAMA_STANDING`. 현재 데이터가 아트 연결의 원본이다.

## 현재 코드

- **P261 죽음의 선고**: <고유 특성> 야마가 살아서 전장에 있는 동안, 감전 상태의 적에게 선고(해로운 상태)를 내린다 — 야마의 아군에게 받는 모든 피해 +20%. 감전의 출처 · 개수와 무관하게 선고는 하나이며, 마지막 감전이 사라지면 함께 사라진다. 효과 명중 · 상태 저항 판정은 없고, 감전이 남아 있으면 선고만 지워도 다시 붙는다.
- **N61 명부의 낙뢰**: 단일 적에게 공격력 130% 피해를 주고 번개를 부착한 뒤, 그 적의 모든 지속피해를 q 비율로 즉시 발동한다(q = 특수공격력 ÷ (특수공격력 + 100 + 6 × (레벨 − 1)) × 속도 ÷ 100, 최대 100%). #단일 #일반 #비접촉 #주문
- **U61 언젠가 다다를 마지막**: <마나 120> 적 전체에 공격력 120% 피해를 주고 번개를 부착한 뒤, 대상별로 모든 지속피해를 min(1, 1.5q) 비율로 즉시 발동한다. #전체 #궁극기 #비접촉 #주문
- **SP61 죽음의 순회**: <로카팔라> 적 전체에 공격력 400% 피해. 인드라 뒤 · 찬드라 앞(+75)에 행동한다. 번개 부착과 지속피해 즉시 발동은 없다. #전체 #특수행동 #비접촉 #주문

### 특성 — 죽음의 선고 (P 261)

야마가 살아서 전장에 있는 동안, 감전 상태의 적에게 선고를 부여한다. 선고는 **같은 진영 아군에게 받는 모든 피해 +20%**.
감전의 출처·개수는 무관하며 선고 하나만 적용한다. 감전이 없어지면 효력도 즉시 사라진다.
추가 효과 명중 판정은 없다. 야마 사망·전장 이탈·라운드 종료 시 효력과 구독을 정리한다.
이미 감전된 적을 포함하며, 감전 해제/재부여를 매 프레임 폴링하지 않고 상태 이벤트/수치 질의를 사용한다.
같은 선고의 중복은 곱하지 않는다. 감전 없이도 아래의 지속피해 즉시 발동은 가능하다.

### 지속피해 즉시 발동 — 공통 규격

```
K = 100 + 6 × (야마 레벨 − 1)
q = clamp01(야마 현재 특수공격력 / (야마 현재 특수공격력 + K) × 야마 현재 속도 / 100)
일반행동 발동 비율 = q
초월기 발동 비율 = min(1, 1.5 × q)
```

- 대상의 **모든 `IsDamageOverTime` 효과**(독, 화상, 출처별 감전, 풍화 등)의 원시 1회분에 위 비율을 곱해 추가 피해를 낸다. 종류·출처·효과 수 제한 없음.
- 기존 효과의 지속시간·중첩·자연 틱·풍화 행동 트리거·상태 순서는 소모하거나 앞당기지 않는다. `OnOwnerTurn`이나 만료 처리를 호출하지 않는다.
- 원래 효과의 시전자·피해 종류·반응 태그·스냅샷 여부를 보존한다. 원 시전자의 주는 피해 보정과 대상의 경감을 **각각 한 번** 적용한다. 야마의 공격력/직접 공격/치명타 보상은 남의 지속피해에 전가하지 않는다.
- 공통 감전·화상·저주·출혈은 생성자 현재 특공을 읽고 생성자 사망 후 마지막 특공을 유지한다. 맹독은 대상 최대 체력 비례다. 풍화 등 기존 효과도 자기 원시 컨텍스트를 유지한다. 별도 종류 제한은 두지 않는다.
- 즉시 발동 자체는 `Effect` 피해이며 직접 공격·일반행동·추가행동·초월기·특수행동 공격 태그를 새로 붙이지 않는다. 실제 DoT 피해 이벤트/처치 귀속은 원 시전자에 남는다.
- 한 행동에서 대상별 효과 목록을 스냅샷으로 한 번 읽고, 대상이 사망하면 나머지 피해를 중지한다. 실제 피해 처리 과정에 제거된 효과는 발동하지 않는다. 새로 만들어진 효과를 재귀 발동하지 않는다.
- 전용 공통 API로 원시 1회분의 컨텍스트를 만들며 자연 발동도 같은 컨텍스트 생성 함수를 사용한다. 새 지속피해도 이 규격에 참여할 수 있어야 한다.
