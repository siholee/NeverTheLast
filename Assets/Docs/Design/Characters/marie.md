# 마리 테레즈 · ID 160

최종 갱신: **2026-10-14**

[아군 목록·성장값](../Detail_08_Confirmed_Characters.md) · [고유 코드 색인](../Detail_11_Code_Catalog.md)

행동을 마친 동료를 치유하고 추가행동의 치명타 피해를 끌어올리는 지휘관.

원화 키: `MARIE_PORTRAIT` / `MARIE_STANDING`. 현재 데이터가 아트 연결의 원본이다.

## 현재 코드

- **P360 보급은 약속이다**: 아군 추가행동의 치명타 피해 +자신 치명타 피해의 40%. 아군은 실제 행동을 마칠 때마다 마리 공격력 15% 치유. 소환수와 마리 자신도 적용.
- **N160 장교의 사격**: 공격력 60% 단일 사격 피해 후 얼음 부착. #일반 #사격 #비접촉
- **U160 돌아올 자리는 남겨둘게**: 상시형. 라운드 시작·일반행동 완료 시 긴급지원 +1(최대 3). 다른 아군이 실제 체력 피해로 HP 30% 이하가 되면 중첩을 선점해 우선 추가행동으로 공격력 280% 치유. 실행 시 조건이 사라지면 중첩 반환. 부활 없음.

- P360 **보급은 약속이다**: 살아서 필드에 있는 동안 아군의 실제 추가행동·우선 추가행동 치명타 피해에 마리 현재 치명타 피해의 40%를 가산한다. 마리 치피 50%면 +20%p. 동일 오라의 가장 큰 하나. 실제 아군 행동이 끝날 때 행위자를 마리 현재 공격력 15%로 치유한다. 자신·독립 소환수 포함, 타격 수와 무관하게 행동당 1회.
- N160 **장교의 사격**: 공격력 60% 단일 비접촉 사격, 피해 뒤 얼음 부착.
- U160 **돌아올 자리는 남겨둘게**: 상시형. 라운드 시작과 일반행동 완료에 긴급지원 +1, 최대 3. 다른 아군이 실제 체력 피해로 HP 30% 이하가 되면 중첩을 1개 선점하여 우선 추가행동으로 공격력 280% 치유한다. 대상별 대기 1건. 실행 시 생존·필드·30% 이하를 다시 확인하며 취소하면 중첩 반환. 부활 없음, 자기 긴급지원 없음, 초월기 완료·아그니의 표를 발생시키지 않는다.

치유는 최대 체력·방어력이 아닌 공격력 기반 예외다. 낮은 기본 HP/방어력과 공격·특공·속도·치피 투자로 후열 지휘관의 비용을 남긴다. 치유 보상은 공통 Heal 입구에서 한 번 적용한다. 행동 종료 치유가 긴급지원 조건을 해소하면 대기 지원은 반환된다.
