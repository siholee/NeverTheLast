# 스카디 · ID 83

최종 갱신: **2026-10-14**

[아군 목록·성장값](../Detail_08_Confirmed_Characters.md) · [고유 코드 색인](../Detail_11_Code_Catalog.md)

얼음을 공급하며 보호막으로 전열을 지키는 설원의 사냥꾼. 공격 육성으로 서브딜을 보탠다.

원화 키: `SKADI_PORTRAIT` / `SKADI_STANDING`. 현재 데이터가 아트 연결의 원본이다.

## 현재 코드

- **P283 혹한의 외투**: 전투 시작 및 자신의 일반행동 완료 시 자신에게 방어력60% 보호막(누적). 출처와 무관하게 보호막을 보유한 동안 공격력+15%(중복 없음). 반격·도발 없음.
- **N83 설원의 사냥꾼**: 단일 적에게 공격력110% 피해와 얼음 부착(효과 명중 적용). #일반공격 #단일 #사격
- **U83 고드름 스파이크**: 마나130. 적 전체 공격력180% 피해와 얼음 부착(효과 명중 적용). 자신에게 방어력120% 보호막(누적). #초월기 #광역 #주문

## 세부 판정과 투자

ID83 / P283 / N83 / U83. 얼음·노르드·거인, 기본 사용 가능. 기존 SKADI_PORTRAIT / SKADI_STANDING 재사용.
사용자 확정 방향: **반격·도발 삭제, 범용 얼음 부착+서브탱커, 공격 육성 시 서브딜**. 오리지널 반격3회 장전은 가져오지 않는다.

- **P283 혹한의 외투:** 전투 시작과 자기 일반행동 완료에 자기 방어력60% 보호막. 출처에 상관없이 보호막이 남아 있으면 공격력15% 증가. 보호막 여러 겹으로 공격력 버프가 중복되지 않는다.
- **N83 설원의 사냥꾼:** 단일 적 공격력110%, 얼음 부착. 부착은 특수공격력·적 특수방어력 효과 명중을 따른다. 사격 형태.
- **U83 고드름 스파이크:** 마나130, 적 전체 공격력180%와 얼음 부착, 자기 방어력120% 보호막. 주문·광역·초월 판정. 피격·빙결을 요구하지 않는다.
- 모든 보호막은 누적, 방어력·보호막 보너스만 사용한다. 체력·공격력·특수공격력을 보호막 계수로 넣지 않는다. 아군 전체 보호막과 직접 빙결 보장은 없다.
- Unit.AnyShieldChanged는 생성·덮어쓰기·소진·외부 제거 직후 조건 스탯을 갱신한다. 특성 정지·사망에는 공격력 상태와 구독을 제거한다.
- 부착/전열: 특공·방어·속도. 서브딜: 공격·치명, 외부 보호막으로 특성 유지. 물 공급원 바루나와 함께 편성할 수 있다.
