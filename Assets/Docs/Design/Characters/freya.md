# 프레이아 · ID 82

최종 갱신: **2026-10-14**

[아군 목록·성장값](../Detail_08_Confirmed_Characters.md) · [고유 코드 색인](../Detail_11_Code_Catalog.md)

실제로 회복한 체력을 온기로 저장해 동료의 피해를 높이고 위기에 꺼내 쓰는 치유사.

원화 키: `FREYA_PORTRAIT` / `FREYA_STANDING`. 현재 데이터가 아트 연결의 원본이다.

## 현재 코드

- **P282 다시 일어날 수 있도록**: 아군의 특수행동·추가행동·초월기가 끝나면 그 행동자를 프레이아 최대 체력 2%만큼 치유. 일반행동·소환수·자신의 긴급 치유 제외. 실제 회복분만 온기에 저장.
- **N82 돌아오는 봄**: 필드 아군 전원을 자신의 최대 체력 8%만큼 치유. 공격하지 않으며 지휘 일제사격에 참여하지 않는다. #일반 #치유
- **U82 브리싱가멘의 기억**: 상시형. 자신이 실제 회복한 체력을 온기로 저장(최대 자신의 최대 체력 75%). 필드 아군 가하는 피해 +저장 온기/자신 최대 체력×40%(최대30%). 자신의 일반행동 시작마다 현재 온기 25% 감소 후 치유. 아군 체력이 30% 이하이면 자신의 최대 체력 18% 온기를 선소모해 우선 추가행동으로 같은 양 치유. 긴급 치유는 온기를 채우지 않으며 발동 조건이 사라지면 선소모 반환. 과잉 치유·다른 치유사의 치유는 저장하지 않는다.

## 세부 판정과 투자

풀(Dendro) · 노르드/신 · 해금. 원화 `FREYA_PORTRAIT` / `FREYA_STANDING`. 공격/원소 부착 능력은 없으며 타고난 원소가 풀이라고 적에게 풀을 부착하지 않는다. 이번 구현은 비음성 SFX를 사용한다.

초월기 상시형, 온기 사용. 코드 P282 · N82 · U82. 마나100은 데이터 공통 필드이며 초월기 발동/충전에 사용하지 않는다.

- **특성 — 다시 일어날 수 있도록:** 실제 아군 특수행동·추가행동(우선 추가 포함)·초월기가 **끝나면**, 행동자에게 프레이아 최대 체력2% 치유. 일반행동·소환수·프레이아 자신의 긴급 치유 제외. 자해를 먼저 지불하고 회복하도록 발동 시점은 행동 완료에 둔다.
- **일반 — 돌아오는 봄:** 필드 아군 전체(자신 포함)를 프레이아 최대 체력8%만큼 치유. 공격하지 않으며 나폴레옹 지휘 사격에 참여하지 않는다.
- **초월 — 브리싱가멘의 기억:** 전투 중 필드에서 상시 작동. **프레이아가 직접 실제 회복한 HP**를 온기로 저장, 최대 자신의 최대 체력75%. 과잉 치유·다른 치유사의 회복·전투 밖 회복·자신의 긴급 치유는 저장하지 않는다. 피해 오라는 `저장 온기 ÷ 프레이아 최대 체력 ×40%`, 최대30%이며 지속피해도 포함한다. 일반행동 시작에 저장 온기의25%(올림)를 줄인 뒤 일반 치유로 다시 쌓는다.
- **긴급 구조:** 필드 아군(자신 포함, 소환수 제외)의 HP가30% 이하이면 최대 체력18%에 해당하는 온기를 선점하고 우선 추가행동으로 같은 양 치유한다. 충분한 온기가 있어야 발동한다. 대상이 예약 중 먼저 치유되거나 시전자가 제어되어 실행 조건이 사라지면 한 번 반환한다. 이 치유는 에너지를 채우지 않으며 자신의 짤힐도 다시 발생시키지 않는다. 사망/정지/라운드 종료에 오라·구독·저장량을 정리한다.

### 회복과 피해 증가의 기회비용

Lv1 전체 치유94/행동 짤힐24/긴급212/온기 상한885, Lv20은 최대 체력3194/전체256/짤힐64/긴급575/상한2396. 반올림과 치유 보너스로 최종량이 달라질 수 있다. 긴급 치유 한 번은 오라를 기본7.2%p 낮춘다. 만피 파티는 저장량이 줄고, 다른 치유사가 먼저 채우면 프레이아가 저축할 부족 체력도 줄어든다. 두 치유사 편성에 별도의 강제 페널티를 붙이지 않고 **실치유 경쟁** 자체로 디메리트를 만든다. 속도는 회복 주기와 자원 감쇠를 동시에 늘리므로 단순한 오라 토템으로 만들지 않는다.
