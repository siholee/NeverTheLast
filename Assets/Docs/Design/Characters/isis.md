# 이시스 · ID 125

최종 갱신: **2026-10-14**

[아군 목록·성장값](../Detail_08_Confirmed_Characters.md) · [고유 코드 색인](../Detail_11_Code_Catalog.md)

세 수호령의 바위 부착과 방어력 보호막으로 소환 파티를 지키는 여신.

원화 키: `ISIS_PORTRAIT` / `ISIS_STANDING`. 현재 데이터가 아트 연결의 원본이다.

## 현재 코드

- **P325 세 겹의 수호**: 피격 불가 수호령3기. 서로 다른 고정 기초속도60/80/100, 각 일반공격은 이시스 방어력35% 피해와 바위 부착 시도. 치명/효과 명중은 이시스 스탯. 초기 생성하고 손실은 자기 일반 완료 때 보충. 토트의 소환 보유자 판정은1명.
- **N125 수호의 매듭**: 아군 전체 및 피격 가능한 아군 소환수에게 방어력35% 보호막. 누적하며 보호막 보너스만 추가 적용. 최대체력/특공 계수 없음.
- **U125 별들의 행렬**: 마나140. 자신의 수호령 포함 아군 모든 실제 소환수 및 소환수 취급 피그말리온의 행동 게이지50% 앞당김. 적/벤치/일반 소환자 본체 제외. 추가 생성/즉시 공격이 아니며 각자의 정상 행동이 이어짐.

바위 속성. P325/N125/U125, 마나140. 방어력 기반 보호막/소환 피해, 특공 기반 부착 성공률. 전문 딜러보다 낮은 직접 계수로 세 개의 안전한 부착원을 보상한다.

- **세 겹의 수호:** 고정 수호단(Cohort)3기: 매듭/눈/날개, ID904/905/906, 고정 기초속도60/80/100. 피격 불가, 별도 칸 없음. 각 일반503은 이시스 현재 방어력35% 단일 비접촉 주문, 소환/일반 공격 태그, 이시스 치명 스탯과 명의 사용. 바위 부착은 이시스 특공 명중을 사용. 기존 바위+바위 진동 유지. 방어력만 투자하면 부착 성공률이 낮다는 한계를 둔다.
- 초기3기 생성. 손실은 자기 일반행동 완료 때 빈 종류만 보충, 나머지 개체를 교체하지 않는다. 외부 다수형 생성/초월기로 개체를 늘리지 않는다. 소환자 사망 시 함께 실제 사망하며 외부 정지/라운드 종료는 사망보상 없이 정리한다. 토트는 수호령3기를 소환자1명으로 센다. 계속 생성/소멸시키는 우치·아누비스 중첩 파티와 구별한다.
- **수호의 매듭:** 아군 전체와 피격 가능한 아군 소환수에게 현재 방어력35% 보호막. 누적, 보호막 보너스만 적용. 최대체력·특공 계수 없음. 비공격 일반행동으로 나폴레옹 지휘 불참. 수호령의 공격 일반은 지휘 참여 가능.
- **별들의 행렬:** 아군 모든 실제 소환수와 소환수 취급 피그말리온의 다음 행동 게이지50% 앞당김. 자기 수호령 포함. 적/벤치/소환자 본체는 제외. 즉시 공격을 대신 실행하지 않고 스케줄러의 정상 행동을 앞당긴다.
- 원화 ISIS 재사용. 수호령은 매듭/눈/날개의192px 벡터 문양, 동일 금빛 계열로 구분. 주인 옆에3개를 겹치지 않게 배치. 생성 그림을 복제하는 캐릭터 원화 대신 영적 표지를 사용한다. 지원 시전은 구매 Handpaint 시트, 신규 임시 보이스 없음.
