# 찬드라 · ID 60

최종 갱신: **2026-10-14**

[아군 목록·성장값](../Detail_08_Confirmed_Characters.md) · [고유 코드 색인](../Detail_11_Code_Catalog.md)

월광으로 치명상을 되돌리는 탱커. 가장 강한 아군 한 명을 키우고, 특수행동 묶음의 끝에서 아군 전원을 회복한다.

원화 키: `CHANDRA_PORTRAIT` / `CHANDRA_STANDING`. 현재 데이터가 아트 연결의 원본이다.

## 현재 코드

- **P260 니샤카라**: <고유 특성> 고유 중첩 '월광'을 가진다. 피해로 체력이 최대 체력의 30% 이하가 되면 월광 1중첩을 소모하고 최대 체력의 50%만큼 즉시 회복한다. 치명상이면 사망 판정 전에 발동한다. 달빛 순환 — 필드에 있는 동안 아군이 특수행동을 마칠 때마다 그 아군이 찬드라 최대 체력의 4%를 회복한다(같은 아군은 자기 턴 사이 1회).
- **N60 샤친**: 응축한 월식의 그림자를 날려 단일 적에게 최대 체력의 50%에 해당하는 특수 피해를 입힌다. #단일 #일반 #특수 #비접촉
- **U60 소마**: <마나 120> 가장 공격력이 높은 아군에게 3턴 동안 대상 공격력의 10% + 찬드라 최대 체력의 10%만큼 공격력을 부여하고, 월광 1중첩을 얻는다.
- **SP60 창야**: <로카팔라> 월광 1중첩을 얻고 모든 적에게 최대 체력의 100%에 해당하는 특수 피해를 입힌다. 실제로 입힌 피해의 20%를 살아 있는 아군 전원에게 똑같이 나눠 회복한다. 회복을 맡으므로 묶음의 맨 끝에 행동한다. #전체 #특수행동 #특수 #비접촉 #주문

## 세부 판정과 투자

> 월광으로 치명상을 되돌리는 베다의 탱커이자 **유지력 담당**. 가장 공격력이 높은 아군 한 명에게 화력을 집중하고,
> 아군이 특수행동을 마칠 때마다 달빛으로 그 아군을 회복시킨다. 로카팔라 묶음이 열리면 **맨 끝**에서 월식의 광역 공격을
> 쏟고, 앞선 특수행동의 피해를 받아 낸 아군 전원을 수습한다.

### 특성 — 니샤카라 (P 260)

| 항목 | 내용 |
| --- | --- |
| 고유 중첩 | **월광**, HUD 표기 상한 9 (`chandra_moonlight`) |
| 발동 | 피해로 체력이 최대 체력의 **30% 이하**가 되면 월광 1을 소모 |
| 회복 | 최대 체력의 **50%** 즉시 회복. 치명상은 `TryPreventDeath`에서 사망 판정 전에 처리 |
| 획득 | 소마 +1, 창야 +1. 라운드 시작은 0 |
| **달빛 순환** | 필드에 있는 동안 아군이 **특수행동**을 마칠 때마다 그 아군이 찬드라 최대 체력의 **4%**를 회복한다. 같은 아군은 **자기 턴 사이에 1회**(그 아군의 `TurnCount`로 센다). 찬드라 자신의 창야도 센다 |

**달빛 순환**은 `ActionScheduler.AnyActionFinished`가 `Special` 종류로 끝난 행동을 알릴 때 일한다. 출처를 묻지 않아 로카팔라 밖의 특수행동 파티에서도 쓴다.

| 파티 | 무엇이 회복을 부르나 |
| --- | --- |
| 로카팔라 | 바유 · 쿠베라 · 인드라 · 찬드라의 특수행동 |
| 시 처형 | 멸망의 시 · 처치 재행동 멸참(`Special(4)`) |

- **특수행동만 센다.** 추가행동(빅뱅 · 철권제재 · 바스테트 추격)은 별개의 개념이라 부르지 않는다.
- 턴당 1회 제한은 시의 연쇄 재행동 같은 반복 특수행동의 과회복을 막는다. 회복량이 찬드라 체력 비례라 찬드라가 단단할수록 파티가 버틴다.

### 일반행동 — 샤친 (N 60)

단일 적에게 **최대 체력의 50%** 특수 피해. 비접촉. 기본 Handpaint는 `chandra.sachi` 조합으로
찬드라 카드 위 은백 시전광을 한 번 연 뒤, 탄도 비행 없이 대상 카드 안 여섯 지점의 `Impact1_Blue`/백색 보조광을
**0.05초** 간격으로 반복한다. 세 번째 피격 정점에서만 기존 피해를 한 번 판정한다. 이전
`MoonlightVolleyBolt` 곡선 연발과 착탄은 Legacy 스위치로 보존한다.

### 초월기 — 소마 (U 60)

가장 공격력이 높은 아군에게 3턴 동안 **대상 공격력의 10% + 찬드라 최대 체력의 10%**를 고정 공격력으로
부여하고 월광 1을 얻는다. 대상 선정과 보너스 수치는 시전 순간에 고정한다.

기본 Handpaint는 역수렴·월륜·`MoonSanctuaryDome`을 쓰지 않는다. 찬드라 카드에서 선정 대상 방향으로
`caster` 공용 `Fire3_Yellow`를 월청·은백으로 틴트해 카드 중앙과 선정 대상 방향 끝에서 짧게 한 번 열고, 선정 대상의 머리 위에 같은 색의
역재생 `hit.support.buff`를 한 번 재생하면서 실제 3턴 공격력 버프와 월광 획득을 적용한다. 끝에는 하단 상태 아이콘 팝을 잇는다. 현행 코드의 효과에는
**보호막이 없으므로 보호막 생성 연출도 넣지 않는다.** 이전 역수렴·돔·전 아군 반응은 Legacy 비교 경로로 보존한다.

### 특수행동 — 창야 (SP 60)

| 항목 | 내용 |
| --- | --- |
| 트리거 | `Combat.SpecialAction.OpenGate`가 연 로카팔라 묶음. 여는 것은 **인드라의 초월기(팔방의 소집, §13)뿐**이다. 검증은 F1의 "양측 궁극기 충전"으로 인드라가 스스로 쓰게 한다 |
| 순서 | `OpenOrder = +100` — 묶음의 **맨 끝**. 회복만 하므로 모든 공격이 끝난 뒤에 수습한다 |
| 시작 | 월광 +1. (옛 묶음 치명타 +25%는 **삭제** — 특수행동 피해 보조는 인드라의 몫) |
| 공격 | 모든 적에게 찬드라 최대 체력의 **100%** 특수 피해 `#전체 #특수행동 #특수 #비접촉 #주문` |
| 회복 | 실제로 입힌 피해 합계의 **20%**를 살아 있는 아군 **전원에게 똑같이 나눠**(찬드라 포함, 1인당 최소 1) 회복 |

기본 Handpaint는 찬드라 카드 중앙과 적 방향 끝의 은백 공용 법사 불꽃 한 번 → 적 전원 얼굴~상체 월광 충격이다.
월광 획득 시각과 대상별 짧은 타격 간격·정점 콜백은 그대로이며, 공격 뒤 실제 회복을 적용한 생존 아군 전원에게
`hit.support.heal`을 한 번씩 연다. 옛 치명타 버프 `affected`는 기본·Legacy 모두 제거했다.
니샤카라의 달빛 순환도 실제 4% 회복 직후 같은 지원 부품의 0.90배 변형과 회복 큐를 사용한다.
대상 사이 궤적·별도 돔·보호막 연출은 없다. 기존 원화와 알파 몸체·휘도 코어 합성은 유지한다.
