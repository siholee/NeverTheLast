# 오르페우스 · ID 25

죽음의 경계를 연주하는 음유시인. 적에게 강인도를 만들어 처치 연계를 열고, 아군의 삭감 효율을 높인다.

원화 키: `ORPHEUS_PORTRAIT` / `ORPHEUS_STANDING`. 현재 데이터가 아트 연결의 원본이다.

## 현재 코드

- **P225 죽음마저 속인 자**: <고유 특성> 살아서 필드에 있으면 적에게 강인도를 생성한다(일반30·정예90·보스150). 격파는 처치 연계를 발동하며 적의 다음 일반행동 시작에 회복. 자체 피해·지연·디버프 없음. 골드·EXP·드랍·영구 사망 성장 없음.
- **N25 애도의 선율**: 단일 적 공격력80% 피해·바람 부착. 강인도15 삭감. #단일 #일반 #주문 #비접촉
- **U25 비탄의 연주**: <마나100> 생존 필드 아군 전체의 강인도 삭감 효율을 10%+40%×특공/(특공+레벨K)만큼 높인다. 대상 일반행동 3회 지속하며 재부여는 갱신한다. 강인도를 추가 생성하거나 채우지 않는다.

## 세부 판정과 투자

**2026-10-12 사용자 단순화 사양 구현.** 기존 `ORPHEUS_PORTRAIT`·`ORPHEUS_STANDING` 및 바람/Greek을 재사용한다. 잔향 강인도·자체 격파 피해·행동 지연·격파 디버프는 없다. 특성은 강인도 생성만, 초월기는 아군 전체 삭감 효율 버프만 제공한다.

- P225 **죽음마저 속인 자**: 살아서 필드에 있는 동안 적에게 강인도를 생성한다. 생성량·회복·판정은 [Detail_02 강인도](../Detail_02_Combat.md#강인도와-처치-연계-2026-10-12). 초기 전장과 뒤늦게 들어온 적 모두 적용한다. 생성은 전투 자원 규칙이므로 효과 명중을 굴리지 않는다. 기존 잔량을 덮거나 격파 직후 재생성하지 않는다. 사망/라운드 종료 시 판정 없이 걷는다.
- N25 **애도의 선율**: 우선도 단일 적에게 공격력80% 피해·바람 부착, 강인도15 삭감. 바람은 현행 효과 명중을 따른다. 비접촉·주문·일반 공격이며 나폴레옹의 지휘 사격에 참여한다.
- U25 **비탄의 연주**: 마나100. 자신 포함 살아 있는 필드 아군 전원에게 `10% + 40% × 특공 / (특공 + K)`의 삭감 효율 증가. K는 오르페우스 레벨의 공용 경감 기준값. 시전 정점 스탯을 읽고 각 대상의 일반행동 완료3회 동안 유지하며 갱신한다. 피격·특수·추가행동은 기간을 소비하지 않는다. 같은 이름 버프는 중첩되지 않는다. 강인도를 생성/회복하거나 피해를 주지 않는다.

특공과 속도에 투자하는 후열 지원이다. 공격·방어의 낮은 성장으로 딜러/쉴더를 대체하지 않는다. 효과는 기존 Handpaint 바람 시전·국소 피격·버프 부품으로 조합하고 새 원화나 이동 투사체를 추가하지 않는다. 기존 SFX 클립을 재사용하며 임의 타 캐릭터 보이스를 지정하지 않는다. 🔸 장기 승률 및 독립 상용 미술 검수는 별도다.

### 시의 강인도 연계 후속

멸참이 남은 강인도를 삭감할 수 있으면 체력 처형과 함께 처형각 후보로 판단한다. 실제 피해의 강인도 격파 신호를 멸참 완료 시 읽어 특성/일반 멸참의 처치 재행동을 연다. 재행동 깊이1·자신의 타격으로 특성을 재예약하지 않는 기존 제한을 유지한다. 격파 때문에 사망 퇴장/칸 비우기/표식 이전을 실행하지 않는다.
