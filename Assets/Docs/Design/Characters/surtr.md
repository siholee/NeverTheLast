## 현재 코드

- **P281 재 속에 남긴 온기**: 적에게 직접 공격으로 실제 피해를 주면 필드 아군 전원에게 현재 방어력 12% 보호막. 광역·다타수도 실제 행동당 한 번. 보호막은 누적되며 보호막 보너스만 추가 적용. 지속피해·원소 반응·자해에는 발동하지 않는다.
- **N81 불씨를 가르는 검**: 적 하나에게 공격력 60% 피해. 불 부착 없음. #일반 #단일 #접촉 #베기
- **U81 아직 꺼지지 않은 종말**: 마나 120. 적 전체에 공격력 180% 피해 및 불 부착(효과 명중). 시전 시 체력이 60% 이상이면 최대 체력 20%를 소모하고 모든 대상에게 최대 체력 14% 계수를 더한다. 두 계수 모두 치명타 가능. 자해는 보호막·피해 경감·피격 효과를 적용하지 않는다. #초월기 #전체 #비접촉 #베기

### 투자 곡선과 밸런스 경계

U자형은 강제 스탯 구간 보너스로 만들지 않는다. 저투자에서는 높은 기초 체력·방어와 자잘한 파티 보호막으로 전열 보조 역할을 한다. 공격·체력·치명타 중 하나만 올리는 중간 투자에서는 낮은 일반공격과 체력 유지 부담이 남는다. 고투자에서는 공격력과 체력의 합산 피해를 치명타·초월기 증폭이 곱해 딜탱 역할을 완성한다. 이는 **설계 의도**이며 같은 비용의 모든 빌드에서 수학적 U자 곡선을 보장한다는 뜻은 아니다.

Lv1 강화 원시 피해는 `82×1.8 +1320×.14 ≈332`, 비용264, 파티 보호막은 1인당9. Lv20은 체력3448/공격180.8/방어180.5, 강화 원시 피해 약808, 비용690, 보호막22. 실전 피해는 방어·치명타·코드·원소 반응을 반영한다. 전문 쉴더를 대체하지 않는 낮은 방어계수와 마나120/낮은 일반 계수로 무투자 광역 딜러의 효율을 제한한다.
