버프의 **배율은 중첩되지 않고 남은 사용 횟수만 누적**한다. 각 수혜자의 실제 공격 타격/피격 하나마다 해당 중첩1개를 소비한다. 다단·바운스는 타격별로 소비하며 보호막에 흡수된 피해도 인정한다. 피해가 없는 행동·완전 무효 피해·지속피해·원소 반응·덧붙는 피해·분담 피해는 증폭/경감 및 소비 대상에서 제외한다. 중첩에는 턴 수명과 설계 상한을 두지 않으며, 해제 가능한 이로운 상태다. 니콜 사망·이탈·특성 제거·전투 종료 시 전원 정리한다.

같은 번개의 성공 재부착도 보호 중첩을 준다. 부착 실패, 적 자신의 부착, 번개가 없는 반응은 보상을 주지 않는다. **번개가 먼저 붙고 얼음이 나중에 붙는 초전도**도 증폭 중첩을 준다. 확산은 이름만으로 판별하지 않고 실제 반응 원소 쌍을 읽어 번개 확산만 인정한다. 반응 내부 재사용 대기 중의 재부착은 보호 중첩만 준다.

HP860(+76) · 공격90(+6) · 특공110(+7.2) · 방어46(+3.6) · 특방62(+4.6) · 속도108 · 치확5% · 치피50%. 공격력은 직접 피해, 특공은 부착/방깎 명중과 반응, 속도는 공급 횟수를 담당한다. 내구 계수 지원은 없다.

추천 **잔 반격**: **전열 잔 / 후열 세이·바스테트·아스톨포·니콜**. 잔이 얼음을, 니콜이 광역 번개를 공급하며 아스톨포가 공격력 치유와 추가행동·반격 치피를 맡는다. 세이는 후열에서 보호막·집중 경감을 제공한다. 에비스와 잔·세이 2인 전열 변형은 반격 대표 비교에서 제외한다. 바위 부착 없는 세이의 방깎은 얼음/번개 반응 재료를 소모하지 않는다.
