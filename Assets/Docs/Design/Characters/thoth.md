# 토트 · ID 124

최종 갱신: **2026-10-14**

[아군 목록·성장값](../Detail_08_Confirmed_Characters.md) · [고유 코드 색인](../Detail_11_Code_Catalog.md)

소환수를 보유한 동료의 수로 공격을 강화하고 서기관과 함께 치유하는 기록의 신.

원화 키: `THOTH_PORTRAIT` / `THOTH_STANDING`. 현재 데이터가 아트 연결의 원본이다.

## 현재 코드

- **P324 살아 있는 기록**: 필드에서 소환수를 현재 보유한 아군 본체1명당 소환 피해+(6%+특공/K×4%p), 명당 최대12%, 총 최대45%. 같은 소환자는1명, 피그말리온도1명. 서기관이 있으면 아군·소환수가 받는 피해12% 감소.
- **N124 생명의 문장**: 필드의 아군 전체와 소환수를 자신의 최대체력5%만큼 치유. 공격·원소부착 없음.
- **U124 사유의 서기관**: 마나120. 서기관1기 소환, 자신의 일반행동3회 수명. 이미 있으면 수명만 갱신(생성 아님). 서기관 체력은 생성 시 토트 최대체력35%, 방·특방60%, 속도90. 피격 가능. 서기관의 치유는 토트 명의.

## 세부 판정과 투자

사용자 수정: 생성 횟수·소환 개체 수를 누적하지 않고 **현재 소환수를 보유한 필드 아군 본체 수**를 센다.

- **일반 생명의 문장:** 필드 아군 전체 및 살아 있는 아군 소환수를 토트 최대체력5% 치유. 공격·원소부착 없음.
