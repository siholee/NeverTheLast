# 시 · ID 2

최종 갱신: **2026-10-14**

[아군 목록·성장값](../Detail_08_Confirmed_Characters.md) · [고유 코드 색인](../Detail_11_Code_Catalog.md)

아군이 만든 처치각을 멸참으로 베어 내고, 연속 처치와 만종으로 전장을 정리하는 바람의 검사.

원화 키: `SHI_PORTRAIT` / `SHI_STANDING`. 현재 데이터가 아트 연결의 원본이다.

## 현재 코드

- **P202 멸망의 시**: <고유 특성> 다른 아군의 공격 직후 멸참의 공격력 250% 피해가 대상의 방어력과 현재 체력만으로 처치에 충분한 적이 있으면, 가장 현재 체력이 낮은 적에게 멸참을 특수행동으로 사용한다. 처형 예측은 치명타·보호막·피해 증감·원소 반응·추가 피해를 세지 않는다.
- **N2 멸참**: 적 하나에게 공격력의 250% 피해를 입힌다. 일반행동 또는 멸망의 시로 사용한 멸참이 적을 처치하면 멸참을 특수행동으로 즉시 한 번 더 사용한다. 재행동 멸참은 처치해도 다시 이어지지 않는다. #단일 #일반/특수 #베기 #비접촉 #물리
- **U2 만종**: <패시브형> 멸참을 사용할 때마다 만종 1중첩을 얻는다. 3중첩에는 멸참 대상에게 공격력의 🔸40~136% 추가 피해를, 6중첩에는 적 전체에 공격력 200%의 분배 피해를, 9중첩에는 적 전체에 공격력 300%의 분배 피해를 준 뒤 0중첩으로 돌아간다. #단일/전체 #궁극기 #분배 #비접촉

## 세부 판정과 투자

> 아군이 만든 처치각을 **멸망의 시**로 낚아채고, 멸참 처치 재행동과 3/6/9타 만종으로
> 단일 마무리를 광역 압력으로 바꾸는 바람의 검사. 원소 · 소속은 개편 전의 시를 유지한다.

| 소속 | `[Divine]` |
| 원소 | 바람 (Anemo) |
| 전투 성향 | **[정밀] [연속] [신속]** (`Precision` · `FollowUp` · `Swift`) |
| 초월기 자원 | 패시브형 만종 · 카드 자원 배지 **0~9** |

### 특성 — 멸망의 시 (P 202)

| 항목 | 내용 |
| --- | --- |
| 발동 | **다른 아군의 공격 피해가 끝난 직후**, 멸참으로 처치 가능한 적이 있으면 멸참을 `Special(4)` 특수행동으로 예약한다 |
| 대상 | 처형 가능한 적 중 **현재 체력이 가장 낮은 적**, 동률이면 방어력이 낮은 적 |
| 처형 예측 | `공격력 × 250% × K / (K + 대상 방어력)`을 대상 **현재 체력**과 비교한다. `K`는 시의 레벨을 따른다 |
| 예측 제외 | 치명타 · 보호막 · 주는/받는 피해 증감 · 방어력 배율 변화 · 원소 반응 · 덧붙는 피해를 보지 않는다 |
| 안전장치 | 시 자신의 피해와 지속·반응 피해는 새 특성 멸참을 예약하지 않는다. 실행 직전에 처치각이 사라지면 공지 없이 버린다 |

특성 멸참은 `OnSpecialActivates`만 발행하며 일반행동 턴·AV와 일반행동 마나 +20을 쓰지 않는다.
실제 효과가 적용되는 순간 좌상단에는 `패시브(특성) — 멸망의 시`, 예약 행동에는 `특수행동 — 멸참`을 표시한다.

### 일반행동 — 멸참 (N 2)

| 항목 | 내용 |
| --- | --- |
| 대상 | 우선도 대상 1명. 특성이 부를 때만 처형 대상으로 고정 |
| 피해 | **공격력의 250%** |
| 처치 재행동 | 일반행동 또는 멸망의 시 멸참으로 처치하면 멸참을 `Special(4)` 특수행동으로 즉시 한 번 더 사용한다 |
| 연쇄 제한 | 재행동 멸참(`Reprise`)으로 처치해도 추가 재행동을 예약하지 않는다. 깊이는 **1** |
| 태그 | 일반 사용은 `SingleTarget` · `NormalAttack` · `NonContactAttack`, 특성·재행동은 `SingleTarget` · `SpecialAttack` · `NonContactAttack` |

기존 처치 시 `AdvanceAction(1.0)`과 검붉은 AV 고리는 이 특수행동 재행동으로 대체한다.

### 초월기 — 만종 (U 2)

| 항목 | 내용 |
| --- | --- |
| 형태 | `IsPersistent=true`, `IsAutoCast=false`인 패시브형 초월기. 마나를 쓰지 않는다 |
| 자원 | 멸참을 사용할 때마다 **만종 +1**. 3/6/9 발동 뒤에도 횟수를 계속 세며, 9타 판정 뒤 0으로 순환한다 |
| 3타 | 멸참 대상 1명에게 추가 피해. 실행 코드의 레벨 계수에 따른 공격력 **40% / 62% / 136%**(Lv.1/50/100) |
| 6타 | 생존 적 전체에 공격력 **🔸200%**의 총 피해를 대상 수로 나눠 가한다 |
| 9타 | 생존 적 전체에 공격력 **🔸300%**의 총 피해를 대상 수로 나눠 가하고 자원을 0으로 만든다 |
| 치명타 | 6·9타는 한 번 굴린 치명 여부를 모든 대상이 공유한다 |

환산 근거는 개편 전 커밋 `a6194c9`의 `ShiFinalVerse`: 3중첩 위력 `20 + round(-0.031×(Lv-1) + 0.00521×(Lv-1)²)`,
6/9중첩 총 위력 100/150이다. 현행 이관 규칙 `위력 50 = 공격력 100%`를 적용했다. 세 수치는 밸런스 확정 전 **🔸**다.
옛 만종의 속도 +레벨×2 상태(7003)와 버프 원형진은 제거한다.
