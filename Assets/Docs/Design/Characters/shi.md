# 시 · ID 2

최종 갱신: **2026-11-04**

[아군 목록·성장값](../Detail_08_Confirmed_Characters.md) · [고유 코드 색인](../Detail_11_Code_Catalog.md)

아군이 만든 처치각을 멸참으로 베어 내고, 연속 처치와 만종으로 전장을 정리하는 바람의 검사.

원화 키: `SHI_PORTRAIT` / `SHI_STANDING`. 현재 데이터가 아트 연결의 원본이다.

## 현재 코드

- **P202 멸망의 시**: <고유 특성> 다른 아군의 공격 직후 멸참의 공격력 300% 피해가 대상의 방어력과 현재 체력만으로 처치에 충분한 적이 있으면, 가장 현재 체력이 낮은 적에게 멸참을 특수행동으로 사용한다. 처형 예측은 치명타·보호막·피해 증감·원소 반응·추가 피해를 세지 않는다.
- **N2 멸참**: 적 하나에게 공격력의 300% 피해를 입힌다. 일반행동 또는 멸망의 시로 사용한 멸참이 적을 처치하면 멸참을 특수행동으로 즉시 한 번 더 사용한다. 재행동 멸참은 처치해도 다시 이어지지 않는다. #단일 #일반/특수 #베기 #비접촉 #물리
- **U2 만종**: <패시브형> 멸참을 사용할 때마다 만종 1중첩을 얻는다. 3중첩에는 멸참 대상에게 공격력의 100% 추가 피해를, 6중첩에는 적 전체에 공격력 250%의 분배 피해를, 9중첩에는 적 전체에 공격력 375%의 분배 피해를 준 뒤 0중첩으로 돌아간다. #단일/전체 #궁극기 #분배 #비접촉

## 세부 판정과 투자

> 아군이 만든 처치각을 **멸망의 시**로 낚아채고, 멸참 처치 재행동과 3/6/9타 만종으로
> 단일 마무리를 광역 압력으로 바꾸는 바람의 검사. 원소 · 소속은 개편 전의 시를 유지한다.

| 항목 | 값 |
| --- | --- |
| 분류 | Unlocked (처음부터 편성 가능) |
| 소속 | `[Divine]` |
| 원소 | 바람 (Anemo) |
| 전투 성향 | **[정밀] [연속] [신속]** (`Precision` · `FollowUp` · `Swift`) |
| 초월기 자원 | 패시브형 만종 · 카드 자원 배지 **0~9** |

### 특성 — 멸망의 시 (P 202)

| 항목 | 내용 |
| --- | --- |
| 발동 | **다른 아군의 공격 피해가 끝난 직후**, 멸참으로 처치 가능한 적이 있으면 멸참을 `Special(4)` 특수행동으로 예약한다 |
| 대상 | 처형 가능한 적 중 **현재 체력이 가장 낮은 적**, 동률이면 방어력이 낮은 적 |
| 처형 예측 | `공격력 × 300% × K / (K + 대상 방어력)`을 대상 **현재 체력**과 비교한다. `K`는 시의 레벨을 따른다 |
| 예측 제외 | 치명타 · 보호막 · 주는/받는 피해 증감 · 방어력 배율 변화 · 원소 반응 · 덧붙는 피해를 보지 않는다 |
| 안전장치 | 시 자신의 피해와 지속·반응 피해는 새 특성 멸참을 예약하지 않는다. 실행 직전에 처치각이 사라지면 공지 없이 버린다 |

특성 멸참은 `OnSpecialActivates`만 발행하며 일반행동 턴·AV와 일반행동 마나 +20을 쓰지 않는다.
실제 효과가 적용되는 순간 좌상단에는 `패시브(특성) — 멸망의 시`, 예약 행동에는 `특수행동 — 멸참`을 표시한다.

### 일반행동 — 멸참 (N 2)

| 항목 | 내용 |
| --- | --- |
| 대상 | 우선도 대상 1명. 특성이 부를 때만 처형 대상으로 고정 |
| 피해 | **공격력의 300%** |
| 처치 재행동 | 일반행동 또는 멸망의 시 멸참으로 처치하면 멸참을 `Special(4)` 특수행동으로 즉시 한 번 더 사용한다 |
| 연쇄 제한 | 재행동 멸참(`Reprise`)으로 처치해도 추가 재행동을 예약하지 않는다. 깊이는 **1** |
| 태그 | 일반 사용은 `SingleTarget` · `NormalAttack` · `NonContactAttack`, 특성·재행동은 `SingleTarget` · `SpecialAttack` · `NonContactAttack` |

기존 처치 시 `AdvanceAction(1.0)`과 검붉은 AV 고리는 이 특수행동 재행동으로 대체한다.

### 초월기 — 만종 (U 2)

| 항목 | 내용 |
| --- | --- |
| 형태 | `IsPersistent=true`, `IsAutoCast=false`인 패시브형 초월기. 마나를 쓰지 않는다 |
| 자원 | 멸참을 사용할 때마다 **만종 +1**. 9번째 사용을 등록하면 이번 행동의 만종 단계는 9로 보존하고 카운터는 0으로 새 순환을 시작한다. 그 후 시가 제어되거나 지휘가 취소되어 후속 피해가 막혀도 다음 멸참을 다시 9단계로 세지 않는다 |
| 3타 | 멸참 대상 1명에게 추가 피해. 공격력 **100%**(레벨에 무관한 고정 계수) |
| 6타 | 생존 적 전체에 공격력 **250%**의 총 피해를 대상 수로 나눠 가한다 |
| 9타 | 생존 적 전체에 공격력 **375%**의 총 피해를 대상 수로 나눠 가하고 자원을 0으로 만든다 |
| 치명타 | 6·9타는 한 번 굴린 치명 여부를 모든 대상이 공유한다 |

만종3타는 공격력100% 고정 계수로 선형 스탯 성장만 받는다. 6/9타는 기존 전체 분배250%/375%를 유지한다.
만종 후속 피해를 받은 생존 적마다 기본20%×시 특공/대상 특방으로 바람 부착을1회 시도한다(최대100%).
특공은 확산 전달·초확산 피해를 높이지만 공격력·치명에 투자할 예산을 사용하므로 멸참 처치각을 줄인다. 일반 멸참 자체에는 부착을 추가하지 않는다.

기초 체력980(+88), 공격128(+8.5), 방어62(+4.8), 특방64(+4.8). 세이·오르페우스를 전열에, 시·찬드라·히미코를 후열에 배치한다. 🔸 밸런스 조정 필요.

특성으로 예약된 멸참의 실제 사망은 명시적 처형으로 집계한다. 강인도 격파는 약탈자의 영혼 등 경제 보상을 발동하지 않는다. 만종6·9타는 분배 피해로 트롤리 딜레마를 받고, 3타 단일 후속과 구분한다. 신규 단일 공격 보상·간파 판정은 [보상 코드13절](../Detail_17_Reward_Codes.md#13-단일-공격간파분배-피해-보상)을 따른다.

### 전투 연출 — 🔸 검증 필요 (2026-10-25)

멸참의 제자리 시전과 세 갈래 검격은 구매 Handpaint 부품을 바람 원소 팔레트로 묶는다. 실제 대상의 흉부 접점에 작은 구매 착탄과 분산 파편·세 붓결을 잇고, 만종 후속 피해도 각 실제 수혜 접점에서 같은 문법을 쓴다. 화면 전체의 순간 섬광은 덧붙이지 않는다. 원화·HUD 앞에서 형상을 온전히 그리며 마스크로 잘라내지 않는다.

일반 멸참·만종 3/6/9·특성 및 재행동은 기존 행동 종류와 판정 시계를 유지한다. 만종을 별도 능동 초월기나 추가행동으로 연출하지 않는다. 실제 1·2배속의 등장·정점·부분 소멸과 숫자 대비에 대한 최종 미술 검증은 남아 있다.
