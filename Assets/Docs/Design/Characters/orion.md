원화 키: `ORION_PORTRAIT` / `ORION_STANDING`. 현재 데이터가 아트 연결의 원본이다.

## 현재 코드

- **P222 시리우스**: 적의 직접 공격으로 체력 또는 보호막이 감소하면 행동당 시리우스1(최대5). 5개 소비: 적 전체 공격력160%+자신 최대체력4% 화살비(추가행동·반격), 발사 후 최대체력5% 치유. 지속·반사·자해 제외. 제어 중 보관.
- **N22 거인의 사냥**: 단일 적에게 공격력100%+자신 최대체력2% 피해. #일반공격 #단일 #사격
- **U22 별을 꿰뚫는 화살**: 마나130. 단일 적 공격력220%+자신 최대체력6% 피해. 자신 최대체력12% 치유, 시리우스+2(최대5·화살비 발동 가능). #초월기 #단일 #사격

- **P222 시리우스:** 적의 직접 공격으로 자신의 체력 또는 보호막이 감소하면 시리우스1(최대5). 다단·여러 피해 패킷은 같은 실제 행동 ID당1회다. 지속피해·덧붙는 피해·원소 반응·자해·피해0·아군 출처는 제외한다. 5개가 모이면 광역 추가행동을 예약한다. 시전자 제어 중에는5개를 보관하고 다른 행동 종료 때 재확인한다. 실제 발사 직전5개를 소비하며 중복 예약·정지한 이전 세대의 실행을 막는다.
- **화살비:** 적 전체 공격력160%+자신 최대체력4%. 대상당 실제 판정1회, 사격·광역·추가공격·반격 태그. 정상 발사 후 자기 최대체력5% 치유. 금빛 화살3개는 연출이며 피해·타수는 중심 판정 하나다.
- **N22 거인의 사냥:** 단일 적 공격력100%+자신 최대체력2%, 사격.
- **U22 별을 꿰뚫는 화살:** 마나130, 단일 적 공격력220%+자신 최대체력6%, 초월·사격. 실제 발사 완료 뒤 자기 최대체력12% 치유, 시리우스2충전(최대5, 초과 버림). 이 충전으로도 화살비를 열 수 있다.
- 바스테트는 Counter 태그를 보고 경호자를 선택한다. 마리의 추가행동 치피 오라와 로키의 표식 추격은 실제 화살비 피해를 사용한다. 체력은 생존·추가 계수·치유에, 공격력·치명은 화력에 투자한다. 모든 치유는 최대체력 계수이며 기존 치유 보너스를 적용한다.
- 정지·사망·라운드 종료에 자원·예약·이벤트 구독·진행 중 화살비를 정리한다. 영구 중첩이나 런 저장 자원이 아니다.
