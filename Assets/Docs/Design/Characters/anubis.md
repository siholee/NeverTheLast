# 아누비스 · ID 121

최종 갱신: **2026-10-14**

[아군 목록·성장값](../Detail_08_Confirmed_Characters.md) · [고유 코드 색인](../Detail_11_Code_Catalog.md)

쓰러진 모든 것의 영혼을 거둬 영구히 단단해지는 저울의 신. 스스로 공격을 끌어오지는 못한다.

원화 키: `ANUBIS_PORTRAIT` / `ANUBIS_STANDING`. 현재 데이터가 아트 연결의 원본이다.

## 현재 코드

- **P321 영혼 수확**: <고유 특성> 살아서 필드에 있는 동안 유닛이 쓰러지면 영혼을 영구히 거둔다(일반 적 1 · 정예 2 · 보스 3 · 아군 1 · 소환수 0.25). 영혼 1당 최대 체력 +8, 방어력 · 특수방어력 +0.4. 영혼 50: 피격 마나 2배 · 150: 사자의 서 4턴 · 300: 전투 시작 시 방어력 270% 보호막.
- **N121 심장의 저울**: 단일 적에게 최대 체력 6% 피해를 주고 준 피해의 30%를 회복한다. 사자의 서 동안 10% · 60% · 바위 부착. #단일 #일반 #접촉 #찌르기
- **U121 사자의 서**: <마나 120> 자신의 3턴(영혼 150 이후 4턴) 동안 심장의 저울이 최대 체력 10% · 회복 60% · 바위 부착으로 강화된다.

## 세부 판정과 투자

> **필드에서 무언가 쓰러질 때마다 영혼을 거둬 영구히 단단해지는 퓨어 탱커.** 스스로 공격을 끌어오는 수단이 없다.
> 전열에 세우고, 기수 · 도발의 문장 같은 보상 코드나 경호 교체를 여는 동료로 **우선도를 받쳐 줘야** 제 몫을 한다.
> 개편 전 아누비스(커밋 `a6194c9`, 영혼 수확 · 저승의 바위 창)의 영혼 개념을 영구 중첩 규칙으로 다시 만든다.

| 항목 | 값 |
| --- | --- |
| 분류 / 원소 | Unlocked (해금 조건은 아직 없어 처음부터 편성할 수 있다) / 바위 (`Geo`) |
| 소속 | 이집트 · 신 (`Egypt` · `Divine`) |
| 전투 성향 | **[견고] [성장]** (`Sturdy` · `Growth` — 성장은 신설, [Detail_03 §5.1](../Detail_03_Character.md)) |
| 스탯 | 체력 1500(+135) · 공격 60(+3.5) · 특공 50(+3) · 방어 100(+7.5) · 특방 95(+7) · 속도 90 · 치확 5 · 치피 50 |
| 초월기 자원 | 마나 120 |
| 코드 | P 321 · N 121 · U 121 |
| 내부 연출 분류 | `lancer` (`vfxClass`, 플레이어에게 노출하지 않음) |

체력 · 방어 계열이 로스터 최고이고 속도가 가장 느리다. 공격력은 쓰지 않는다 — 일반행동이 **최대 체력 계수**라
영혼으로 늘어난 체력이 그대로 화력이 된다(초가스 · 사이온식 순환).

### 특성 — 영혼 수확 (P 321)

아누비스가 **살아서 필드에 서 있는 동안** 필드의 유닛이 쓰러지면 영혼을 거둔다(`Unit.AnyUnitDied`, `AnubisSoulHarvest.SoulValueOf`). 영혼은 [영구 중첩](../Detail_03_Character.md)
(키 `anubis.soul`)이라 전투 · 라운드 · 휴식, 아누비스 자신의 사망을 넘어 런 끝까지 남는다.

| 쓰러진 유닛 | 영혼 |
| --- | ---: |
| 일반 적 | 1 |
| 정예 적 | 2 |
| 보스 | 3 |
| 아군 (아누비스 자신 제외) | 1 |
| 소환수 (진영 무관 — 우치의 분신, 적 소환물 등) | **0.25** |

- 한 유닛은 해당하는 값 중 **가장 큰 하나**로 한 번만 센다(소환수 판정을 받는 피그말리온이 쓰러져도 +1).
- **영혼 획득량은 소수일 수 있다.** 소수 몫은 [영구 중첩](../Detail_03_Character.md)의 공용 누적 칸에 모였다가 1이 될 때마다 영혼이 된다.
  배지는 정수만 보인다(🔸 툴팁의 소수 첫째 자리 표시는 아직 없다). 다른 항목도 밸런싱에서 1 아래로 내릴 수 있다.
- 소환수는 머릿수가 많은 만큼 한 기의 값이 낮다 — 아군 사망(1)보다 확실히 아래인 0.25. 억제 상한 없이 **값 자체로** 가속 폭을 정한다.
- 우치(§10)는 자기 행동마다 분신 1기를 소모하므로 전투당 약 10기 → 영혼 +2.5. 스테이지당 약 4.5 → 7, **약 1.5배 가속**이다.
- 벤치에 있거나 이미 쓰러진 동안 일어난 사망은 세지 않는다.

**영혼 1당 (영구, 합연산):** 최대 체력 +8 · 방어력 +0.4 · 특수방어력 +0.4

| 기준점 | 예상 영혼 | 기초 대비 |
| --- | ---: | --- |
| 30스테이지 | 약 135 | 체력 +1,080 |
| 50스테이지 (Lv.45 안팎) | 약 225 | 체력 +1,800(약 +24%) · 방어 +90(약 +21%) |
| 100스테이지 (Lv.90 안팎) | 약 450 | 체력 +3,600(약 +27%) |

> 스테이지당 처치 약 4.5(일반 3.8 + 정예 · 보스 가중)를 가정했다. 영혼도 레벨도 스테이지에 비례해 자라므로
> **기초 대비 비율이 무한 모드에서 거의 일정**하다 — 깡 수치인데도 후반에 죽지 않는 이유다.
> 성장 코드(축적의 촉진 · 겹겹이 쌓인 운명, [Detail_17](../Detail_17_Reward_Codes.md))를 몰아주면 1.5~2배가 된다.

**영혼 이정표 (누적 영혼 기준, 한 번 열면 유지)**

| 영혼 | 이름 | 효과 |
| ---: | --- | --- |
| 50 | 깃털의 판결 | 피격 마나가 2배(+5 → +10) |
| 150 | 명계의 문지기 | 사자의 서 지속 3턴 → **4턴** |
| 300 | 오시리스의 대리인 | 전투 시작 시 방어력 270%의 보호막 |

이정표는 전부 **버티는 힘**만 키운다. 아누비스는 성장해도 공격을 끌어오지 않는다.

### 일반행동 — 심장의 저울 (N 121)

우선도 단일 적에게 **최대 체력 6%**의 물리 접촉 피해를 주고, 준 피해의 30%만큼 자신을 회복한다.
`#단일 #일반 #접촉 #찌르기` — 아군 첫 `#찌르기` 공격이라 관통([Detail_17 §3.1](../Detail_17_Reward_Codes.md))을 연다.
Lv.1 피해 약 90으로 잔의 신성한 일격(공격력 100% ≈ 92)과 비슷하다.

### 초월기 — 사자의 서 (U 121)

마나 120을 소모해 아누비스 **자신의 3턴**(영혼 150 이정표 뒤 4턴) 동안 심장의 저울을 강화한다.

| | 기본 | 사자의 서 |
| --- | ---: | ---: |
| 피해 | 최대 체력 6% | **최대 체력 10%** |
| 회복 | 준 피해의 30% | **준 피해의 60%** |
| 원소 | — | 적중 대상에 **바위 부착** |

- 재시전하면 같은 상태를 교체해 지속을 새로 채운다. 집중이 아니므로 제어에 걸려도 끊기지 않는다.
- 초월기는 턴을 쓰지 않으므로 시전 직후의 일반행동부터 강화된다.
- 피격 마나(+5, 영혼 50 이정표 뒤 +10)가 주 충전원이라 **맞을수록 자주 돈다.** 우선도가 낮으면 마나도 회복도 반쪽이다.
- 바위 부착은 사바흐(번개) · 히미코(불) 등 다른 원소 공격수의 반응 재료가 된다 — [Detail_16](../Detail_16_Elements.md).

### 우선도 — 아누비스가 스스로 갖지 않는 것

우선도는 기본 0 · 전열 +1이고 동률이면 무작위다([Detail_02](../Detail_02_Combat.md), `CombatTargets.PickByPriority`).
아누비스의 코드에는 우선도가 없으므로, 다른 전열(전부 +1)과 동률이면 공격의 일부만 받는다.

| 수단 | 우선도 | 비고 |
| --- | ---: | --- |
| 전열 배치 | +1 | 모든 전열 공통 — 이것만으로는 동률 |
| 보상 코드 기수 (T2) / 도발의 문장 (T3) | +1 | [Detail_17 §4.2 · §4.3](../Detail_17_Reward_Codes.md). 승급 사다리 |
| 바스테트 P322 경호 교체 | 대상 교체 | 견고 보유자라 경호 후보. 단 반격 보유자(잔)가 먼저 뽑힌다 |
| 🔸 아군에게 우선도를 주는 동료 | +1 | 현 로스터에 없다 — [Detail_15 §4](../Detail_15_Party_Synergy.md) |

> **일반 탱커와의 역시너지는 의도다.** 피그말리온의 날카로운 가시 · 잔의 텐션 오르는데!는 자신에게 +1을 걸어
> 아누비스와 공격을 나눠 가진다. 아누비스 편성은 "스스로 공격을 끄는 탱커"가 아니라 **우선도를 넘겨주는 쪽**(코드 · 경호 교체 ·
> 이후의 우선도 부여 동료)을 골라야 하며, 이 차이가 일반 탱커 편성과 아누비스 편성을 갈라 놓는다.
