## 판정·투자

일반·초월기·추격은 공격력 계수이며 치명타가 가능하다. 특공은 맹독·출혈 증폭과 부여 명중, 속도는 맹독 유지와 추격 보충에 기여한다. 추격은 실제 Additional이며 일반행동 완료·마나를 추가하지 않는다. 맹독·출혈은 같은 추격 예산을 공유한다. 정산·독안 파열에는 추격하지 않는다. 예약 때 횟수 차감, 같은 보충 구간에서 실행 취소되면 반환한다. 추격은 맹독을 재부여하지 않는다. 아스톨포의 추가행동 기본 치피와 마리의 추가행동 치피를 받는다.

기초/레벨 성장은 10_units.yaml 및 아군 목록을 따른다. 행동·피해는 공통 스케줄러·대상 개입·TakeDamage 경로를 사용한다. 무한 오라·표식·이벤트·예약 예산은 사망/정지/전투 종료에 정리한다.

## 자산·호환

전투 VFX는 `PurchasedArcherFx`가 구매한 Hovl AAA Projectiles Vol 1의 Hit 4 명중, Flash 4 전용 시전광, Arrow 21 비행을 풀 원소색으로 재생한다. `PurchasedVfxBaker`는 원본 재질·입자 모듈을 비행48셀·명중96셀·시전24셀 RGBA 시트로 렌더하며 전격 보조 꼬리는 복제본에서 제외한다. 원본 팩과 기존 GUID는 보존한다. 일반은3줄, 추격은 큰 유도 화살1줄, 초월은 실제 수신자당5줄의 시각 묶음이다. 시전은 몸체의 당김·방출과 실제 손앞을 따르는 시전광을 연결하고, 화살 윤곽은 구매 바람 텍스처의 빛과 농담으로 감싼다. 실제 대상 방향의 작은 호로 빠르게 이동하며 기존 피격 정점에 도착한다. 명중은 실제 몸통 접점을 추종하고 카드가 회수되면 마지막 유효 접점에서 잔상을 마친다.

명중은 120Hz로 실제 베이크한96셀 중 초기2셀 뒤의2~95셀을 쓴다. 기존 정점의 강세를 유지하면서 파편 시간을 늘리고, 공통 명중 기본 크기는2.45카드로 줄였다. Hit 전용 단일 패스에서 인접 셀의 premultiplied RGBA를 보간해 두 겹 alpha 합성의 밝기 출렁임을 줄인다. 정점 뒤에는 구매 노이즈의 정지된 농담으로 본체가 부위별로 풀리고, 국소의 원본 파편이 흩어지며 사그라든다. 전체 형상을 줄여 제거하지 않는다. 이 경로는 다른 시전·비행·공통 합성의 기본값을 바꾸지 않는다.

착탄 뒤 0.24게임초 대기 후 맹독 버블을 재생하며 성공한 맹독 갱신에도 표시한다. `PoisonBubblesFx`는 기존 거품 원화로 부여5개·자연 틱3개의 시각 거품을 시차로 부풀리고 흔들어 상승시킨 뒤, 립 조각과 작은 물방울로 터뜨린다. 자연 틱의 아직 터지지 않은 기포는 추격 시전에 연결해 실제 명중의 밝은 본체가 풀린 뒤 원래의 0.14게임초 시차로 터진다. 이 대기는 시각 전용이며 취소·명중 누락/회수와 2.5게임초 제한으로 해제한다. 이는 피해 틱 횟수나 추가 맹독 부여가 아니다. 모든 형상은 카드·HUD 앞에 온전히 그리며 잠깐 원화를 덮을 수 있다. 실제 상태와 HUD의 사실 표시, 단일 피해·맹독·추격 예산·마나·행동 대기를 변경하지 않는다. 장식 시각은 scaled time을 따르고 일시정지에 멈추며, 표시 시작은 렌더 프레임 단위로 양자화된다.
