# 만사 무사 · ID 200

최종 갱신: **2026-10-14**

[아군 목록·성장값](../Detail_08_Confirmed_Characters.md) · [고유 코드 색인](../Detail_11_Code_Catalog.md)

부는 자신의 자격을 증명한다. 재보와 방호를 공급하고 남은 보상을 왕실의 구매권으로 매입한다.

원화 키: `MANSAMUSA_PORTRAIT` / `MANSAMUSA_STANDING`. 현재 데이터가 아트 연결의 원본이다.

## 현재 코드

- **P400 왕실의 구매권**: 전투 시작 시 필드에 있으면 승리 전투 골드+25%. 무료 보상1장 선택 후 남은 카드 최대2장을 상점 가격으로 구매. 일반행동은 방어력80% 전체 보호막을 위해 재보1 소비.
- **N200 왕실의 방호**: 재보1 소비, 살아 있는 필드 아군 전체에 자신의 방어력80% 보호막을 누적. 보호막 보너스 적용. 재보0이면 보호막 없이 행동 완료·마나20 획득.
- **U200 황금의 행렬**: 마나100. 자신의 방어력 D 기준 재보 min(10,6+floor(D/100)) 획득. 아군 공격력·특수공격력 min(24%,8%+D×0.04%p) 증가. 만사 일반행동2회 지속·갱신.

## 세부 판정과 투자

말리·바위·재보/지원/보호막. P400/N200/U200, 마나100. 2026-10-11 사용자 제공 만사 무사 원화(`MANSAMUSA_PORTRAIT` / `MANSAMUSA_STANDING`)·임시 제이드 보이스. 성장 및 모든 계수 원본은 [재보 사양 §3](../Detail_18_Treasury.md).

- P400: 전투 시작 필드 편성 자격으로 이번 승리 골드+25%, 무료 보상1개 뒤 남은 카드 최대2개를 상점 가격으로 구매. 사망해도 이번 정산 자격 유지, 벤치 토템/중복 경제 효과 없음.
- N200 왕실의 방호: 재보1 소비·필드 아군 전체 DEF80% 보호막. 공격/부착 없음, 잔고0에서도 일반행동 완료·마나+20.
- U200 황금의 행렬: DEF 기반 재보6~10 충전과 ATK/SP8~24% 버프, 만사 일반행동2회 지속. 만사 사망/코드 정리 시 버프 제거. DEF 계수 보호막은 HP/공격 계수 치유와 섞지 않는다.
