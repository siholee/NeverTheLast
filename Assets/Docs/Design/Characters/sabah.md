# 사바흐 · ID 3

최종 갱신: **2026-10-14**

[아군 목록·성장값](../Detail_08_Confirmed_Characters.md) · [고유 코드 색인](../Detail_11_Code_Catalog.md)

아군이 만든 빈틈을 그림자에서 베어 내는 처형자. 디버프가 쌓인 적에게 강해지고 아즈라엘로 적 전체를 가른다.

원화 키: `SABAH_PORTRAIT` / `SABAH_STANDING`. 현재 데이터가 아트 연결의 원본이다.

## 현재 코드

- **P203 빈틈 포착**: <고유 특성> 공격 대상의 디버프(지속피해 포함) 1개당 가하는 피해가 4% 증가한다. 아군이 적에게 해로운 상태를 부여·갱신하거나, 아군이 건 지속피해가 적에게 피해를 줄 때마다 아즈라엘 1중첩을 얻는다.
- **N3 검격**: 그림자로 녹아 단일 적에게 110 + 공격력의 100% 피해를 입힌다. 일반행동 3번째마다 번개 베기로 바뀌어 우선도가 높은 적부터 최대 3명에게 같은 피해를 입히고 번개 원소를 부여한다. #단일/다중 #일반 #베기 #접촉 #물리
- **U3 아즈라엘**: <아즈라엘 7> 아즈라엘 7중첩을 모두 소모해 적 전체에 150 + 공격력의 100% 피해를 입힌다. 대상마다 한 번 판정한다. #전체 #궁극기 #베기 #접촉 #물리

### 특성 — 빈틈 포착 (P 203)

- 공격 대상이 가진 해로운 상태(지속피해 포함) 하나마다 사바흐가 가하는 피해가 **4%** 증가한다.
- 아군 누구든 적에게 해로운 상태를 새로 부여하거나 갱신하면 아즈라엘 +1.
- 아군이 만든 지속피해가 실제 피해를 줄 때마다 아즈라엘 +1.
- 7에 닿으면 자동 시전 궁극기가 예약된다. 공용 마나 획득은 이 중첩을 올리지 않는다.

### 일반행동 — 검격 / 번개 베기 (N 3)

평소에는 단일 적에게 `110 + 공격력×1.0` 피해를 주는 접촉 일반행동이다. 일반행동 세 번째마다 검격을 대신해
우선도가 높은 적부터 최대 3명을 같은 피해로 한 번씩 공격하고 번개를 부착한다. 대체행동은 행동 슬롯을 더 쓰지 않는다.

기본 Handpaint 연출은 사바흐 카드가 이동하지 않은 채 `Slash1_Purple` 검격을 먼저 그리고, 대상 카드에서
`Lightning2_Purple`과 `Impact1_Purple` 전격을 연다. 시전·피격 모두 `VfxSpace.AimFrom`의 사바흐→대상 방향을 따른다.
기존 이동형의 약 **0.64초** 판정 정점을 유지해 대상별 정확히 한 번 피해를 적용한다. 세 번째 번개 베기는
사바흐 카드에서 큰 검격을 **한 번만** 그리고, 각 대상 위치의 전격 피격과 판정을 **0.09초 간격**으로 연다.
대상 사이의 중간 칼날·관통선은 만들지 않는다. 이전 침식→그림자 웅덩이 이동→
`ClawRakeFx` 3줄→원위치 재구성 연출은 `Presets/ShadowAmbushFx`와 Legacy 전역 스위치로 보관한다.
공용 시전·피격·톤다운 슬롯은 `96_vfx.yaml`의 `sabah.lightning_slash`와 `sabah.lightning_sweep`에서 조합한다.

### 초월기 — 아즈라엘 (U 3)

아즈라엘 7중첩을 전부 소모하고 적 전체에 `150 + 공격력×1.0` 피해를 각각 한 번 준다. 옛 구현처럼 한 번 굴린
치명타 결과를 모든 대상이 공유한다.

`SabahFx.Azrael`은 사바흐를 숨기지 않는다. 카드 위에서 `AimFrom` 방향의 `Slash5_Blue`를 보라·검정 몸체와
좁은 전격 코어로 재착색해 발도를 정확히 한 번 만든다. 이어 적 진영 중앙에 적당히 큰 `Lightning2_Purple` 벼락을
한 번 내리고 그 낙하 끝점에서 `Smoke3_Purple` 한 장이 좌우로 퍼진다. 피해는 연기가 각 적 카드의 가로 위치에
닿는 순서대로 대상별 한 번만 판정한다.
전장 톤 다운은 발도의 색과 실루엣을 받치는 수준으로 유지하며, 치명타 공유와 대상별 1회 계약은
바꾸지 않는다. 이전 소멸→검보라 암전→가는 영혼 절단→재등장 원화는 Legacy 자료로만 남는다.
단일 `cast`·중앙 벼락 `hit`·수평 연기 `hit`·`screen` 조합은 `96_vfx.yaml`의 `sabah.azrael`이 소유한다.
