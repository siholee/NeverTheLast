# 세이 · ID 1

최종 갱신: **2026-10-15**

[아군 목록·성장값](../Detail_08_Confirmed_Characters.md) · [고유 코드 색인](../Detail_11_Code_Catalog.md)

방어력으로 싸우는 수호자. 아군에게 대지의 방패를 두르고, 그 방패가 맞을수록 창세의 결정을 모아 터뜨리며, 노래로 파티 전체의 공격을 끌어올린다.

원화 키: `SEI_PORTRAIT` / `SEI_STANDING`. 현재 데이터가 아트 연결의 원본이다.

## 현재 코드

- **P201 빅뱅**: <고유 특성> 고유 중첩 '창세의 결정'을 가진다. 필드 위에 보호막을 두른 아군이 공격을 받을 때마다 1중첩을 얻는다. 창세의 결정이 7개 모이면 무작위 적에게 방어력의 25%에 해당하는 작은 바위 조각 7개를 발사한다. 이 공격은 대상 우선도를 무시한다. <추가> 이후 아군 전체에게 100 + 방어력의 5%에 해당하는 보호막을 부여한다. #다중 #특성 #비접촉
- **N1 땅고르기**: 바위 조각을 던져 55 + 방어력의 50% 피해를 입히고, 맞은 대상에게 바위 원소를 부여한다. #단일 #일반 #비접촉
- **U1 창세의 노래**: <집중> <마나 120> 3턴간 아군 전체에게 50 + 방어력의 15%만큼 공격력을 부여하고, 아군이 피해를 가할 때마다 세이 방어력의 10%에 해당하는 고정 피해를 추가한다. 추가로 아군 전체에게 레벨 × 2 + 방어력의 25%에 해당하는 보호막을 부여한다. 집중 — 효과가 세이를 기준으로 지속되며 세이가 행동불능이 되면 해제된다.

## 세부 판정과 투자

창세의 노래를 집중 중 다시 시전하면 이전 집중을 먼저 정리한 뒤 새 버프·집중을 설치한다. 새 공격력 증가와 덧붙는 피해가 기존 집중의 종료로 지워지지 않는다. 시전 중 세이가 사망하거나 제어되면 남은 부여를 진행하지 않는다.

> 대지를 고르는 수호자. **방어력을 계수로 쓰는** 드문 유닛이라 단단할수록 세게 친다.
> 개편 전의 세이를 새 규칙으로 다시 만든 캐릭터다. 초상화 · 스탠딩은 원래 세이의 그림이다.

### 특성 — 빅뱅 (P 201)

| 항목 | 내용 |
| --- | --- |
| 고유 중첩 | **창세의 결정**, 최대 7 (`sei_genesis_crystal`) |
| 쌓임 | 필드 위의 **보호막을 두른 아군**이 **적에게** 공격받을 때마다 +1. 지속피해로는 쌓이지 않는다. 보호막을 판정하는 시점은 경감 · 흡수 전이다(`Unit.AnyDamageIncoming`) |
| 발동 | 7이 되면 **우선 추가행동**을 예약한다. 행동이 열리는 순간 7을 소비한다 |
| 효과 | 작은 지층 암편 **7개**, 암편마다 **무작위 적**을 따로 골라 **방어력의 25%** 피해. 치명타 판정은 암편마다 |
| 보호막 | 추가행동이 끝나면 **아군 전체**에게 **100 + 방어력의 5%** 보호막 |
| 우선도 | **대상 우선도를 무시한다** (도발 · 은신 등 우선도 효과를 보지 않는다) |
| 태그 | `MultiTarget` · `PassiveAttack` · `NonContactAttack`, `CodeType.Passive` |

> **결정의 재료를 스스로 깐다.** 초월기가 두른 두꺼운 보호막 위로 적이 때리면 결정이 쌓이고, 빅뱅이 터진 뒤
> 다시 보호막을 둘러 다음 결정을 잇는다. 첫 빅뱅은 초월기 이후에야 쌓이기 시작한다 — 전투 초반에 보호막이 없는
> 동안은 특성이 쉰다. 디버그 패널의 **아군 보호막** 버튼(최대 체력의 50%)은 이 흐름을 건너뛰고 볼 때 쓴다.

| 항목 | 내용 |

### 초월기 — 창세의 노래 (U 1)

| 항목 | 내용 |
| --- | --- |
| 비용 | 마나 120 · **집중** |
| 지속 | 세이의 턴 **3번** |
| 버프 | 아군 전체 공격력 **+ (50 + 세이 방어력의 15%)** — 시전 순간의 방어력으로 고정한다 |
| 덧붙는 피해 | 버프를 받은 아군이 피해를 가할 때마다 대상에게 **세이 현재 방어력의 10%** 고정 피해. 지속피해와 덧붙는 피해에는 붙지 않는다 |
| 보호막 | 아군 전체에게 **레벨 × 2 + 방어력의 25%** 보호막. 버프와 같은 순간(빛줄기가 닿을 때) 두른다 |
| 집중 | 세이가 **행동불능(제어)** 에 걸리거나 쓰러지면 버프 · 덧붙는 피해가 즉시 풀린다. **보호막은 남는다** — [Detail_03 §4.5](../Detail_03_Character.md) |
| 상태 | 버프 7001 `sei_song_buff`(금빛 오라) · 표식 7002 `sei_song_marker`(세이 카드의 링) |

고정 피해는 **때린 아군의 피해**로 기록된다(피해 미터 · 처치 판정). 세이 방어력을 읽으므로 세이의 방어 버프가 파티 전체의 화력이 된다.
