방어력으로 싸우는 수호자. 방어력 감소와 피해 증가로 아군 화력을 지원하고, 보호막과 집중 경감으로 전열을 지킨다.
보호막을 두른 아군의 피격은 빅뱅 추가공격으로 돌려준다. 원화 키는 `SEI_PORTRAIT` / `SEI_STANDING`이다.

## 특성 — P201 빅뱅

- 보호막을 두른 필드 아군이 적의 공격을 받으면 창세의 결정 +1, 최대7. 보호막은 경감·흡수 전에 판정한다. 지속피해·반응·분담 피해는 중첩을 주지 않는다.
- 7중첩이면 우선 추가행동을 예약하고, 실제 시전 시7개를 소비한다. 대기 중에는 더 쌓이지 않는다.
- 무작위 적에게 방어력25% 암편7발. 발마다 대상·치명타를 따로 결정하며 대상 우선도를 무시한다.
- 종료 후 아군 전체에게 `125 + 방어력7.5%` 보호막. 기존 보호막과 합산한다.
- 피해 태그: `MultiTarget`, `AdditionalAttack`, `PassiveAttack`, `NonContactAttack`, `Spell`. 추공 코드와 아마테라스의 실제 추가공격 조건에 참여한다. 단일 추공 전용 치피는 받지 않는다.

## 초월기 — U1 창세의 노래

마나120. 시전 효과와 집중 오라의 수명은 별개다.

| 구분 | 효과·수명 |
| --- | --- |
| 시전 보호막 | 아군 전체에게 `1200 + 레벨×48 + 방어력720%`. 보호막 보너스는 공통 경로에서 적용 |
| 시전 피해 증가 | 아군 전체 가하는 피해 +25%, **각 대상의 일반행동3회**까지. 재시전은 갱신 |
| 집중 오라 | **세이의 턴3회** 동안 받는 피해 -25%, 아군 공격 적중마다 세이 **현재 방어력25%**의 추가 고정 피해 |
| 집중 중단 | 세이의 행동불능·사망·전투 종료 시 오라와 추가 피해 종료. 이미 부여한 보호막과 시전 피해 증가 버프는 유지 |
| 재시전 | 이전 집중을 먼저 정리한 후 새 집중·시전 효과를 설치. 시전 중 사망·제어 후 남은 대상 부여 중단 |
| 상태 | 집중 오라7001 `sei_song_buff`, 집중 표식7002 `sei_song_marker`, 방깎7003 `sei_ground_shred`, 시전 피해 증가7004 `sei_song_blessing` |

추가 고정 피해는 때린 아군에게 귀속하며 `BonusDamage`로 처리한다. 지속피해·원소 반응·분담·덧붙는 피해는 이를 발동하지 않는다. 아군이 오라를 잃거나 집중이 종료되면 발동하지 않는다. 추가 피해가 다시 추가 피해를 부르지 않는다.

방어력은 보호막·빅뱅·집중 추가 피해를 함께 올린다. 방어력 감소의 안정성에는 특공, 집중 가동에는 속도·마나 효율이 유효하다. 빅뱅은 치명타를 사용하지만 공격력 계수는 없으므로 정밀 기반 공격력 코드의 직접 수혜는 낮다.

## 연출

기본 Handpaint는 바위 원소색의 손앞 시전, 구매 외피 투사체와 실제 흉부 착탄을 사용한다. 땅고르기의 여섯 발은 장식이며 기존 세 번째 정점의 피해 한 번을 유지한다. 빅뱅은 실제 선택한 일곱 대상의 개별 판정에 구매 코어와 분산 파편을 잇는다. 창세의 결정 획득은 자기 카드의 짧은 수렴 결, 창세의 노래는 실제 수혜자의 보호막 결로 구분한다. 집중과 시전 버프의 논리 수명을 연출 때문에 바꾸지 않는다. 🔸 검증 필요: 실제 1·2배속의 전체 모션·숫자 대비·잔상과 다양한 원화/배경의 최종 미술.
