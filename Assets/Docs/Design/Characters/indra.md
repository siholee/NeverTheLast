# 인드라 · ID 63

최종 갱신: **2026-10-14**

[아군 목록·성장값](../Detail_08_Confirmed_Characters.md) · [고유 코드 색인](../Detail_11_Code_Catalog.md)

로카팔라를 소집하는 데바의 왕. 초월기로 특수행동 묶음을 열고, 바즈라로 마지막에 내려친다.

원화 키: `INDRA_PORTRAIT` / `INDRA_STANDING`. 현재 데이터가 아트 연결의 원본이다.

## 현재 코드

- **P263 데바의 왕**: <고유 특성> 필드에 있는 동안 아군 전원의 특수행동 피해 +25%. 다른 아군이 특수행동을 마칠 때마다 인드라 마나 +10.
- **N63 뇌정**: 단일 적에게 공격력 110% 피해를 주고 번개를 부착한다. #단일 #일반 #비접촉 #주문
- **U63 팔방의 소집**: <마나 120> 로카팔라 묶음을 연다 — 필드의 로카팔라 참여자 전원의 특수행동을 순서대로 예약한다. 피해는 없다.
- **SP63 바즈라**: <로카팔라> 적 전체에 공격력 150% 피해. 궁극기 판정도 함께 가져 궁극기 피해 증가 효과를 받는다. 아군이 깐 버프 · 디버프를 받은 뒤 친다. #전체 #특수행동 #궁극기 #비접촉 #주문

## 세부 판정과 투자

> **로카팔라를 소집하는 데바의 왕.** 초월기로 로카팔라 아군의 특수행동을 열고, 자신은 특수행동으로 순수하게 적을 친다.
> 특성이 **모든 특수행동**의 피해를 올려, 로카팔라가 아닌 특수 파티에도 서브 서포터로 들어갈 자리를 남긴다.
> 서브 서포터 + 서브 딜러. 바유(원소 취약) → 바루나(보호막) → 쿠베라 → **인드라** → 야마 → 찬드라(회복) 순으로, 아군이 깔아 둔 디버프 · 버프를 다 받은 뒤 친다.

| 항목 | 값 |
| --- | --- |
| 분류 / 원소 | Unlocked (해금 조건은 아직 없다) / 번개 (`Electro`) |
| 소속 | 베다 · 로카팔라 (`Vedic` · `Lokapala`, 개편 전 데이터) |
| 전투 성향 | **[특수] [방출]** (`Special` · `Burst`) — 초월기가 곧 묶음 개방이고, 바즈라가 궁극기 피해 증가를 받는다. 개방은 강력하지만 다른 지원 코드와 결이 달라 [지원]은 달지 않는다 |
| 스탯 | 체력 1050(+92) · 공격 98(+6.5) · 특공 75(+4.5) · 방어 65(+4.8) · 특방 70(+5.2) · 속도 108 · 치확 5 · 치피 50 |
| 초월기 자원 | 마나 120 |
| 코드 | P 263 · N 63 · SP 63 · U 63 |

**로카팔라 규칙 (확정)** — 로카팔라 묶음(`SpecialAction.OpenGate`)은 **인드라의 초월기만 연다**(`OpenGate`의 호출처는 `IndraGathering` 하나).
로카팔라 유닛은 출시 전까지 순차로 들이며, 인드라 외에는 모두 **참여자**로 설계한다(바유 태풍의 눈 · 바루나 넘치는 판결 · 쿠베라 골드 러쉬 · 아그니 제일 먼저 태울 곳 · 야마 죽음의 순회 · 찬드라 창야).

### 특성 — 데바의 왕 (P 263)

필드에 있는 동안:

| 효과 | 내용 |
| --- | --- |
| 왕명 | **아군 전원의 특수행동 피해 +25%** (`SpecialAttack` 태그 피해, 인드라 포함). 출처를 묻지 않는다 |
| 소집 순환 | 다른 아군의 특수행동이 끝날 때마다 인드라 마나 +10 (마나 효율 적용) |

- **로카팔라에 묶이지 않는다.** 시의 멸망의 시 · 처치 재행동 멸참도 `SpecialAttack`이라(`ShiGhostSlash`) 지금 바로 +25%를 받는다.
  이후 다른 특성 묶음의 특수행동 파티가 생겨도 그대로 서브 서포터가 된다.
- 소집 순환은 묶음이 클수록 다음 개방을 앞당긴다. 묶음 인원 n이면 개방 1회에 마나 +10(n−1). 로카팔라 4인이면 120 중 30을 돌려받는다.
  시 편성에서는 멸참 재행동마다 마나가 차 초월기가 빨라지지만, 연 묶음이 없으면 인드라 자신의 바즈라만 나간다.

### 일반행동 — 뇌정 (N 63)

우선도 단일 적에게 공격력 **110%** `#단일 #일반 #비접촉 #주문`, 번개 부착.
번개는 찬드라 · 쿠베라 · 아누비스(바위) 등과 반응 재료가 된다 — [Detail_16](../Detail_16_Elements.md).

### 특수행동 — 바즈라 (SP 63)

| 항목 | 내용 |
| --- | --- |
| 트리거 | 로카팔라 묶음 참여(자신의 팔방의 소집 포함) |
| 순서 | `OpenOrder = +50` — 바유(-100)의 원소 취약 · 쿠베라(0) 다음, 찬드라(+100) 앞. **아군이 건 버프 · 디버프를 다 받은 뒤** 친다 |
| 공격 | 적 전체에 공격력 **150%** `#전체 #특수 #궁극기 #비접촉 #주문` |
| 판정 | `SpecialAttack` + `UltAttack`을 함께 가진다 — 데바의 왕(+25%)과 **궁극기 피해 증가 효과**(결전의 포효 · 결전의 일격 등)를 모두 받는다 |
| 그 밖 | **없다.** 순수 공격. 서포트는 특성, 유지력은 찬드라가 맡는다 |

### 초월기 — 팔방의 소집 (U 63)

마나 120. **로카팔라 묶음을 연다** — 필드의 로카팔라 참여자 전원(인드라 포함)의 특수행동을 `OpenOrder` 순으로 예약한다.
초월기 자체는 피해를 주지 않는다. 턴을 쓰지 않으므로 소집 직후 묶음이 바로 이어진다.

- 연 묶음은 `gateTags: [Lokapala]` **데이터**로 둔다. 다른 특수 묶음이 생기면 이 목록을 넓히거나 다른 개방자에게 맡기며,
  데바의 왕은 어느 묶음이든 똑같이 받쳐 준다.
- 묶음에 인드라만 있으면 바즈라 하나만 나간다 — 로카팔라 동료가 늘수록 같은 초월기 한 번의 값이 커진다.

### 로카팔라 편성

| 순서 | 참여자 | 특수행동 | 묶음 안의 역할 |
| ---: | --- | --- | --- |
| -100 | 바유 (§14) | 태풍의 눈 — 적 전체 소량 피해 + **전속성 직접 공격 취약** | 디버프를 먼저 깐다 |
| -50 | 바루나 (§16) | 넘치는 판결 — 적 전체 공격력 70% + 아군 전원 방어력 100% 보호막 | 뒤의 참여자가 치기 전에 **보호막**을 깐다 |
| 0 | 쿠베라 (§11) | 골드 러쉬 — 적 전체, 보유 골드 비례 | 골드를 모았다면 **메인 딜러** |
| +25 | 아그니 (§17) | 제일 먼저 태울 곳 — 인드라U에서 얻은 기존 표 한 장을 집중 Additional로 반환 | 준비 뒤 추공이 인드라SP보다 앞선다 |
| +50 | 인드라 | 바즈라 — 적 전체 공격력 150% (궁극기 판정) | **개방** · 특수행동 피해 보조(데바의 왕) · 서브 딜링 |
| +75 | 야마 (§15) | 죽음의 순회 — 적 전체 공격력 400% | 버프 · 디버프를 다 받은 뒤의 **마무리 딜러** |
| +100 | 찬드라 (§3) | 창야 — 적 전체 최대 체력 100% + 아군 전원 회복 | **유지력**, 맨 끝에서 수습 |

**순서 규칙** — 디버프 · 버프를 거는 참여자는 음수, 피해가 주인 참여자는 0 이상, 회복만 하는 참여자는 맨 끝.
파티는 5명까지라 로카팔라 일곱이 한 번에 서지는 못한다. 실제로 필드에 선 참여자만 위 순서로 나선다(예: 야마 · 바루나 · 인드라 · 찬드라 편성은 바루나 → 인드라 → 야마 → 찬드라).
한 번의 팔방의 소집 = 특수행동 n회 → 데바의 왕 +25%가 모두에, 앞의 디버프가 뒤의 참여자에, 달빛 순환이 모두에(턴당 1회), 인드라 마나 +10(n−1).
