# NeverTheLast — 공통 개념

최종 갱신: **2026-10-14**

개념 정의만 둔다. 세부 수치·계수는 각 상세 사양이 원본이다.

## 진행

**런**은 편성부터 생명력 소진까지 이어지는 한 여정이다. **테마**는 배경·적·사건·보스를 묶는 단위다.
표시상 스테이지 하나는 테마 하나의 8라운드이며 내부 `RoundManager.Round`에 대응한다.
표시상 라운드/누적 층수는 내부 `Stage`와 대응한다. 두 이름을 혼용해 보스 위치나 티어 확률을 계산하지 않는다.
**내용 슬롯**은 고정 보스 삽입으로 앞당겨진 테마 내부의 편성·사건 위치다. [진행 사양](Detail_01_Progression.md)

## 행동과 시간

**일반행동**은 속도와 AV로 정해지는 기본 행동이다. 공격 외에도 치유·방호·소환일 수 있다.
**추가행동**은 별도 트리거로 예약되며 일반행동의 AV를 소모하지 않는다. 반격도 추가행동의 조건과 태그를 사용한다.
**특수행동**은 특수 슬롯의 고유 트리거로 열리며 추가행동으로 세지 않는다. 로카팔라는 인드라의 초월기가 묶음을 연다.
**초월기**는 마나·고유 스택·상시 패시브형 자원에 따라 작동한다. **집중**은 지속 시전 상태이며 제어·사망으로 끊긴다.
**턴**은 전투의 논리 시계, **연출 시간**은 표시의 시계다. 배속·일시정지·프레임 수로 피해나 턴 기반 발동을 다시 계산하지 않는다.
[전투 사양](Detail_02_Combat.md) · [자원 사양](Detail_03_Character.md)

## 스탯과 상태

최대 체력·공격력·특수공격력·방어력·특수방어력·속도·치명타 확률·치명타 피해의 8스탯을 직접 성장시킨다.
특수공격력은 반응·지속피해·효과 명중 및 일부 지원 계수, 특수방어력은 효과 저항과 지속/반응 피해 경감에 관여한다.
**보호막**은 체력 앞에서 피해를 흡수하며 누적된다. 생성량은 기본적으로 방어력과 보호막 보너스를 따른다.
**치유**는 실제 회복한 체력과 초과 치유를 구분한다. 일반적인 치유 계수는 최대 체력이며 캐릭터별 승인 예외는 아군 사양에 둔다.
**효과 명중**은 적대 원소 부착·디버프 등의 성공 판정이다. 아군에게 주는 지원은 저항하지 않는다.
[스탯](Detail_03_Character.md) · [피해·상태](Detail_02_Combat.md)

## 원소와 지속피해

**속성**은 유닛의 고유 원소, **부착**은 지속시간을 가진 반응 재료다. 고유 원소만으로 반응하지 않는다.
**원소 반응**은 부착된 두 원소의 조합 결과이며 원소 부착을 소모한다. 같은 원소 반응은 바람·바위만 유지한다.
**지속피해**는 행동 조건에 따라 자연 발동하고 종류마다 수명 시계를 가진다. 같은 종류를 다시 걸면 기간을 갱신한다.
야마의 즉시 발동은 원 지속피해나 남은 기간을 소비하지 않는다. [원소·지속피해 사양](Detail_16_Elements.md)

## 소환·중첩·처치

**소환수**는 칸 없는 전투 개체다. 소환자 보유 수와 필드의 소환수를 보유한 본체 수를 구분한다.
피그말리온처럼 소환수로 취급되는 본체는 별도 소환 객체와 구분한다. [소환 사양](Detail_03_Character.md)
**영구 중첩**은 유닛의 런 성장값이다. **축전량**은 보상 코드 한 장의 인스턴스에 속하며 교환·승급·판매·저장에 유지된다.
**재보**는 아군 파티 전체가 함께 충전·소비하는 전투 자원이다. 예약된 양과 가용량을 구분하고 사용 캐릭터가 없으면 HUD를 숨긴다.
[보상 코드](Detail_17_Reward_Codes.md) · [재보](Detail_18_Treasury.md)

**강인도**는 오르페우스가 적에게 만드는 처치 연계 자원이다. 격파는 가상 처치이며 실제 사망·골드·EXP·드랍은 만들지 않는다.
격파의 고정 피해 등은 개별 코드 효과이며 공통 격파 피해·행동 지연·디버프는 없다. [강인도 사양](Detail_02_Combat.md)

## 코드·아이템·저장

**고유 코드**는 캐릭터의 기본 기술이다. **보상 코드**는 획득 가능한 패시브이며 개인 활성 칸과 보관함을 가진다.
공용 아이템은 파티 보급에 보관하며 장비나 중량으로 취급하지 않는다. 넥타르는 소비 후 런 내 영구 능력치를 남긴다.
**골드**는 구매 자원이며 **재보**와 서로 교환 가능한 같은 재화가 아니다.
**계정 저장**은 해금·설정, **런 저장**은 진행·유닛·아이템·코드 인스턴스를 보존한다.
