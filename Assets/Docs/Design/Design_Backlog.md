# 남은 결정과 검증

최종 갱신: **2026-10-15**

현재 구현된 규칙은 상세 사양에 둔다. 완료된 작업·검수 회차·채택 이력은 [보관소](../../../Docs/Archive/README.md)로 옮겼다.
아래의 `🔸`는 미구현, `🔸 검증 필요`는 구현과 별개로 남은 실측/최종 판정이다.

## 1. 게임 전체 QA·상용 미술·성능 — 🔸 검증 필요

1차 Root 검토와 2차 Opus 5.5 독립 검토의 범위는 **게임 전체**다.
공통 시스템·전체 로스터·전체 연출·경제/보상·진행·저장·실제 입력·빌드 Player와 최적화를 포함한다.
부분 PASS와 전체 합격을 구분한다. 현재 최종 기술/미술 승인은 완료되지 않았다.

공통 시스템·전체 로스터의 소형 독립 기술 검토와 실제 Unity/Windows QA Player 회귀를 진행했다.
수정 범위와 일부 UI 정지 화면의 통과를 전체 미술·청감·장기 밸런스·실기기 성능 승인으로 확대하지 않는다.
최신 상태/coverage/소스 근거는 로컬 `Logs/WholeGameReview20261015/root-next-state.json`·`coverage.json`·`root-current-review.md`가 원본이다.
계속할 때 해당 파일과 최신 사용자 지시를 읽고, 완료된 불변 범위는 동일 소스 근거로 재사용한다.
문서/브랜치 정리는 QA 승인·새 빌드 배포·릴리스 완료로 보고하지 않는다.

VFX 독립 검수는 작은 묶음으로 순차 의뢰한다. 전체 부품/스킬/화면을 한 번에 넣거나 장문 세션을 통째로 resume하지 않는다.
미술 결함은 Root가 직접 보정하고 실제 Unity에서 재검증한다. [UI·검수 규약](Detail_07_UI_Tech.md)

## 2. 장기 진행과 경제 — 🔸 검증 필요

- 초반 범용 구간과 24/48층 스펙 시험의 장기 추천 조합 승률·턴 수·도달 체력, 테마별 난이도 편차. 48층은 실제 Unity 편성 비교와 자연 진행을 실시했으나 모든 난수/테마/보상 조합을 보장하는 검증은 아님.
- 무한 런 후반 EXP/레벨 격차·보스 예산·회복 수급과 구매 시세의 지속 가능성.
- 활성 7칸/무료 교환·축전기/넥타르·경제 오라와 만사 추가 구매의 슬롯당 기여.
- 재보 축적/소비/환급의 행동 예산과 이슈타르 장탄, 강인도 가상 처치/다중 공물의 유지력.
- 일반 치명 보상과 확정 치명·치명 전환 빌드의 실제 선택률/효율 차이.
- 짧은/긴 휴식과 식량의 현행 구현에 대한 장기 압박. 상단에서 식량을 숨긴 것은 시스템 삭제와 다르다.

현행 harness는 존재한다. 다수 seed·편성·후기 구간의 자연 진행 실측이 끝났다고 취급하지 않는다.

## 3. 미리워크/신규 캐릭터 — 🔸 미구현

브라다만테의 전체 피해 분담·반격 유지력 지원, 보류된 아스톨포, 라부아지에·아스클레피아의 전투 리워크는 남아 있다.
[미구현 제안](../Proposals/Unimplemented_Characters.md)과 [서사 설정](../Narrative/README.md)을 읽는다.
오리지널의 아트·NPC/사건 등장이 곧 현행 플레이어블 구현을 의미하지 않는다.
복구 테마 사건에서 미리워크 인물을 실제 영입하는 경로도 해당 캐릭터 구현과 함께 검토한다.

## 4. 첫 실행 도입부 — 🔸 미구현 원고

세이 단독 첫 인사 V2.1과 관련 공개 단계는 [현행 원고](../Narrative/First_Start_Intro.md)에 있다.
이름/성별 입력·이름 저장/치환·첫 실행 여부·편성 연결을 별도 구현해야 한다.
현재 멸망 이후 내레이션 데이터와 테스트의 인트로 건너뛰기를 원고 채택으로 자동 수정하지 않는다.
