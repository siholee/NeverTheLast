불씨의 대상 안 화염 중심·외곽과 피해 숫자 대비를 반영했다. 🔸 검증 필요: 실제 시간의 시전~피격 연결성·청감·여러 배경/대상·Player 성능. [히미코](Characters/himiko.md)의 기능 검사와 일부 정지 화면을 상용 게임 동급 또는 전체 미술 승인으로 확대하지 않는다.
