## 3. 복구 적의 코드 공간

이관 적의 일반/초월 ID는 원본 적ID+10000(11020~13203), 특성은 원본 적ID+20000(21020~23203)이다. 현행 1001~1004 공용 코드와 아군·보상 코드를 덮어쓰지 않는다. `Codes/RestoredEnemyCodes.cs`가 `EnemyData.reworkKit`의 명시 사양을 읽는다. 20_codes에는 개체별 이름과 설명462개를 등록한다. 피해와 상태·회복의 공통 입구, 단일/범위 태그, 효과 명중, 일반행동 완료, 집중 해제 및 라운드 정리를 그대로 사용한다.


### 2026-10-13 오리온·스카디 등록
P222 OrionSirius / N22 OrionHunt / U22 OrionStarPiercer. P283 SkadiFrostMantle / N83 SkadiSnowHunt / U83 SkadiIcicleSpike. 수치 원본은 Detail_08 §28~29. 스카디는 반격·도발 코드가 없고 오리온 화살비만 추가행동·반격이다.


## 4. 등록과 네임스페이스

소환수 일반 코드·보상 패시브 ID는 슬롯 네임스페이스를 구분한다. 코드 공통 자원·공격 형태·이벤트는 [02 전투](Detail_02_Combat.md)·[03 캐릭터](Detail_03_Character.md)를 따른다. 생성 팩토리와 YAML 이름을 함께 등록한다.
