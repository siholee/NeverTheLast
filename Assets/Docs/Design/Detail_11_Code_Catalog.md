## 1. 읽는 법

### 1.1 분류는 서로 다른 네임스페이스다

`CodeFactory`는 passive / normal / ultimate를 **각각 따로** 조회한다.
그래서 **ID 숫자가 같아도 분류가 다르면 완전히 다른 코드**다.

예를 들어 오리온의 P·N·U는 모두 80이지만 셋 다 다른 클래스로 생성된다.
`164`는 패시브에서는 콜로세움 '챔피언의 여유', 궁극기에서는 레기온 '일제 투창'이다.

### 1.2 위력과 피해

```
피해 = 위력 × 시전자 스탯 × 0.2
```

'STR 기반 위력 80'은 주스탯 대신 STR을 쓴다는 뜻이다.
보호막도 같은 식으로 산출한다(`SkillDamage(위력, 스탯)`).

**위력은 두 형식 중 하나다.**

| 형식 | 표기 | 쓰는 곳 |
| --- | --- | --- |
| 고정 | `위력 80` | 대부분의 코드 |
| **고정값 + 스탯 비례** | `위력 50 + STR×0.2` | 로마 테마 전체 |

```
위력 = 고정값 + 시전자 스탯 × 계수      (Code.PowerStatCoefficient)
```

두 번째 형식은 **저점을 고정값으로 보장하고 고점을 억제한다.**
위력 자체가 스탯에 비례하면 최종 피해는 스탯의 제곱에 가깝게 자라므로,
계수를 작게(0.2~0.6) 잡으면 후반 폭주 없이 초반 화력만 확보된다.
`위력 DEX×0.6`처럼 고정값이 0인 형태는 순수 비례형이라 초반이 약한 대신 성장 폭이 크다.

### 1.3 표기

| 표기 | 뜻 |
| --- | --- |
| `<고유 패시브>` | 캐릭터당 1개. 코드 용량을 쓰지 않는다 |
| `<전수 불가능>` | 서포터 카드로 넘겨줄 수 없다. **모든 고유 패시브가 여기 해당한다** |
| `<강화 등급>` | 금색 코드. 같은 계열의 일반(은색) 등급을 대체하며, 둘을 함께 들면 일반 쪽이 발동하지 않는다 |
| `<장비 전용>` | 장비가 부여한다. 코드 용량을 쓰지 않고 장비를 벗으면 걷힌다 |
| `<적 전용>` | 적만 보유한다 |
| `<보스 전용>` | 그 유닛이 보스로 등장할 때만 붙는다 |
| `#물리` `#특수` `#접촉` `#비접촉` `#베기` `#찌르기` | 피해 태그 |
| 보유자 `—` | 현재 어떤 유닛도 참조하지 않는 사문 코드 |

### 1.4 신규 코드 등록

1. `20_codes.yaml`의 올바른 분류에 고유 ID와 표시 설명을 등록한다.
2. 코드 클래스를 만들고 `CodeFactory`의 같은 분류에 연결한다.
3. `10_units.yaml`(아군) 또는 `60_enemies.yaml`(적)의 `codes`·`levelPassives`에 연결한다.
4. 이 문서를 갱신한다. 절차 전문은 [Detail_12 §6](Detail_12_Code_Weapon_Catalog.md)을 본다.

### 1.5 ID 배치 규칙

**ID는 계열이 정한다.** 슬롯마다 네임스페이스가 다르므로 배치도 슬롯별로 본다.

| 구간 | 무엇이 들어가는가 | 규칙 |
| --- | --- | --- |
| 1~179 | 아군 일반·궁극기 / 공용 해금 패시브 | **아군 일반·궁극기는 소유 유닛 ID와 같은 번호**. 패시브 쪽 1~179는 여러 유닛이 나눠 쓰는 공용 해금 |
| 180~199 | 데이터가 가리키지 않는 패시브 | 참조가 끊긴 사문 코드와, YAML 대신 **코드에서 직접 부르는** 것(팔랑크스 183)을 모아 둔다 |
| 200~399 | 아군 고유 패시브 | **소유 유닛 ID + 200** |
| 400~499 | 장비 전용 패시브 | `codeGrants`가 실어 나른다. 코드 용량을 쓰지 않는다 |
| 900~999 | 사문 일반·궁극기 | 패시브의 180~199에 대응한다 |
| 1000~1099 | 적 공용 | 병종 공용 성장 패시브·일반공격 |
| 1100~1199 | 콜로세움 | |
| 1200~1299 | 로마 군단 | |
| 1300~1399 | 메히코 | |
| 1400~1499 | 아스완 | |

**아군 코드는 유닛 ID만 알면 찾을 수 있다.** 오리온(22)의 일반공격과 궁극기는 둘 다 22,
고유 패시브는 222다. 세 슬롯이 서로 다른 네임스페이스라 같은 숫자를 겹쳐 쓸 수 있다.

> **적 코드는 `CodeFactory`가 구간으로 한꺼번에 받는다.**
> `>= 1200 and <= 1211 => new LegionNormal(context, (LegionNormalStyle)(codeId - 1200))`처럼
> **ID 간격이 그대로 색인**이다. 그래서 적 계열은 블록 안에서 간격까지 유지한 채 옮겼다.
> 새 적 코드를 계열 중간에 끼워 넣으면 그 뒤가 전부 밀리니, 반드시 계열 끝에 붙인다.

로마 3인(아그리파·옥타비아·카이사르)은 레기온 적과 구현을 공유하지만 코드는 아군 규칙을
따른다. `CodeFactory`에 제 몫의 분기가 있고, 거기서 `LegionNormalStyle.Agrippa` 같은
이름으로 스타일을 직접 건넨다 — 예전처럼 적 구간의 ID 간격에 얹혀 있지 않다.

캐릭터 ID의 소속별 블록은 [Detail_03 §7.4](Detail_03_Character.md)를 본다.
