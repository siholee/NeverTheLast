## 1. 규칙

### 1.1 분류는 서로 다른 네임스페이스다

특성 · 일반행동 · 특수행동 · 초월기는 ID 공간이 따로다. 특성 201과 초월기 201은 무관하다. `CodeFactory`가 슬롯마다 다른 스위치로 푼다.

### 1.2 피해 표기

피해는 `고정값 + 스탯 × 계수`로 적는다(`Code.StatDamage`). 스탯이 적혀 있지 않으면 시전자 공격력이다.
설명 끝의 `#태그`는 피해의 성질 — [Detail_02 §6](Detail_02_Combat.md).

### 1.3 등록

1. C# 구현 → 2. `CodeFactory` 스위치 → 3. `20_codes.yaml` 이름 · 설명

### 1.4 ID 배치

| 구간 | 무엇이 들어가는가 | 규칙 |
| --- | --- | --- |
| 1~199 | 아군 일반행동 · 특수행동 · 초월기 | **소유 유닛 ID와 같은 번호** |
| 200~399 | 아군 고유 특성 | **소유 유닛 ID + 200** |
| 400~499 | 폐기된 영역 | 장비 부여 코드와 함께 제거되어 비어 있다 |
| 1000~1099 | 적 공용 | 시험장 병종이 쓴다 |

적 테마 블록(1100~)은 새 테마를 들일 때 100칸씩 연다. 적 코드를 구간 스위치로 받는 경우
ID 간격이 스타일 색인이 되므로 **계열 끝에만 덧붙인다.**
