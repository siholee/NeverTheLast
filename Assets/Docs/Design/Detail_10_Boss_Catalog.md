## 1. 보스 슬롯 규칙

| 슬롯 | 결정 | 스폰 |
| --- | --- | --- |
| 중간 보스 | 테마의 `midBossId` + `midBossStageInRound`(기본 8) | 패턴이 없으면 **단독** |
| 최종 보스 | 테마의 `bossId`, 10스테이지 | 패턴이 없으면 **단독** |
| 고정 보스 | `fixedBossStages` — 🔸 **현재 비어 있다** | 라운드의 **마지막 전투**를 차지 |

고정 보스가 낀 라운드는 2번 슬롯을 건너뛰고 이후를 1씩 당긴다.
그래서 테마 보스가 9번째 전투로 밀리고 마지막 칸이 고정 보스 자리가 된다 —
[Detail_09 §2.2](Detail_09_Enemy_Catalog.md)를 본다.

**`stagePatterns`에 그 슬롯의 편성이 적혀 있으면 단독 스폰보다 우선한다.**
호위를 붙이려면 패턴에 보스 ID를 직접 적으면 된다. 로마 군단이 이 방식을 쓴다.

`GetStageKind()`는 HUD 진행 예고에 같은 규칙을 쓴다. 스폰 규칙을 바꾸면 두 곳을 함께 고쳐야 한다.

## 3. 로마 군단 (테마 id 5)

### 3.1 중간 보스 — 아그리파 + 옥타비아 (9스테이지)

**둘이 한 쌍이다.** 아그리파는 옥타비아를 밀어 주는 서포터라 단독으로는 위협이 되지 않는다.
9스테이지 패턴에 에퀴테스 ×2 + 센츄리온 호위와 함께 배치된다.

| P | **309 화합(Concordia)** |

**화합(Concordia)** — 아그리파가 단일 아군에게 이로운 효과를 주면 그 아군이 '화합' 2스택을 얻고
가하는 피해가 25% 늘어난다. 아그리파의 턴마다 1스택 줄고, 새로 부여하면 이전 보유자가 잃는다.
따라서 **화합은 항상 한 명에게만 붙어 있다.**

**최고의 2인자** — 필드에 옥타비아가 있으면 일반공격이 무조건 옥타비아를 향하고,
추가로 옥타비아의 행동 게이지를 100% 채운다. 곧 옥타비아가 즉시 한 번 더 움직인다.

> **먼저 죽여야 할 쪽은 아그리파다.** 아그리파를 남겨 두면 옥타비아가 치명타 피해 +20%,
> 화합 +25%, 행동 게이지 100%를 매 턴 얻는다.

**저스핏 고화력 궁극기 딜러다.** 패시브가 DEX를 깎아 턴이 덜 돌아오는 대신 궁극기 한 방이 커진다.
궁극기 자원은 **행동 횟수가 아니라 전투 시간에 비례해** 차오르므로([Detail_02 §2.4-B](Detail_02_Combat.md)),
느려져도 궁극기 주기는 거의 손해를 보지 않는다. 이 두 규칙이 맞물려 컨셉이 성립한다.

**팍스 로마나** — 공격이 적중한 대상 수마다 궁극기 자원을 2% 회복한다.
전체 공격인 궁극기가 5명을 맞히면 그 자리에서 10%가 돌아온다.

**심안** — 원소가 붙은 적을 공격하면 내구를 무시하고 피해를 준 뒤 그 원소를 지운다.
같은 편 트리아리·센츄리온이 부여한 바위 원소가 옥타비아의 관통 조건이 된다.

호위는 에퀴테스 ×3(전열) + 트리뷴 ×1(후열)이다.

**카이사르는 스스로 때리는 보스가 아니라 진영을 굴리는 보스다.**

| 코드 | 효과 |
| --- | --- |
| 왔노라, 보았노라, 이겼노라 | 적을 처치할 때마다 모든 '로마' 아군의 가하는 피해 +10%. **상한 없이 중첩된다** |
| 갈리아의 정복자 | 자기 전열의 '로마' 아군이 받는 피해 −10% |
| 위대한 전술가 | 자기 전열의 '로마' 아군이 단일 피해를 주면 같은 대상에게 추가공격으로 일반공격 |
| 대범한 관용(Clementia) | 적을 처치하고 전열에 빈 자리가 있으면 **센츄리온을 소환한다** |
| 독재관 | 궁극기의 지속 턴 수 +1 |
| U 주사위는 던져졌다 | 아군 전체 행동 게이지 +100%. 3턴간 아군이 치명타를 낼 때마다 위력 `LUK×0.1`의 고정 피해 추가 |

**전열을 비우지 못하면 진다.** 위대한 전술가로 호위의 딜이 두 배가 되고,
아군이 죽을 때마다 왔노라 스택이 쌓이며, 빈자리는 대범한 관용이 센츄리온으로 메운다.
반대로 **에퀴테스를 빠르게 정리하면** 추가공격의 원천이 사라지고 소환도 자리를 못 찾는다.

> **대범한 관용은 전열이 꽉 차 있으면 발동하지 않는다.** 카이사르 본인이 전열 한 칸을 쓰므로
> 호위 3기를 남겨 두면 소환이 봉쇄된다 — 잡는 순서를 고르는 판단이 생긴다.

## 4. 아스완 (테마 id 7)

메히코가 '전열을 제물로 쓰는' 편성이었다면 아스완의 두 보스는 **체력 자체를 자원으로 쓴다.**
오시리스는 깎일수록 단단해지고, 아문·라는 때릴수록 세진다. 방향이 정반대라 대처도 다르다.

### 4.2 중간 보스 — 오시리스 (ID 3011, 9스테이지)

| 항목 | 값 |
| --- | --- |
| 등급 | boss · 전열(archetype 8) · 단독 |
| 원소 | 바람 |
| 주/부 | INT / LUK |
| 스탯 | STR 16 +2 · DEX 14 +1 · **CON 8 +1** · INT 40 +4 · LUK 24 +2 |
| P | 364 불완전한 부활 |
| N | 306 대지의 진혼 — 적 전체 INT×1.2 + 바위 원소 |
| U | 306 재생의 격류 — 적 전체 INT×2.0 + 행동 게이지 50% 지연 |
| 해금 | 126 순환 @40 |

**깎을수록 단단해진다.** 체력이 14개의 부위로 나뉜다.

- 최대 체력 ×14 — CON 기본값을 8로 낮게 잡아 9스테이지 기준 **16,000**이 된다.
- 시작 시 받는 피해가 **2.4배**(= 받는 피해 감소 −140%). 부위가 하나 깨질 때마다 10%p씩 줄어
  마지막 부위에서 1.0배가 된다. 체감 체력은 처음 약 6,700에서 점점 늘어난다.
- 부위가 깨질 때마다 **사령 3기**가 필드에 선다(빈칸만큼만). 적 진영은 8칸이므로
  오시리스를 뺀 최대 7기가 동시에 설 수 있다.
- 체력 바가 **14칸으로 끊겨** 보인다. 부위가 몇 개 남았는지가 화면에서 그대로 읽힌다
  (`BaseEffect.HpSegmentCount` → `Unit.HpSegmentCount` → `UnitCardView.RefreshHpSegments`).

초반에 부위를 몰아 깨면 이득이 크지만 그만큼 사령이 쏟아진다. **화력과 처리량 중 무엇을 먼저 낼지**
고르게 만드는 구조다. 소환되는 사령은 `AswanCombat.WraithId`(1052)이며,
라운드 도중에 들어오므로 소환 직후 `OnRoundStart`를 직접 보내 패시브를 걸어 준다.

### 4.3 최종 보스 — 아문·라 (ID 3012, 10스테이지)

| 항목 | 값 |
| --- | --- |
| 등급 | boss · 전열(archetype 8) · 단독 |
| 원소 | 번개 |
| 주/부 | INT / LUK |
| 스탯 | STR 18 +2 · DEX 18 +2 · CON 70 +7 · INT 44 +5 · LUK 26 +2 |
| P | 365 승천 |
| N | 307 칼날 세례 — 서로 다른 적 3명에게 INT×1.8 |
| N+ | 308 강화 일반공격 — 단일 INT×1.8 |
| U | 307 태양의 심판 — 승천 스택 × INT×0.6을 적 전체에게, 이후 스택 0 |
| 해금 | 95 파죽지세 @10 · 368 초월 @30 · 369 영혼 흡수 @50 · 370 지옥불 @70 |

**때릴수록 세지고 맞으면 줄어든다.** 적을 공격한 **행동마다** 승천 1스택을 얻고
피해를 받으면 1스택을 잃는다. 스택 하나당 치명타 피해 +5%, 가하는 피해 +5%다.
한 행동이 여러 대상을 때려도 한 번만 쌓이도록 스케줄러의 행동 카운트를 표식으로 쓴다.

칼날 세례가 치명타로 터지면 강화 일반공격이 곧바로 추가행동으로 예약된다.
`지옥불`(@70)까지 열리면 강화형이 끝난 뒤 스택 수만큼 칼날이 더 날아간다.

궁극기는 쌓인 스택을 전부 태운다. **스택이 0이면 아예 발동하지 않으므로**,
꾸준히 때려서 스택을 털어 두는 것이 그대로 대처법이 된다.

## 5. 플레이어 버전과의 관계

아그리파·옥타비아·카이사르는 **아군으로도 쓰인다.** 유닛 데이터는 따로지만
P·N·U와 해금 패시브는 같은 코드를 공유한다.

> **차이는 '보스 전용' 패시브뿐이다.** 위 표에서 `보스 전용`으로 표시한 코드
> (312~317, 그리고 옥타비아의 284 심안)를 뺀 것이 플레이어 버전이다.
