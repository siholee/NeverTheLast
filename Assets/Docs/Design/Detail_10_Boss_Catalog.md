## 1. 공허 분쇄자 (2001) — 시험장 8스테이지

| 항목 | 내용 |
| --- | --- |
| 일반행동 | 돌격 — 짧은 후퇴→부분 전진으로 시전하고 대상 초상화 중심에 굵은 충격 별·짧은 충격파 고리·카드 반동을 한 중타격 단계로 재생 |
| 궁극기 | **대지 분쇄** — 같은 카드 움직임과 더 큰 중타격으로 공격력 180% + **고정 기절 1턴**. 기절 성공 때만 단순한 상태 부여광 한 번 |
| 검증 목적 | 기절이 집중 시전자에게 들어가면 집중 효과(버프 · 덧붙는 피해)가 풀리고 보호막은 남는가 |
| 공략 축 | 세이가 우선도 대상이 되면 창세의 노래가 끊긴다. 노래를 켠 직후 분쇄자의 마나를 본다 |

## 2. 공허룡 (3001) — 시험장 10스테이지

| 항목 | 내용 |
| --- | --- |
| 일반행동 | 사격 — 후열 용 카드 중앙과 아군 방향 끝의 보스 배율 `Fire3` 작은 불꽃 한 번 → `Explosion1`의 충돌 끝을 대상 초상화 중심에 맞추고 암자주 몸체를 카드 오른쪽에 남기는 카드 폭 안팎 피격 한 번. 투사체·원형 집속 없음 |
| 궁극기 | **공허의 숨결** — 더 큰 같은 법사 시전과 절제된 화면 톤 뒤 아군 전원에게 대상별 보스 체급 `Explosion1` 피격 한 번·공격력 110% (마나 120) |
| 공략 축 | 숨결은 보호막을 두른 아군 전원을 한꺼번에 때리므로 세이의 창세의 결정이 한 번에 여럿 쌓인다 |
