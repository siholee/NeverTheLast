## 1. 보스 슬롯 규칙

| 슬롯 | 결정 | 스폰 |
| --- | --- | --- |
| 중간 보스 | 테마의 `midBossId` + `midBossStageInRound`(기본 8) | 패턴이 없으면 **단독** |
| 최종 보스 | 테마의 `bossId`, 10스테이지 | 패턴이 없으면 **단독** |
| 고정 보스 | `fixedBossStages` — 🔸 **현재 비어 있다** | 라운드의 **마지막 전투**를 차지 |

고정 보스가 낀 라운드는 2번 슬롯을 건너뛰고 이후를 1씩 당긴다.
그래서 테마 보스가 9번째 전투로 밀리고 마지막 칸이 고정 보스 자리가 된다 —
[Detail_09 §2.2](Detail_09_Enemy_Catalog.md)를 본다.

**`stagePatterns`에 그 슬롯의 편성이 적혀 있으면 단독 스폰보다 우선한다.**
호위를 붙이려면 패턴에 보스 ID를 직접 적으면 된다. 로마 군단이 이 방식을 쓴다.

`GetStageKind()`는 HUD 진행 예고에 같은 규칙을 쓴다. 스폰 규칙을 바꾸면 두 곳을 함께 고쳐야 한다.

## 3. 로마 군단 (테마 id 5)

### 3.1 중간 보스 — 아그리파 + 옥타비아 (9스테이지)

**둘이 한 쌍이다.** 아그리파는 옥타비아를 밀어 주는 서포터라 단독으로는 위협이 되지 않는다.
9스테이지 패턴에 에퀴테스 ×2 + 센츄리온 호위와 함께 배치된다.

| P | **300 화합(Concordia)** |
| N | 100 — 피해 없음. INT가 가장 높은 아군에게 1턴간 치명타 피해 +20% |
| U | 100 제 2의 건국자 — 아군 전체 궁극기 자원 +20%, **'화합' 표식** 보유자는 +40% |

**화합(Concordia)** — 아그리파가 단일 아군에게 이로운 효과를 주면 그 아군이 '화합' 2스택을 얻고
가하는 피해가 25% 늘어난다. 아그리파의 턴마다 1스택 줄고, 새로 부여하면 이전 보유자가 잃는다.
따라서 **화합은 항상 한 명에게만 붙어 있다.**

**최고의 2인자** — 필드에 옥타비아가 있으면 일반행동이 무조건 옥타비아를 향하고,
추가로 옥타비아의 행동 게이지를 100% 채운다. 곧 옥타비아가 즉시 한 번 더 움직인다.

> **먼저 죽여야 할 쪽은 아그리파다.** 아그리파를 남겨 두면 옥타비아가 치명타 피해 +20%,
> 화합 +50%, 행동 게이지 100%를 매 턴 얻는다.

**저스핏 고화력 궁극기 딜러다.** 패시브가 DEX를 깎아 턴이 덜 돌아오는 대신 궁극기 한 방이 커진다.
궁극기 자원은 **행동 횟수가 아니라 전투 시간에 비례해** 차오르므로([Detail_02 §2.4-B](Detail_02_Combat.md)),
느려져도 궁극기 주기는 거의 손해를 보지 않는다. 이 두 규칙이 맞물려 컨셉이 성립한다.

**팍스 로마나** — 공격이 적중한 대상 수마다 궁극기 자원을 2% 회복한다.
전체 공격인 궁극기가 5명을 맞히면 그 자리에서 10%가 돌아온다.

**심안** — 원소가 붙은 적을 공격하면 내구를 무시하고 피해를 준 뒤 그 원소를 지운다.
같은 편 트리아리·센츄리온이 부여한 바위 원소가 옥타비아의 관통 조건이 된다.

**카이사르는 스스로 때리는 보스가 아니라 진영을 굴리는 보스다.**

| 코드 | 효과 |
| --- | --- |
| 왔노라, 보았노라, 이겼노라 | 적을 처치할 때마다 모든 '로마' 아군의 가하는 피해 +10%. **상한 없이 중첩된다** |
| 갈리아의 정복자 | 자기 전열의 '로마' 아군이 받는 피해 −10% |
| 위대한 전술가 | 자기 전열의 '로마' 아군이 단일 피해를 주면 같은 대상에게 추가행동으로 일반행동 |
| 대범한 관용(Clementia) | 적을 처치하고 전열에 빈 자리가 있으면 **센츄리온을 소환한다** |

| U 주사위는 던져졌다 | 아군 전체 행동 게이지 +100%. 3턴간 아군이 치명타를 낼 때마다 위력 `LUK×0.1`의 고정 피해 추가 |

**전열을 비우지 못하면 진다.** 위대한 전술가로 호위의 딜이 두 배가 되고,
아군이 죽을 때마다 왔노라 스택이 쌓이며, 빈자리는 대범한 관용이 센츄리온으로 메운다.
반대로 **에퀴테스를 빠르게 정리하면** 추가행동의 원천이 사라지고 소환도 자리를 못 찾는다.

> **대범한 관용은 전열이 꽉 차 있으면 발동하지 않는다.** 카이사르 본인이 전열 한 칸을 쓰므로
> 호위 3기를 남겨 두면 소환이 봉쇄된다 — 잡는 순서를 고르는 판단이 생긴다.

## 4. 아스완 (테마 id 7)

메히코가 '전열을 제물로 쓰는' 편성이었다면 아스완의 두 보스는 **체력 자체를 자원으로 쓴다.**
오시리스는 깎일수록 단단해지고, 아문·라는 때릴수록 세진다. 방향이 정반대라 대처도 다르다.

### 4.2 중간 보스 — 오시리스 (ID 3011, 9스테이지)

| 항목 | 값 |
| --- | --- |
| 등급 | boss · 전열(archetype 8) · 단독 |
| 원소 | 바람 |
| 주/부 | INT / LUK |
| 스탯 | STR 16 +2 · DEX 14 +1 · **CON 73 +9** · INT 40 +4 · LUK 24 +2 |
| P | 1404 불완전한 부활 |
| N | 1406 대지의 진혼 — 적 전체 INT×0.9 + 바위 원소 |
| U | 1405 재생의 격류 — 적 전체 INT×1.5 + 행동 게이지 50% 지연 |
| 해금 | 37 순환 @40 |

**깎을수록 단단해진다.** 체력이 14개의 부위로 나뉜다.

- 최대 체력 ×14. 다만 **Lv40까지는 적 전용 `금 간 생명의 앙크`(4188)**가 다시 ×0.1을 적용한다.
  9스테이지 기준 CON 145, 최대 체력 **20,300**이며 Lv41부터 장비가 빠져 본래 성장 곡선으로 복귀한다.
- 시작 시 받는 피해가 **2.4배**(= 받는 피해 감소 −140%). 부위가 하나 깨질 때마다 10%p씩 줄어
  마지막 부위에서 1.0배가 된다. 9스테이지 체감 체력은 처음 약 8,460에서 점점 늘어난다.
- 부위가 깨질 때마다 **사령 3기**가 필드에 선다(빈칸만큼만). 적 진영은 8칸이므로
  오시리스를 뺀 최대 7기가 동시에 설 수 있다.
- 체력 바가 **14칸으로 끊겨** 보인다. 부위가 몇 개 남았는지가 화면에서 그대로 읽힌다
  (`BaseEffect.HpSegmentCount` → `Unit.HpSegmentCount` → `UnitCardView.RefreshHpSegments`).

초반에 부위를 몰아 깨면 이득이 크지만 그만큼 사령이 쏟아진다. **화력과 처리량 중 무엇을 먼저 낼지**
고르게 만드는 구조다. 소환되는 사령은 `AswanCombat.WraithId`(1052)이며,
라운드 도중에 들어오므로 소환 직후 `OnRoundStart`를 직접 보내 패시브를 걸어 준다.

### 4.3 최종 보스 — 아문·라 (ID 3012, 10스테이지)

| 항목 | 값 |
| --- | --- |
| 등급 | boss · 전열(archetype 8) · 단독 |
| 원소 | 번개 |
| 주/부 | INT / LUK |
| 스탯 | STR 18 +2 · DEX 18 +2 · CON 70 +7 · INT 44 +5 · LUK 26 +2 |
| P | 1405 승천 |
| N | 1407 칼날 세례 — 서로 다른 적 3명에게 INT×1.8 |
| N+ | 902 대체행동 — 단일 INT×1.8 |
| U | 1406 태양의 심판 — 승천 스택 × INT×0.6을 적 전체에게, 이후 스택 0 |
| 해금 | 29 파죽지세 @10 · 1408 초월 @30 · 1409 영혼 흡수 @50 · 1410 지옥불 @70 |

**때릴수록 세지고 맞으면 줄어든다.** 적을 공격한 **행동마다** 승천 1스택을 얻고
피해를 받으면 1스택을 잃는다. 스택 하나당 치명타 피해 +5%, 가하는 피해 +5%다.
한 행동이 여러 대상을 때려도 한 번만 쌓이도록 스케줄러의 행동 카운트를 표식으로 쓴다.

칼날 세례가 치명타로 터지면 대체행동이 곧바로 추가행동으로 예약된다.
`지옥불`(@70)까지 열리면 강화형이 끝난 뒤 스택 수만큼 칼날이 더 날아간다.

궁극기는 쌓인 스택을 전부 태운다. **스택이 0이면 아예 발동하지 않으므로**,
꾸준히 때려서 스택을 털어 두는 것이 그대로 대처법이 된다.

**총 체력은 유지한 채 세 칸으로 나뉘며, 두 칸이 깨지는 순간 속성과 모습이 번개 신에서 공허의 존재로 바뀐다.**

**까마귀도 그때부터 날아온다.** `후긴과 무닌`(3002)은 `공허 각성` 상태를 확인하고,

| 결정 | 무적 | 체력 | 카운트다운 | 놓치면 |
| --- | ---: | --- | ---: | --- |
| 허기 결정 (1135) | 10 | 소환 시점 본체 최대 체력 3% | 자기 턴 3 | **흡수** — 본체가 최대 체력 10% 회복 + 포만 1 (주는 피해 +20%, 전투 끝까지) |
| 파열 비늘 (1136) | 8 | 같음 | 자기 턴 3 | **파열** — 상대 전원 각자 최대 체력 35%. 방어력·피해 배율 무시, 회피 불가, 보호막은 흡수 |

- 입장 시 허기·파열 하나씩. 이후 **일반행동 3회마다 하나**(파열 → 허기 교대). 종류별 2개·합계 3개가 상한이며,
  상한이나 자리 때문에 거르더라도 교대 순서는 넘어간다.
- 결정은 행동 속도를 본체에서 빌리고, 자기 턴 시작의 지속피해가 카운트다운보다 먼저 처리된다.
  발동 직전 턴의 틱으로 쓰러뜨리면 발동하지 않는다.
- 궁극기 공허 강하는 상대 전원에게 `고정 120 + STR 위력 90`을 주고 살아 있는 결정의 카운트다운을 1씩 당긴다.
  **1 남은 결정은 당기지 않는다.** 입장 후 일반행동 2회 전에는 쓰지 않는다.
- 본체가 쓰러지면 남은 결정은 발동 없이 떠난다. 결정은 처치해도 보수를 주지 않는다.

| 해금 | 효과 |
| --- | --- |
| Lv30 단단한 결정 | 결정 무적 +2 |
| Lv50 사냥의 절정 | 처음 50% 이하가 되면 소환 주기 3회 → 2회 (되돌리지 않음) |
| Lv60 탐욕 | 흡수 회복 15%, 포만 1개당 +25% |

🟡 결정의 무적·체력·카운트다운·흡수·파열 수치는 전투 검증 전 가정값이다. 과하면
**무적 → 카운트다운 → 흡수·파열 수치 → 소환 주기** 순으로 조정한다.

## 4-E. 해안 전선 (테마 id 20)

### 4-E.1 중간 보스 — 심연의 공포 (ID 2071, 8스테이지)

**제어를 어디에 쓸지 고르는 싸움이다.** 앞의 돌격대장과 곁의 사냥꾼, 본인까지 셋 모두 갑주를 두르고,
공포는 궁극기로 촉수 폭풍을 **준비**한다.

| 항목 | 값 |
| --- | --- |
| 등급 | elite · 후열 · 돌격대장 · 사냥꾼 호위 |
| 원소 | 바람 |
| P / N / U | 1800 공허의 갑주 / 1840 심연의 촉수 / 1840 촉수 폭풍 |

- N: 서로 다른 둘에게 INT 위력 50.
- U: 피해 없이 준비. 다음 일반행동이 상대 전원 INT 위력 110 + 바람 부착으로 바뀐다. 준비 중 행동불능이면 취소.
- 갑주를 벗겨도 INT 화력은 남는다 — "약화했다"와 "준비를 끊었다"가 다른 가치라는 것을 가르친다.
  바람 부착은 앞 슬롯들이 남긴 물·얼음·불을 아군 사이에 퍼뜨린다.

### 4-E.2 최종 보스 — 심연의 집정관 (ID 3080, 10스테이지)

**갑주를 벗길 제어와 해일을 끊을 제어가 모두 필요하다.** 세이메이의 봉인부 속박은 갑주 해제와 준비 공격 차단을 함께 노린다. 단독 등장.

| 항목 | 값 |
| --- | --- |
| 등급 | boss · 전열 · 단독 |
| 원소 | 물 |
| P / N / U | 1850 심연의 집정권 / 1850 방파제 파쇄 / 1850 해연의 대호흡 |

| 규칙 | 내용 |
| --- | --- |
| **6구간** | 체력을 6등분한다. 한 번의 피해는 **보호막 흡수 뒤** 현재 구간의 끝까지만 체력을 깎는다(`BaseEffect.HpLossFloor`). 초과분은 이월하지 않는다. 체력을 회복하지 않으며, 총체력은 최대 체력 그대로다 |
| **브레이크** | 경계에 닿으면 다음 구간으로 넘어가며 남은 갑주 보호막을 걷고 **한 구간 체력 기준** 갑주를 다시 두른다. 이미 행동불능이면 새 갑주는 곧바로 벗겨진다(제어 회차는 늘지 않는다). 마지막 구간의 끝은 실제 사망이다 |
| **N** | 단일 STR 위력 100. 매 3번째는 상대 전열 전체 STR 위력 75의 꼬리 휩쓸기 |
| **U 대호흡** | 입장 후 일반행동 2회 뒤부터. 피해 없이 준비만 한다. 다음 일반행동이 **해일** — 상대 전원 `고정 120 + STR 위력 125`. **원소를 붙이지 않는다**(물을 연달아 붙이면 정수가 아군 버프가 되므로 위력으로 대신했다). STR은 해일이 나가는 순간 값이라 갑주를 벗겨 두면 약해진다 |
| **취소** | 준비 중 실제 행동불능. 브레이크는 준비를 취소하지 않는다. 해일로 바뀐 회차도 순번 하나로 센다 |

| 해금 | 효과 |

| Lv30 무거운 꼬리 | 꼬리 휩쓸기 75 → 85 |
