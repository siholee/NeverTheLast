# 상세 기획서 09 — 스킬·무기 관리 목록

최종 갱신: 2026-08-12

이 문서는 플레이어 캐릭터 코드와 장비 숙련을 한곳에서 찾기 위한 색인이다. 실제 런타임 원본은 `20_codes.yaml`, `40_items.yaml`, `CodeFactory.cs`이며 캐릭터별 상세 수치는 [Detail_08](Detail_08_Confirmed_Characters.md)를 따른다.

## 1. 공통 슬롯 규칙

| 슬롯 | 런타임 타입 | 규칙 |
| --- | --- | --- |
| 고유 패시브 P | `UniquePassiveCode` | 캐릭터당 1개. 코드 용량 미점유. 전수 가능하면 원본이 지정한 별도 열화 ID를 기록 |
| 일반공격 N/N+ | `BaseNormalCode` | 고유 이름 없음. N+도 UI에는 일반공격으로 표시 |
| 고유 궁극기 U | `UltimateCode` | 캐릭터당 1개. 상시형 수르트 궁극기도 이 슬롯에 속함 |
| 해금 패시브 | `PassiveCode` | `levelPassives`의 레벨 조건과 코드 용량을 만족하면 활성 |

`<전수 불가>`가 없는 고유 패시브는 원본 ID를 전수하지 않고 별도 일반 패시브 ID를 기록한다. 현재 전수 불가 고유 P는 세이·시·찬드라·피그말리온·테세우스·케찰코아틀·츠쿠요미·수르트다.

## 6. 신규 코드 등록 체크리스트

1. `20_codes.yaml`의 올바른 분류(passive/normal/ultimate)에 고유 ID와 표시 설명을 등록한다.
2. 코드 클래스를 만들고 `CodeFactory`의 같은 분류에 연결한다.
3. 캐릭터 코드면 `10_units.yaml`의 `codes` 또는 `levelPassives`에 연결한다.
4. 일반/강화 일반공격의 `CodeName`은 `일반공격`으로 통일한다.
5. 영구 이벤트 리스너는 사망·라운드 종료 시 반드시 해제한다.
6. 새 숙련이면 `EquipmentProficiency`, `IsWeapon`, 이 문서의 숙련 표를 함께 갱신한다.
7. 현재 전용 그래픽 제작 전이므로 신규 공격은 공용 투사체를 사용하고, 아래 아이디어만 기록한다.

## 7. 그래픽 아이디어(미구현)

| 코드 | 추후 연출 아이디어 |
| --- | --- |
| 오리온 강타 | 방패로 자세를 무너뜨린 뒤 검의 무게감 있는 일격, 대상 갑옷에 균열 표시 |
| 테세우스 N+ | 창끝의 첫 타격 뒤 원형 수면 충격파가 전장을 가로지름 |
| 테세우스 U | 창에 물의 궤적이 감기고 적중 후 물결이 시전자에게 되돌아와 회복 |
| 케찰코아틀 U | 나히다 E처럼 조준 표식을 넓게 연결한 뒤 잎·문양이 동시에 발화 |
| 아스클레피오스 U | 보랏빛 약액 투사체가 아군을 통과할 때 보호막 문양을 남기고 대상 지점에서 원형으로 파열 |
| 아마테라스 U | 캐릭터 주변에 태양 문양 차원문 4개가 열리고, 기본공격마다 문별로 한 대상을 추적하는 쌍화살(DEX 위력 8) 발사 |
| 피그말리온 U | 검붉은 장미 가시가 몸을 감싸 방벽이 되고, 접촉한 적에게 화염 장미 문양이 겹쳐 피어남 |

그래픽 작업 착수 전까지 위 항목은 코드 요구사항이 아니며, 실제 구현은 모두 공용 투사체를 유지한다.
