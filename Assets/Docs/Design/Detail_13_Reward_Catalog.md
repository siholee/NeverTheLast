## 1. 보상 생성

한 전투에서 처치한 적들의 `drops`, `commonDropItemIds`, `90_rewards.yaml`의 즉시 보상을
한 풀로 합친다. 카드마다 현재 라운드의 티어 확률을 굴린 뒤 같은 티어 후보 하나를 뽑는다.
후보가 없으면 가장 가까운 티어로 물러난다.

기본 선택지는 3장이고 25스테이지마다 1장씩 늘어 최대 6장이다. 고른 아이템은 파티 공용
인벤토리에 들어가며, 회복·부활·레벨 보상은 고르는 즉시 적용된다.

## 4. 즉시 보상

`90_rewards.yaml.rewards`에는 치료의 영역, 부활의 신약, 이상한 사탕이 있다.

- 치료 보상은 다친 아군이 있을 때만 후보가 된다.
- 부활 보상은 쓰러진 아군이 있을 때만 후보가 된다.
- 대상 지정형은 보상 화면의 공통 대상 선택기를 쓴다.
- T5 파티형 보상은 전원에게 적용한다.
