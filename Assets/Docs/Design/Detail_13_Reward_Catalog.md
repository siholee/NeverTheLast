# 상세 기획서 13 — 보상 목록

최종 갱신: 2026-08-24

> 보상 선택지의 실제 풀과 티어 확률을 기록한다. 장비 자체의 수치는 [Detail_14](Detail_14_Equipment_Catalog.md)을 따른다.

관련 코드: `RewardManager.cs`, `InventoryManager.cs`  
관련 데이터: `40_items.yaml`, `90_rewards.yaml`

## 1. 전투 보상 생성

1. `40_items.yaml`에서 `eventOnly: true`가 아닌 아이템을 보상 후보로 만든다.
2. `themeIds`가 비어 있지 않으면 **현재 테마가 그 목록에 있을 때만** 후보에 남는다.
3. `rarity`를 보상 티어로 사용한다.
4. 현재 보상 라운드의 티어 가중치를 굴린다.
5. 같은 티어 후보가 없으면 가장 가까운 티어 아이템 3개 중 하나를 뽑는다.
6. 한 번 제시한 아이템은 같은 3택 안에서 중복하지 않는다.

선택한 장비는 선택 대상 유닛의 개인 인벤토리에 들어간다. 3차 중량 기준을 넘어도 장비는 사라지지 않지만, 해당 유닛의 휴대품을 정리해 기준 이하로 낮출 때까지 전투 출진·훈련·휴식·덱 구성 등 진행 행동을 할 수 없다.

## 4. 테마 전용 보상

`ItemData.themeIds`에 `stageThemes[].id`를 적으면 그 테마의 라운드에서만 등장한다.
**적 `themeId`가 아니다** — 콜로세움은 테마 4(적 5), 로마 군단은 테마 5(적 6)이다.

| 테마 | id | 전용 보상 |
| --- | ---: | --- |
| 콜로세움 | 4 | 🔸 없음 |
| 로마 군단 | 5 | 레기온 세트 T2 9종 (4201~4209) |

`themeIds`가 비어 있는 아이템은 모든 테마에 등장한다. T1 14종이 여기 해당한다.
