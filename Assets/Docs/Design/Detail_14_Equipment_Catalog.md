# 상세 기획서 14 — 폐지된 장비 체계

최종 갱신: 2026-09-26 (장비 전면 폐지)

> 이 문서는 장비가 현행 규칙이 아님을 명시하기 위한 이력 문서다.
> 개편 전 전체 규격과 목록은 커밋 `a6194c9`에서 확인한다.

## 1. 현행 규칙

- 유닛은 장비를 장착하거나 휴대하지 않는다.
- 장착 슬롯, 양손 판정, 장비 숙련, 중량, 내구, 장비 스탯, 장비 부여 코드는 없다.
- `BaseClasses/Equipment.cs`와 유닛별 장비 저장 필드는 삭제했다.
- 모든 아이템은 `InventoryManager`의 **파티 공용 인벤토리**에 들어간다.
- `40_items.yaml`은 장비 목록이 아니라 공용 아이템(식량 · 전투 비약 · 코드 도구) 목록이다.

## 2. 데이터 마이그레이션

저장 형식은 장비 폐지 때 v11이 되었고, 보상 코드 도입으로 현재 v12다. v11 이하 저장은 현재 리워크와 호환되지 않는다.
옛 장비 ID와 캐릭터별 장착·휴대 목록은 복원하지 않는다.

현행 아이템 규칙과 식량 경제는 [Detail_05](Detail_05_Economy.md), 드랍 풀은
[Detail_13](Detail_13_Reward_Catalog.md)을 기준으로 한다.
