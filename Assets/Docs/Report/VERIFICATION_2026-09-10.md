# main 통합 및 플레이 검증 보고서 (2026-09-10)

## 통합 범위

- `feature/lokapala-special-actions`를 `main`에 fast-forward 통합했다.
- `feature/effect`, `feature/void-series-and-summons`를 포함한 활성 기능 브랜치의 변경은 모두 현재 `main`의 조상이다.
- `origin/backup/main-before-main2-merge`는 이름과 용도대로 과거 보관 브랜치이므로 제품 이력에 다시 병합하지 않았다.
- 검증 환경은 Unity `6000.4.9f1`, Windows Editor Play Mode다.

## 수정한 결함

- 프레이아·아그리파·테스카틀리포카·이단심문관의 비공격 일반행동이 완료 신호를 누락하던 문제를 수정했다.
- 아그리파 `화합`이 자기 자신이 부여한 이로운 효과에 재진입해 무한 재귀하던 문제를 막았다.
- 호루스의 DEX→STR 변환과 중량 계산이 서로 재귀하던 문제를 분리하고, 설명대로 최종 DEX만큼 STR이 증가하도록 보정했다.
- 바루나의 정화가 제어 상태 객체만 지우고 행동 불가 타이머를 남기던 문제를 수정했다.
- 로카팔라 특수행동 예약을 유닛별로 추적해 사망·제어·중복 개방·라운드 종료 시에도 배치 정리가 끝나도록 수정했다.
- 메뉴와 전투 씬 사이에서 오래된 `GridManager`·`DragAndDropManager`가 남던 수명 문제를 수정했다.
- 패배 후 적이 없는 준비 단계가 열리던 문제를 수정했다. 같은 스테이지 적을 다시 생성하며, 생명력 0에서는 `GameOver`를 유지한다.
- 공허의 사슴 일반행동과 대체행동 위력을 같은 계열 엘리트 수준으로 조정했다. 조정 전에는 6스테이지에서 동일 편성이 반복 전멸했고, 조정 후 해당 구간을 통과했다.
- 에어본 파티클 설정 순서 오류를 수정했다.
