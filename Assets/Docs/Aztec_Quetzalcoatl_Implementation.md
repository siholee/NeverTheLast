# 메히코 테마 구현 기록

2026-08-25 기준 신규 아즈텍(메히코) 테마의 단일 구현 기록이다. 이전의 벌새 사제·올빼미 주술사·코요테 전사·틀랄록 대사제 및 구 테스카틀리포카 전투 코드는 제거했다.

|---|---:|---|---|

적 데이터의 `startingItemIds`와 `startingProficiencies`를 런타임에 함께 읽도록 확장했다. 재규어는 둔기, 독수리는 장궁, 뱀 사제와 테스카틀리포카는 장창을 실제로 장착하므로 숙련 조건 패시브가 적에게도 정상 적용된다.

## 전투 구현

- 재규어 전사: 행동불능 대상 피해 +25%, STR 기반 접촉 물리 공격, 궁극기로 바위 부착.
- 독수리 전사: 맹독 대상 피해 +25%, DEX 일반공격과 STR 궁극기, 궁극기로 맹독 부여.
- 뱀 사제: 아군 사망 시 적 전체 INT 기반 추가공격, 일반행동으로 체력이 낮은 다른 아군을 공격, 궁극기로 아군 전체 회복 및 풀 부착.
- 테스카틀리포카: 전열 아군 수당 아군 전체 피해 감소, 전열 아군 즉시 행동 및 1턴 피해 +50%, 스택형 궁극기로 전열을 정예 재규어 4명으로 교체.

명시되지 않은 두 수치는 다음처럼 고정했다.

- 테스카틀리포카 궁극기 요구량: 8스택. 재규어 사망 +2, 재규어 지목 +1.
- 테스카틀리포카 최대 체력: INT 1당 +1%.

궁극기를 사용할 때마다 테스카틀리포카에게 받는 피해 +50% 상태를 독립 중첩한다. 전열 초기화는 사망이 아니라 퇴장으로 처리하므로 초기화된 재규어가 다시 궁극기 스택을 제공하지 않는다.

`망치 나가신다!`를 위해 피해 컨텍스트에 부분 내구 관통을 추가했다. 기존 `DurabilityPenetration` 태그의 전부 무시와 구분되며, 둔기를 장착하고 숙련된 재규어는 정확히 내구 5만 무시한다.

`비몽사몽`은 공명 반응에 한해 시전자 CON을 1.2배로 계산한다. 다른 반응 피해나 기본 CON에는 영향을 주지 않는다.

## 스테이지 편성

메히코는 스테이지 테마 ID 6, 적 테마 ID 7을 사용한다. 5스테이지는 `연기 나는 거울` 사건이며 나머지 편성은 아래와 같다.

|---:|---|---|

| 2 | 재규어 전사 ×4 | 정예 독수리 전사 ×1 |
| 3 | 정예 재규어 전사 ×3 | 정예 독수리 전사 ×2 |
| 4 | 정예 재규어 전사 ×4 | 뱀 사제 ×1 |
| 6 | 정예 재규어 전사 ×4 | 정예 뱀 사제 ×1 |
| 7 | 정예 재규어 전사 ×3 | 정예 뱀 사제 ×2 |
| 8 | 정예 재규어 전사 ×2 | 정예 독수리 전사 ×1, 정예 뱀 사제 ×2 |
| 9 | 정예 재규어 전사 ×2 | 정예 독수리 전사 ×1, 정예 뱀 사제 ×1, 케찰코아틀 ×1 |
| 10 | 정예 재규어 전사 ×2 | 테스카틀리포카 ×1 |

## 스프라이트 규격

- 스탠딩: RGBA PNG, 1024×1536.
- 초상화: RGBA PNG, 1024×1024.
- 배경: 알파 0의 실제 투명 배경.
- 정규화 도구: `Tools/normalize_character_sprites.py`.

신규 7종뿐 아니라 `Resources/Sprite/Standings`와 `Portraits`의 기존 캐릭터 자산 전체를 같은 규격으로 변환했다. Unity 메타의 `alphaIsTransparency`도 모두 활성화했다.
