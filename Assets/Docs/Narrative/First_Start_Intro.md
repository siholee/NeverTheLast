# 첫 실행 도입부 — 세이와 첫 인사

최종 갱신: **2026-10-14**

**🔸 미구현 시나리오원고(V2.1)**.

[세이 설정](Sei.md)을 기준으로 집필한다. V0/V1/V2와 검토 메모는 보관소에 있다.

## 1. 장면의 목적과 범위

- 첫 실행에서 세이 한 명이 플레이어를 맞이한다. 다른 인물의 등장·음성·통신은 없다.
- 번영한 우주를 배경으로 안내를 시작한다. 우주가 이미 멸망한 장면이나 최후의 항성 회상으로 시작하지 않는다.
- 정식 설명을 시작했다가 고유명사 피로에 대한 메타 발언을 하고, 어처구니없을 정도로 간단하게 요약한다.
- 이름을 묻고, 진지한 여행의 초대로 분위기를 회복한 뒤 첫 편성 UI로 이어진다.
- 이전 사용자 설정의 성별 선택은 이름 입력 다음 UI 항목으로 남긴다. 구체적인 선택지와 아바타 구현은 미정이며 대사의 중심으로 삼지 않는다.
- 영겁회귀·불가피한 최종 패배·주인공의 반복되는 존재·최초의 만남은 공개하지 않는다.

## 2. 🔸 연출의 공통 전제

밝은 방주의 공간. 창밖에는 빛을 잃지 않은 별과 행성의 불빛이 보인다. 세이는 플레이어를 향해 서 있다. 세계 소개 영상이나 설정 자막을 별도로 추가하지 않는다. 지문은 제작 메모이며 새로운 화자의 대사가 아니다.

`{playerName}`은 이 원고의 이름 치환 표기다. 현행 코드에서 지원하는 토큰이라는 뜻이 아니다. 이름·성별 입력 구간도 구현 예정 지시이며 실제 입력 UI가 있다는 뜻이 아니다.

## 3. 현재 원고 — V2.1

V1의 대사 본문은 433자였다. 사용자의 추가 지시에 따라 세이의 정체·방주 운영자라는 직무, 번영한 행성들의 생활, 변방의 위협, 동료와 함께 준비하는 방식, 세이와 플레이어의 소망을 보강했다. 짧은 요약은 장면 전체의 길이를 제한하는 기준이 아니라 웃음 장치로 남긴다.

## 4. 현행 구현과의 차이

현행 main의 `GameManager.StartFromIntent()`는 테스트 흐름으로 신규 런에서 인트로를 건너뛰고 캐릭터 선택으로 바로 진입한다. `PlayIntroThen()`과 `00_intro.yaml`은 있지만 본 테스트에서 호출 경로나 데이터를 변경하지 않는다.

기존 `00_intro.yaml`의 멸망 이후 내레이션·기록자·세이 카메오는 이 신규 원고의 설정 근거로 쓰지 않는다. 해당 데이터는 이 작업에서 수정하지 않는다.

이름·성별 입력, 이름 저장·치환, 첫 실행 여부 판정, 편성으로의 연결은 후속 구현 항목이다. 시나리오 테스트를 실제 플레이 검증으로 보고하지 않는다.
