# SD 디오라마 전장 — 비주얼 리메이크 제안

최종 갱신: **2026-10-29** · 상태: 🔸 미구현 제안(방향 확정, P1 무대 모드 1차 구현 🔸 검증 필요)

카드 원화 전장을 무대 위에 선 SD 유닛으로 바꾼다. 전투 판정·행동서열·AV·피해 콜백·상태/자원 판정은 바꾸지 않고 **보이는 층만 교체**한다.
세계관 소재(열차·황무지)와 손패 UI는 가져오지 않는다. 기존 카드 경로는 `VisualMode.Card/Stage` 전환으로 남긴다.

- 시안: 저장소 루트 `Docs/Mockups/VisualSD/index.html`(v1.2). 좌표·크기 원본은 시안 스크립트의 `ROW`·`rowDist`·`place`·`anchor`·`SD_SETS`·`hsrBarHTML`·`cutin`이다.
- SD 원화: `Docs/Mockups/VisualSD/sd_gen/style_c3/`(확정본). 생성 기록 `sd_gen/report*.md`, 검수 `sd_gen/review_c_eyes_pose.md`.
- 구현 기록: `Logs/VisualSDP1_20261029/`(S1~S8 보고·검수). 다음 단계 지시서 뼈대: `Docs/Mockups/VisualSD/P2_Codex_Brief.md`.

## 2. SD 규격

- 원본 1024×1280 투명 RGBA, 전신, 그림자·글자·배경·VFX 없음. 파일 `{ID}_SD_{IDLE|WINDUP|STRIKE|HIT|DOWN}.png`, 등록 위치 제안 `Assets/Resources/Sprite/SD/`.
- 같은 캐릭터 5장은 머리 크기·의상·얼굴·무기 손·원소색 위치가 같아야 한다. 발 기준선은 캐릭터마다 다를 수 있으므로 캐릭터별 발 좌표를 데이터로 둔다.
- 깊이 배율 1.0에서 몸 높이 250px(1080p). 정예·대형 ×1.15, 보스 ×1.6~2.2.
- 앵커 4점: `head`(상태 글자) · `chest`(피격 접점) · `hand`(시전) · `feet`(그림자·행동 고리). 캐릭터별 보정값은 `97_stage_figures.yaml`.
- 생성 규칙과 실제 프롬프트는 `sd_gen/report_v5.md`(IDLE)·`report_v6.md`(포즈). 참조는 스탠딩·초상화·확정 IDLE을 함께 첨부한다.
- 검수: 얼굴 크롭이 캐릭터끼리 구분되는가 · 단색 실루엣이 캐릭터·포즈끼리 구분되는가 · 시선이 적 쪽인가.

| 상태 | 1배 길이 | 프레임 | 판정과의 관계 |
| --- | --- | --- | --- |
| 대기 | 1.6s 반복 | IDLE + 호흡 | 없음 |
| 예고 | 0.36s(+초월기 1.15s) | IDLE + 바닥 고리 | 기존 예고 대기 |
| 공격 준비 | 0.14s | WINDUP | 연출만 |
| 공격 정점 | 정점 ~ 0.32s | STRIKE | 기존 타격 콜백 시각을 **구독만** |
| 피격 | 0.2~0.42s | HIT | 실제 피해 적용 뒤 |
| 쓰러짐 | 0.6s | DOWN → 결정 조각 | 실제 사망 뒤. 강인도 격파에는 쓰지 않음 |

모든 SD 모션과 프레임 교체는 scaled 시간으로 1~5배를 따르고 일시정지 중 진행하지 않는다.

## 3. 진형 배치 좌표

GridManager 좌표(x −2…2, y 1…4)·대기석 5칸·전후열 헬퍼는 그대로이고, `StageLayout`이 화면 좌표만 계산한다.

| 항목 | 규칙(1080p, 시안 `ROW`·`rowDist`) |
| --- | --- |
| 열 거리 | 중앙에서 전열 190px, 후열 540px. 거리 = 기준 × (0.80 + 0.25t) + 30 × (t − 0.5) |
| 깊이 레인 | y 560(먼) ~ 870(가까운). 한 열 1명 t=0.5, 2명 t={0.2, 0.8}, 3명 이상 t=i/(n−1). 준비는 4레인 고정 t=row/3 |
| 깊이 배율·정렬 | 0.84 + 0.22t, 그리기 순서 = 화면 y |
| 바닥 열 표시 | 전열·후열 띠를 옅게(전투 7~10%), 준비 화면은 진하게(20%)와 “전열·후열” 이름 |
| 전열 공백 | 전투 중 전열이 비면 후열을 안쪽으로 당김(현행 유지) |
| 그리기 층 | 배경 원화 < 색 보정 < 바닥 열 표시 < 그림자 < SD(깊이 정렬) < VFX < 숫자·상태 글자 < 화면 UI(하단 HUD 포함) < 컷인 |

현재 P2 구현은 위 진형 좌표와 `StageRowBands`의 Stage 전용 바닥 띠를 사용한다. S7의 전열 200·후열 560·지그재그 +100/−80과 하네스 기대값은 P2 S1에서 교체했다.

| 초월 원 | 42px, 카드 바깥쪽 위 모서리에 겹침. 충전 완료 시 카드가 원소색 테두리로 빛나며 8px 뜸. 행동 중 14px 뜸 |

현재 P2 구현은 Stage 전용 하단 양 진영 HUD다. 재보는 현행 활성 조건에서만 보이고, 미활성 때 양 진영 줄을 모으며 증원 줄은 118×105px로 둔다.

## 5. 연출

- 피격: 원소색 베기 2획과 백색 심, 결정 파편, 발밑 파문, 짧은 명도 상승과 반동. 직접 연타는 같은 행동ID·수신자에 한해 `N타 합계`로 누계(현행 규칙).
- 치명·초월기만 유닛·효과 층을 짧게 흔들고 배경은 흔들지 않는다.
- 초월기 컷인: 화면을 어둡게 누르고, 사선 띠가 세로로 열리며, 스탠딩 원화·원소 광·속도선·기술명이 시차로 들어온다. 화면 섬광은 낮은 명도차로 한 번.
- 컷인 얼굴 프레이밍: 원화 얼굴점을 띠 안 고정점에 맞추고 그 점을 회전 축으로 써서 얼굴이 잘리거나 기술명에 가리지 않게 한다. 비인간형 적은 얼굴점이 없어 원화가 비어 보인다(D6, P2 지시서 S4).
- 컷인 시간: Stage의 실제 초월기 예고 시작에 1.15초 전체판, 입력 비차단. 기존 예고 0.36초에 연출 전용 1.15초를 더하며 이 동안 AV·상태 턴은 진행하지 않는다. 대기 끝의 생존·제어·실행 조건 재확인과 취소를 유지한다.
  Card 모드·BalanceSim(`NTL_SIMULATION`)·검증 시드 세션에는 추가 시간이 없다. 근거: `Logs/VisualSDP1_20261029/S8.md`·`S8b_review.md`.

## 6. 현행 규칙 개정 대상

채택 시 [07 UI·기술](../Design/Detail_07_UI_Tech.md)과 AGENTS.md의 다음 문장을 함께 고친다.

- “아군/적 모두 적 카드 기본 구조” → “아군/적 모두 같은 SD 무대 유닛, 정보는 하단 양 진영 카드”.
- “초월 원은 캐릭터 위” → 초월 원은 하단 카드 모서리.
- “행동서열의 확장… 예고·시전·효과”에 Stage 초월기 컷인 연출 대기(1.15초)를 예외로 추가. Card 모드는 그대로.
- 원화 피격점·`portraitContacts` 규칙 → SD 앵커 규칙. 원화 비율·alpha·임포트 정책은 원화 용도(초상화·스탠딩·컷인)에 한해 유지.
- 상단 바·행동 순서·피해 집계 위치, VFX 앞 레이어·`ElementPalette`·구매팩 시트/정점 보존은 그대로.
